# このCodexセッションで作った手描き風アセット

出所: 会話 01a197da-ca51-7162-82ef-489108b86f5c。2026-11-04にアップロード。
mmotest既存の制作体系・本番アセットとは区別するための保管フォルダです。
既存マップの参照先やアセットは差し替えていません。

- current/: ビューアで選択できる11種類のモデルと、別サイトで比較できる描き込みXの木箱。元の切り株のブロックアウトを含みます。
- variants/: 以前の完成版と試験版。針葉を細かくした版など、現在は採用していないものも明記して保存。
- methods/: 制作手順とレシピ。previews/: 外観の確認画像。
- manifest.json: ファイルの出所、同梱内容、サイズ、SHA256。

各ZIPをフォルダごと展開してください。GLB、BLEND、必要なテクスチャ、使用上の説明を同梱しています。
ZIPだけを置くことで、GLBとBLENDに入る画像をGit上でさらに重複させない形にしています。
マップの地形、ゲームシーン、ライト、カメラは配布対象に含めていません。
各モデルの制約・材質・マップ構成は同梱READMEと制作メモを参照してください。

## B01置換の候補・上位3つ

1. **切り株**: 単純な幹と根の形に、木口の年輪・樹皮・苔・接地の陰を描ける。既存の成果を最も活かせる。
2. **木箱（crate）**: 大きな面が多く、木目、板の継ぎ目、鋲、角の擦れをテクスチャで整理しやすい。B01に5個あり置換効果も確認しやすい。
3. **荷台（cart_frame）**: 外形は梁と板で読みやすく、木目・接合部・金具を描いた質感で補える。今回はB01の車輪のない荷台として作り、現行の車輪付き荷馬車をそのまま使わない。

評価軸: 少ない形状でシルエットが読めること、塗りで素材感を足しやすいこと、既存ステージ内で比較しやすいこと。
描き込みXの木箱は `current/crate-painted-x.zip` に保管しました。プレビューは `previews/crate-painted-x.png`、制作メモは `methods/crate-painted-x-method.md`、立体Xとの比較は [木箱ビューア](https://sol-painted-crate-20261104.shindou-kazuma12.chatgpt.site/) で確認できます。B01専用荷台の制作とステージ置換はまだ行っていません。
