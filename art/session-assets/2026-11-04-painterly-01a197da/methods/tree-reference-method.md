# 見本の広葉樹

ユーザーの見本画像をもとに制作した、回転して見られる3Dモデルです。
以前の広葉樹M13の「独立した曲面の葉＋樹冠から転写したカスタム法線」を使っています。

## 同梱ファイル
- Reference_Oak.glb：実行用。1メッシュ・1材質・16,404三角形。
- Reference_Oak.blend：ベイク済みモデル。同梱Texturesを参照。
- Textures/BaseColor.png：4096×4096の色テクスチャ。
- Paint_Source.blend：226個の葉ファンと連続した幹を編集できる塗り元。画像をパック済み。
- README.md：この説明。

GLBは画像・UV・カスタム法線を内蔵しています。
ノーマルマップ・AOマップ・ラフネスマップは使用していません。
塗りと樹冠の色のグラデーションをCyclesのEMITで焼き込みました。実際の光や床の影は色へ焼いていません。
葉の内側に球体は残していません。床・カメラ・ライトはアセットに含みません。
BlenderではZ上、GLBではY上。高さ約4.3m、幅約4.6m。

## 推奨表示
粗さ0.95、金属度0。色テクスチャはsRGB。
サイトでは半球光と柔らかい斜めの光を使い、重なる葉の強い自己影を抑えています。
Three.jsではモデルのcastShadow=true、receiveShadow=false。床のみ影を受けます。

## 制作手順
1. 太く短いS字の幹、大きな中央の樹冠、左右の低い葉群でブロックアウト。
2. 樹冠を丸い先端の曲面の葉へ置き換える。
3. 一時的な樹冠から法線を転写し、一時メッシュは削除。
4. 生成した樹皮と葉の筆跡の画像をUVへ配置。根元の苔と樹冠の上下の色差を加える。
5. 4Kの色テクスチャへベイクし、GLBへ書き出す。
6. 正面・側面・背面で形と葉の面の向きを確認し、GLBの再読み込みを検証。

見本1枚からの再構成なので、側面と背面の形は補完しています。
