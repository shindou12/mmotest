# 木の柵：制作方法

切り株と同じ金茶色、面のある筆跡、根元の苔を使い、手描き風の木の柵に展開しました。

## 1. 太い部材で輪郭をつくる

支柱2本、横板2本、斜めの補強材1本をBlenderで制作。角を大きめに面取りし、横板にわずかな反り、支柱の切り口に不揃いを加えました。部材は厚みのある閉じた形状です。

## 2. 筆跡を部材の長さに沿わせる

切り株を参考に、製材した木の表面を画像生成しました。金茶色の大きな塗り分け、流れる筆跡、細い割れ目、少数の節を設計。横板や斜材にも長さ方向に木目が通るよう、部材ごとにUVの向きを設定しています。

## 3. 接合部と根元を描き込む

鋲と座金は表裏の合計8か所に立体として配置。茶金色の塗り分けと小さな溝で接合部を読みやすくしました。支柱の足元には、切り株と同じノイズと高さのマスクで苔を重ねています。

## 4. 焼き込んで、回して確認する

木目、切り口の年輪、苔、鋲の色をEmissionベイクで2Kのベースカラー1枚に統合。前後の画像を確認し、鋲の強すぎる暗い縁と支柱の切り口を修正しました。最後にGLBをBlenderへ読み戻して確認しています。

## 出力仕様

1,808三角形 / 1メッシュ / 1マテリアル / 1 UV / 2,048 × 2,048 px。支柱の中心間隔は2.10 m。GLBはY-up、BlenderはZ-up。原点は接地面の中央。

Blender標準ノードと画像生成を使用。ベイク対象は色とデザイン上の明暗です。表示環境の照明でも明暗が変わる、粗さ0.92のPBRマテリアルとして書き出しています。
