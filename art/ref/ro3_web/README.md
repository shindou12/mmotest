- **見本と同じ画像:** 4Gamer の SS/030〜032 と YouTube 3NeAoBqD3MM のサムネイルは、`art/ref/trees/T01〜T04` と同じ画像でした。
- **見本に使えないもの:**

  - 画面を撮った写真（反射と斜めの歪み）。
  - 文字ばかりのスライド。
  - 名札が画面を覆う町（Game*Spark 1012624）。
  - 宣伝の文字が大きいサムネイル。
- **集めていないもの:** 動画のフレームです。「RO3 First Look」（648A_LVV9T8、約 1 時間）、Pioneer Test の録画、公式トレーラーには、フィールドの場面がもっとあります。ただ、動画を取り込む道具（yt-dlp）が入っていないため、集めていません。
