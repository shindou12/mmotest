# 板と金具のアセットを見本から作る

`docs/world-art/prop-blockout.md` を最初から最後まで読み、その手順に従う。この手順は試行中で、規則集には採用していない。

守ること:
1. 見本がなければ、作り始める前にユーザーに頼む。
2. 形・展開図の配置・下絵・見た目の判断は自分でする。札で Luna に渡さない。
3. 形は 3 段階で作り、段階ごとに撮って見本と並べる。色を塗る前に、灰色のままゲームのカメラで確かめる。
4. 絵は `docs/world-art/templates/atlas-paint-card.md` を複製した札で Luna に渡す。合否はずれの数値で決める。
5. 一時の地図と GLB はコミットしない。本番の置き換えはユーザーが判断する。
6. 終わったら `docs/world-art/rules/<物>-<チケット>.md` に記録し、新しい失敗を手順書の「よくある失敗」に足す。

世界全体の色や光の規則は、スキル `world-art` と `docs/world-art/rulebook.md` を見る。
