# モデル・モーション・エフェクトのリプレイス順

現在遊べる3層を対象に、戦闘中に何度も見えるものから作る。
ボス3体の専用モデルは制作済み。今回はそれぞれの主役となる部位を使うモーションと演出を2技ずつ試作した。

| 順 | 対象 | 現状 | 制作内容 |
|---|---|---|---|
| 1 | ボスの主力技 | 今回6技を試作 | 構え・振り・命中時の止め・戻り。剣筋、根、葉、鋏、毒針を専用化 |
| 2 | ボスの突進・特殊技 | 共通の動作が多い | グラズの盾突進、ユグドラの根の檻・召喚、スコルピオの突進・尾の薙ぎ払い |
| 3 | 激昂・最終形態 | 共通の発光・動作が中心 | 体の動かし方と予備動作を変え、各ボスの特徴を強める |
| 4 | 通常敵のシルエット | 3層に12定義、8種類の基本造形 | ボア・狼・通常蠍の区別を優先。名前と見た目が合うモデルを作る |
| 5 | 武器の専用モデル | 共有の形状が多い | 制作済みのユニーク武器を組み込み、未制作の武器種を順に補う |
| 6 | NPCと環境小物 | NPCはプレイヤーの造形を流用 | 商人・鍛冶屋などの役割を服と姿勢で見分けられるようにする |

## 今回の6技

| ボス | 技名 | 既存パターン | 動き | エフェクト |
|---|---|---|---|---|
| グラズ | 覇王の薙ぎ払い | cone | 盾を立てて溜め、体をひねって水平に振り抜く | 実際の刃を追う金色の軌跡、斬撃波、土煙 |
| グラズ | 王断の一撃 | slam | 大剣を頭上に上げ、重く振り下ろして止める | 縦の剣筋、地面の亀裂、衝撃の輪 |
| ユグドラ | 根脈の波 | shock | 枝の腕を持ち上げ、地面へ叩きつける | 外へ順に伸びる曲がった根、緑の波、花粉 |
| ユグドラ | 樹冠の雨 | rain | 枝を広げて樹冠を揺らし、光を集める | 攻撃の発生直前に落ちる葉、着弾時の花粉 |
| スコルピオ | 双鋏の連撃 | combo | 左右の鋏を交互に開閉し、最後は両鋏で締める | 鋏を追う琥珀色の軌跡、砂と甲殻片 |
| スコルピオ | 毒針の射撃 | shot | 尾を引いて毒針へ力を集め、前へ出す | 毒針からつながる緑の流れ、扇状の毒液弾 |

モーションはTransform操作。モデルの生成、技のタイミング、ポーズ、エフェクトを別ファイルに分ける。
共通の補間や軌跡生成を使い、主役の部位と予備動作で個性を出す。

## 次に作るボス技の順

1. グラズの盾突進：盾を前へ出し、腰を落として踏み込む。盾の接触に火花と土煙。
2. ユグドラの根の檻：両腕を広げ、根が外周を囲む。召喚も小さな枝や光点で森林の系統に揃える。
3. スコルピオの尾の薙ぎ払い：鋏で守りを固めて低い姿勢を取り、尾を横へ振る。砂の帯と針の軌跡。
4. 各ボスの激昂・最終形態：先に揃えた主力技を強めて再利用し、移行時のポーズと演出を付ける。

既存の使用パターンとフェーズ移行技を合わせると3体で38組ある。今回の専用モーションは6組で、残る32組は以下。

- グラズ：combo / charge / sweep / shot / fissure / barrage / chase / shock / ultimate
- ユグドラ：combo / cage / summon / cone / shot / checker / haven / spiral / nova / ultimate
- スコルピオ：chase / sweep / cone / ring / rain / charge / fissure / checker / spiral / cross / cage / shock / ultimate

全部を独立した新規技にせず、既存の斬撃・根・毒針の素材を再利用し、構えや振り方を変えて作る。
今回の6組以外は従来のモーションを使う。対応した着弾形状には、ボスごとの共通演出が付く。

## 動作確認と使い方

ブランチ：`codex/boss-motion-trial`。専用ボス3体がある `codex/boss-model-refine` から分岐。
このブランチのゲームを通常どおり起動すると、対応する攻撃で新しいモーションと演出が使われる。
試作ページ：`http://localhost:8080/boss-motion-trial.html`。ボス・技を選択し、再生を止められる。
UIはRoot階層、Passive View、Presenter、イベントを裁定する状態機械のMediatorで構成する。

- 64件のテストが通過。技の開始時に共通の構えが一瞬混ざらないことも確認。
- 2人のオンライン接続で6技のID・再生・専用エフェクトを確認し、スタン時には両方の再生が取り消されることを確認。
- 変更前の6技×3段階＝18組と、攻撃の発生時刻・形状・弾の速度・ダメージが同じことを検証。
- 技の終了後に通常の姿勢へ戻ること、武器の握りと根の接地、エフェクトの解放を確認。
- 攻撃情報がモデルより先に届く場合、途中参加、重複した同期情報、スタン時の取り消しに対応。
- サーバーからの攻撃通知と同期情報を使う。演出用メッシュは当たり判定を持たない。
- 動画は各12秒、1280×720、30fps、H.264。各ボス2技ずつ、通常速度で2回ずつ再生する。

赤い攻撃予告と既存の判定処理は維持する。動画は独立した試作ステージで、攻撃予告と演出を既存のタイミングに合わせて再生している。
