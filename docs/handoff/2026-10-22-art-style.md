## 5. 進め方（rulebook 13 の要約。これを外れると後で比べられなくなる）
- 1 回に 1 つだけ変える（URL の引数か地図の JSON の 1 項目）。入／切は条件を固定して撮る（`abshoot.sh`・`abcompare.py`）
- **絶対値ではなく比で比べる**（明暗比・材質ごとの日陰/日なた・青の寄り・同じ材質の色相・分位点。`rulecheck.py`・`refstats.py`）。見本も同じ道具で測る
- 1 枚・1 方向で決めない: 見本のカメラ + 標準ビュー（斜め・横・俯瞰・歩行者・近景・遠景）を撮って比較シートで見る（`views.mjs`・`viewsheet.py`）
- 規則の採用は 1.2 の 4 条件（効く向き・複数の場面・副作用なし・見本の範囲）。欠けたら「条件付き」「未検証」と書く
- 新しい仕組みは値を 2 段変えて画素が変わるかを先に確かめる（効いていなかった前例: F25）
- 地図全体に効く規則は既定を変えず、地図の JSON で入れる。規則を変えたら全部の地図を撮り直す（F20）
- 記録: ループごとに `goal-<地図>.md` か `rules/<題>.md`、実験は `experiments.md`、失敗は `pipeline.md` の 5、規則が変わったら `rulebook.md`（確度の印 [確定]/[測定]/[暫定]/[未検証] を付ける）。撮影は `pack_shots.py` で webp にしてコミット

```sh
git fetch origin && git checkout claude/funny-hypatia-z9ba69 && git pull   # 研究の最新はこのブランチ（新しい会話の作業ブランチはそこから切る）
npm ci
# 最初の確認（組み立て済みの地図がコミットにあるので Blender は要らない。サーバーは views.mjs が立てる。1 ビュー約 2 分）

blender -b --factory-startup --python tools/worldart/blender/build_assets.py
blender -b --factory-startup --python tools/worldart/blender/build_map.py -- mihon2
```

**最初の確認**: B01〜B04 の明暗比・彩度・輝度が `rules/ab-L23.md` の最後の表と ±0.03 以内なら環境は正しい。2026-10-22 にこのブランチ（60759f9）で撮り直して一致を確かめた: 明暗比 2.59/2.38/2.52/2.40、彩度 0.55/0.57/0.51/0.30、輝度 0.47/0.53/0.48/0.45。外れたら研究を進めずに環境（three の版・ソフトウェア描画・Blender の版）を疑う。
- 画面のない環境では描画が遅い。撮影・組み立ては同時に 1 つだけ。
- ユーザーは Windows の PC のセッションでも作業している。その環境の道具の場所は `docs/godot/windows-setup.md`（Python は `-I -X utf8`）
- Godot での確認は任意（`sh tools/agents/setup.sh --godot`、`godot/worldart/README.md`）。研究の判断は three.js の画面で行う。

## 7. 決まりごと
- 見た目の判断（規則の採用・構図・色・形）は画像と数値の両方で。判断の根拠（どの画像・どの数値）を記録に残す
- コミットとプッシュは自分のブランチだけ。PR は頼まれたときだけ
- **見本の画像（ゲームの画面）はこのリポジトリの中で研究に使う。外部のサービスへ送る・公開するときは先にユーザーに相談**
- API キー・従量課金は使わない。認証・課金・戻しにくい操作はユーザーに相談
- **許可を待たず自律的に進める**（ユーザー、2026-10-22。下の禁止事項は除く）。区切り（ループ 1〜2 回分か、規則を 1 つ採用・棄却したとき）ごとに、ユーザーが見られる比較シートと短い報告を出す。進捗は区切り線つきの日本語の一行（CLAUDE.md の「進捗ログ」）
- **車輪の再発明をしない**: 描画の仕組みや道具を一から組む前に定番の手法を検索し、出典を `docs/world-art/sources.md` に残す（CLAUDE.md）
- ユーザーの好みとして決まったこと: 水の太陽のきらめきは既定 0（波の表現で十分）、浅瀬は明るい水色。生成した絵は見本にしない
- 会話が重くなったら（CLAUDE.md の「会話の切り替え」）、`docs/handoff/<日付>-art-style.md` を書いて止まる
- 歩ける比較ページ（Artifact「見本② 版くらべ」https://claude.ai/artifact/A31scCgQs9tWLQ1dhMAgZQ 、試遊 https://claude.ai/artifact/4RJANYkdaxpV6FNCyB4smZ ）は `tools/worldart/compare/` で組み立てる。作り直すときは新しい版を足し、過去の版は git から取り出す
