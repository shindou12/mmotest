# コボルド王 グラズ：専用モデル

ブランチ：`codex/graz-model-refine`。`codex/coop-hard-mode` のキャラクター改修済み版から分岐。

汎用の鎧騎士から、犬科の顔・立ち耳・牙・真鍮の王冠を持つコボルドの王に変更。
鉄色の鎧、赤い短いマント、毛皮の肩飾り、王冠の紋章を持つ盾、欠けのある幅広の大剣を組み合わせた。
共有の `MeshToonMaterial`・4段階の陰影・背面輪郭線を使う。

## ゲームへの組み込み

- 第1層のボス定義だけに `appearance: 'graz'` を追加。
- `makeMob()` の第6引数に外観を渡し、`graz-model.js` の専用造形を選ぶ。
- 敵種 `knight`、ボスの大きさ `2.8`、攻撃パターン、HP、ダメージ、スタン値は同じ。
- 既存の `animateMob()` が本体・剣腕・脚・マントを動かす。専用の頭と尻尾にも、同じ関数の既存処理を適用する。
- 他のボスと通常の騎士は元のモデルを使う。

通常どおりゲームを起動すると、第1層のボスがこのモデルになる。
比較ページは `http://localhost:8080/graz-refine.html`。
プレビューは Root 階層、Passive View、Presenter、イベントを受ける状態機械の Mediator で構成する。

## 検証

- 54件のテストが通過。全武器の動き、武器ツリー、協力プレイ、ボスのスタン値を含む。
- ブラウザで384状態を確認。本体・剣腕・脚・マント・発光の軸について、既存モデルとの行列差は0。
- 2人のオンライン接続で同じ第1層ボスを表示。専用モデル・剣・大きさ・予備動作を確認。
- 本体5,310三角形。共有の地面リングを含めて5,390三角形。輪郭用の追加描画は別。

## 配布モデルと比較素材

比較画像とMP4は、ゲームで使う生成コードとトゥーン材質を直接描画したもの。
MP4は16秒、1280×720、30fps、H.264、yuv420p。

`graz-refined.glb` は静止ポーズの部品階層を保存したモデル。
GLBではトゥーン材質を標準PBR材質に変換しているので、別のビューアでは陰影が変わる。
ゲーム用のTransformアニメーションは `animateMob()` にあり、GLBにはAnimationClipやスキニングを含めない。
ゲームではGLBを読み込まず、専用生成コードを使用する。
