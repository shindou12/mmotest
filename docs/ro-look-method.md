# RO風の背景の作り方（手順）

参考にしたのは Ragnarok Origin のような「高い角度から見下ろす、緑が濃く明るい、柔らかい光」の画面。
外部のアセットは使わず、絵（テクスチャ）は全部コードで canvas に描く。実験場 `public/lab.html?style=ro` で確かめられる。

コードの場所:
- 地面: `public/js/previews/ro-style.js`（`PAINT` と `roGroundMaterial()`）
- 木・茂み・草・シダ: `public/js/previews/foliage.js`（`FOLIAGE_TEX` と `FoliageBuilder`）
- 光・カメラ・仕上げ: `public/js/previews/graphics-lab.js`（`setStyle()` / `setTime()` / `gradePass` / `tiltPass`）

## 1. 地面は「描いた模様を混ぜる」
- 草・土・川岸の3種類の模様を canvas に描く（草は房と小花、土は小石と轍、岸は小石）。繰り返しが目立たないよう、筆の点をランダムに重ねる。
- 地面の頂点に `splat`（土の割合・岸の割合）を持たせ、シェーダーでノイズを足してから混ぜる。境目が筆でなぞったようにギザギザになるのが大事。
- 頂点に `shade` も持たせ、木の下は暗く（AO）する。これだけで「森の中」に見える。
- 色: 草 `#84b84c` 前後の黄緑、道 `#d2b47c` の明るい土色。彩度は高め、暗い緑は使わない。
- 草の模様は房を大きめ（8〜18px）・多め（1700）に。遠目でも筆の草に見える大きさにする。
- シェーダーで 20m ほどの大きなむらを掛ける（黄みの明るい所と深い緑の所）。繰り返し模様が目立たなくなる。

## 2. 木は「葉っぱの絵の板」を丸く集める
- 葉っぱの絵を 2×2 のアトラスに描く（広葉樹の星型の葉 24 枚、モミの葉の房、シダ、草の房）。透過は alphaTest。
- 木は幹と枝（円柱）＋枝先ごとに小さな「房」を3〜4つ寄せる。房はランダムな向きの葉の板を球状に置いたもの。丸一つにすると綿あめのようになるので、小さな房を寄せて輪郭をでこぼこにし、房の間に陰と幹が見えるようにする。
- 法線は板の向きではなく房の中心からの向き（球の法線）にする。これで板の木が丸い塊として光る。裏面で法線を反転させない。
- 房の内側ほど暗く、上ほど明るく頂点色で塗る（`(0.5 + r*0.5) * (0.78 + k*光)`）。
- 影は `customDepthMaterial` に同じテクスチャと alphaTest を渡す。木漏れ日のようなまだらの影が落ちる。
- 風: 頂点に揺れの強さを持たせ、時間で少し揺らす。
- もみの木は「上から見た一段の枝」の絵（中心から羽のような枝が放射状）を描き、水平な大きい板＋外へ垂れる小さい板を段々に重ねる。上の段ほど小さく明るい。縦の板で作ると暗いテントのようになる。

## 3. 地面を埋める
- 木の周りと道の脇に茂み（低い房）、木陰にシダ、全体に草の房を数万本（ノイズで群生させ、道の縁は濃く）。
- 3D の草は消す。描いた草の房のほうが絵と馴染む。
- 赤いキノコ・花など少量の差し色を置く。

## 4. 光
- 半球光の地面側の色をオリーブ寄りの緑 `0x3a5634` にして、影を黒ではなく暖かい深緑にする（青緑にすると冷たく見える）。
- 太陽は暖色 `0xffe6b8`。トゥーンの段はやめ、なだらかなグラデーション（`[150,188,222,255]`）。
- 背景の輪郭線は消す（キャラだけ残す）。

## 5. カメラ
- 画角 30° の望遠で、高く遠くから約 47° で見下ろす（歩くとき 高さ 24.8・後ろ 23.2）。55° だと真上すぎて木が丸いだけになり、47° だと幹と木の横顔が見える。
- キャラと注目点の間の木、カメラの近くの木は点描で抜く（OCC）。抜く芯は全部消す（薄い膜が残ると画面が汚れる）。低い草とシダは抜かない。

## 6. 仕上げ（ポストエフェクト）
- 色調: 彩度 1.06、コントラスト 1.02、周辺減光 0.2、暗部を少し緑に持ち上げ（lift .02, .03, .01）、明部を黄みに（gain 1.07, 1.04, .86）。
- ティルトシフト: 画面の上下をぼかす（中央 ±0.22 はぼかさない、強さ 3.5）。ミニチュアのような奥行きが出る。
- ブルームは弱め（0.35）。
- 霧は全景だけ薄く。

## 確かめ方（ループ）
1. 同じ視点（歩く・全景・川の夕方）で撮る。
2. 参考画像と並べ、差を「色」「密度」「形」「光」に分けて一番大きい差を1つ直す。
3. 1 に戻る。

## 残っている課題
- 草の房が多いので、スマホでは数を減らす設定が要る。
- 夜の葉の色はまだ詰めていない。
- 岩が硬い灰色の多面体のまま。見本は明るい灰色に苔がのった柔らかい岩。
