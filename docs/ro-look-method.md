# RO風の背景の作り方（手順書）

この手順書だけで、いまと同じ質の背景が作れるように書いています。経緯は知らなくて構いません。
上から順に読めば作れます。迷ったら「6. 失敗集」と「7. 数値の早見表」を見てください。

## 0. 目指す見た目と、基準になる画面

目指すのは Ragnarok Origin のような画面です。高い角度から望遠で見下ろします。緑は明るく黄みがかり、光はやわらかく、影は黒ではなく暖かい深緑です。地面は筆で描いた絵のように見せ、木は葉っぱの絵を描いた板を重ねて作ります。

外部の画像や3Dモデルは使いません。絵（テクスチャ）は全部コードで canvas に描き、形は three.js のコードで組みます。

基準になる画面は次の2つです。作ったものがこれより見劣りしたら、どこかが手順から外れています。

| 画面 | 開き方 | 何の基準か |
|---|---|---|
| 実験場 RO風 | `npm start` のあと `http://localhost:8091/lab.html?style=ro` | 森・川・橋・コテージのある広い場所。視点と時間帯を切り替えられる |
| 見本の再現 | `http://localhost:8091/ref-forest.html` | 見本の一枚（森の小道の分かれ道）を同じ画角で再現したもの |

## 1. 道具とファイル

three.js r160（`public/vendor/three`）を使います。ブラウザで ES モジュールとして読み込みます。

| ファイル | 中身 |

| `public/js/previews/ro-rock.js` | 岩肌の絵 `rockTexture()`、岩の材質 `roRockMaterial()`、岩の形 `blockGeometry()`・`rockGeometry()`、三方向投影の GLSL `ROCK_GLSL` |
| `public/js/previews/ref-forest.js` | 見本の再現の場面一式。新しい場面を作るときの雛形にする |

**新しい場面は `ref-forest.js` を複製して作るのがいちばん確実です。** レンダラー・光・仕上げ・配置の道具が全部入っています。

## 2. 守ること（これを外すと質が落ちる）

1. 背景にはトゥーン（段の陰影）も輪郭線も使わない。`MeshLambertMaterial` でやわらかく塗る。トゥーンと輪郭線は人物だけに使う。
2. 地面はテクスチャを1枚貼るのではなく、描いた模様を場所ごとに混ぜる。境目は筆でなぞったようにぎざぎざにする。
3. 木は丸いメッシュにしない。葉っぱの絵を描いた小さな板をたくさん重ね、板の法線を茂みの中心から外向きにそろえる。
4. 影は黒くしない。空の光（半球光）を強めにし、その地面側の色を暖かい深緑にする。
5. 画角 30° の望遠で、遠くから約 47〜50° で見下ろす。仕上げに色調補正と、画面の上下のぼかしを掛ける。

## 3. 作り方

### 3.1 レンダラーと仕上げ

`ref-forest.js` の冒頭をそのまま使います。値は次のとおりです。

- レンダラー: `antialias: true`、`setPixelRatio(min(devicePixelRatio, 1.5))`、影は `PCFSoftShadowMap`、トーンマップは `ACESFilmicToneMapping`（露出 1.0）。
- `gradientMap()` の中身を `[150, 188, 222, 255]` にし、フィルターを `LinearFilter` にする。トゥーンの段がなだらかになります（人物は自分用の段を別に持つので影響しません）。
- 仕上げは次の順に掛けます: RenderPass → UnrealBloom（強さ 0.35、半径 0.45、しきい値 0.95）→ OutputPass → 色調補正 → ぼかし。
- 色調補正（ShaderPass）。l は輝度 `dot(c, (0.299, 0.587, 0.114))` です。
  - 彩度: 実験場は 1.06、見本の再現は 0.88（見本の彩度が低いため）
  - コントラスト: 実験場は 1.02、見本の再現は 1.12
  - 暗部の持ち上げ: `c += lift * (1 - l)`。lift は 0.02〜0.03, 0.03, 0.01〜0.02
  - 明部の色: `c *= mix(1, gain, smoothstep(0.2, 0.8, l))`。gain は実験場が (1.07, 1.04, 0.86)、再現が (1.1, 1.03, 0.94)
  - 周辺減光 0.2
- ぼかし（ティルトシフト）: 画面の縦位置 0.48 から ±0.22 はぼかさず、外側を強さ 3.5 で 12 点ぼかします。ミニチュアのような奥行きが出ます。

### 3.2 カメラ

- `PerspectiveCamera` の画角は 30°。50° だとパースが強すぎて MMO の見下ろし画面になりません。
- 見下ろす角度は 47〜50°。55° を超えると真上から見るようになり、木が丸いだけになって幹も横顔も見えません。
- 距離は、人物（背丈 1.7m）が画面の高さの約 12% になるように決めます。見本の再現では距離 23、角度 50° です。実験場の歩く視点は高さ 24.8・後ろ 23.2 です。

### 3.3 光

| | 値 | 理由 |
|---|---|---|
| 半球光（空） | 色 `0xe8f0e0`、強さ 1.3 | 見本は影の中も明るい。空の光が弱いと影が重くなる |
| 半球光（地面側） | `0x5a6a3a`（実験場は `0x3a5634`） | 影を暖かい深緑にする。青緑にすると冷たく見える |
| 太陽 | 色 `0xffe6b8`、強さ 2.3〜2.7 | 暖かい日なた。半球光との比は 2:1 くらいにする |
| 影 | `mapSize` 2048、範囲は場面の幅、`bias -0.0005` | 木漏れ日のまだらが出る細かさ |

太陽の向きは、見本の影の向きから逆算します。影が画面の左やや上へ伸びているなら、太陽は右やや手前です（再現では `sun.position = (32, 23, 8)`）。崖の面に日が当たっているかどうかも合わせて確かめます。日の当たらない向きの崖は暗い灰色の塊に見えます。

### 3.4 地面

地面は細かいグリッド（0.17m 間隔くらい）のメッシュで、高さ関数から作ります。頂点に次の2つを持たせます。

- `splat`: y に土の割合（0〜1）、z に川岸の割合。道からの距離で決め、`(fbm - 0.5) * 1.2〜1.4` のノイズを足して縁を崩します。道の半幅は 0.8〜1.8m です。
- `shade`: 色の掛け算（1 が普通）。木の下は 0.72 まで暗くします（実験場の `roPlants` の最後を参照）。

材質は `MeshLambertMaterial` の `onBeforeCompile` で `#include <map_fragment>` を置き換え、次を順に計算します（`roGroundMaterial()` と `ref-forest.js` の ground を参照）。

1. 草の模様を 2つの縮尺（7m と 19m）で読んで 0.35 で混ぜる（繰り返しを目立たなくする）。
2. 約 20m の大きなむらを掛ける。暗い側 (0.86, 0.92, 0.8)、明るい側 (1.1, 1.08, 0.9)。
3. 土と川岸を `smoothstep(0.35, 0.65, splat + 草の模様のノイズ)` で混ぜる。境目が筆のようにぎざぎざになります。
4. 急な面（法線の y が 0.78 から 0.6 へ下がるところ）は岩肌に替える（`rockTri`）。
5. `shade` を掛ける。

地面の絵（`PAINT`、512px で端がつながる模様）の要点です。

- 草: 地色 `#84b84c`。明暗の丸いむら 70 個の上に、根元が暗く先が明るい草の房を 1700 個（長さ 8〜18px、先の色は `#94c460`〜`#d2e692`）、小花の集まりを 26 個。房が小さいと遠目でただの緑の面になります。
- 土: 地色 `#d2b47c`、むら、踏み固めた明るいすじ 500 本、小石 160 個。
- 見本に合わせて色を寄せるときは、模様ではなく材質の掛け算で寄せます（再現では草に (1.32, 1.02, 0.95)、土に (0.86, 1.0, 0.8)）。

### 3.5 崖と岩

**崖は「地形の急な面」と「その面に張りつけた角ばった岩の塊」の2層で作ります。** どちらか一方だけでは崖に見えません。

1. 地形の高さ関数で、台地の縁に沿ってほぼ垂直に上げます（幅 1.2m で 3.8〜5m）。縁の線までの距離に `(fbm - 0.5) * 1.4` を足して、縁をでこぼこにします。急な面には地面の材質が自動で岩肌を貼ります。
2. `cliffChunks()`（`ref-forest.js`）で、縁の線に沿って 1m ごとに、面を横切る向きに 0.45〜0.8m ずつ進み、その場所の地形の高さに `blockGeometry()` の塊を置きます。大きさは `s = 0.45〜0.8` で、幅 s×1.1〜1.7、高さ s×0.7〜1.2、奥行き s×0.8 です。材質は `roRockMaterial({ flat: true, moss: 0.4 })` を使います。
3. `blockGeometry()` は、箱を 35% だけ球へ寄せ、ランダムな5枚の面で角を斜めに切り落とし、弱いノイズを掛けた形です。平らな面と鋭い角が残るので、割れた岩に見えます。

岩の材質（`roRockMaterial`）は、岩肌の絵を三方向から投影して貼り（4.5m で1回）、上を向いた面に草の模様を苔としてのせます。岩肌の絵は地色 `#cdd2b6` に明暗のむら、層のような横の割れ目と、そこから下りる短い縦の割れ目です。割れ目は濃くしすぎないこと（線が目立つと漫画のペン線に見えます）。

道ばたの小石は `rockGeometry(detail: 1)` を 0.2m 前後で、苔なし（`moss: 0`）にします。苔をのせると緑の円盤に見えます。

### 3.6 植物

植物は全部 `FoliageBuilder` で溜めて、最後に `build()` で種類ごとに1メッシュにします。

```js
const F = new FoliageBuilder(), Rf = seeded(4242);
F.tree(x, y, z, Rf, { size: 1, trunk: 1, leaf: 0xffffff });
F.pine(x, y, z, Rf, { size: 0.9 });
F.cloverBush(x, y, z, Rf, { size: 1 });
F.cycad(x, y, z, Rf, { size: 1.15, trunk: 1.2 });
F.fern(x, y, z, Rf, { size: 0.6 });
F.tuft(x, y, z, Rf, { size: 1, col: new THREE.Color(1.25, 1.12, 0.9) });
scene.add(F.build());
```

葉の材質（`foliageMaterial`、自動で付く）の要点です。自分で作り直すときも次を守ってください。

- `MeshLambertMaterial`、`alphaTest: 0.45`、`side: DoubleSide`、頂点色あり。
- 法線は板の向きではなく、茂みの中心から外向きにする。裏面で法線を反転させない（`normal = normalize(vNormal)`）。こうすると板の集まりが丸い茂みとして光ります。
- 影は `customDepthMaterial` に同じ絵と `alphaTest` を渡す。これで地面に木漏れ日のまだらの影が落ちます。
- 風: 頂点の `swayK`（揺れの強さ）に時間の sin を掛けて揺らす（草 0.12、シダ 0.06、ほか 0.035）。

葉の色は「絵の色 × 頂点色」です。頂点色は 1 を超えてもよく（Float32）、絵そのものより明るくしたいときは 1.3 などを渡します。

| 植物 | 作り方 | 気をつけること |
|---|---|---|
| 広葉樹 `tree` | 幹と2〜4本の枝。枝先ごとに小さな茂み（clump）を3〜4つ寄せる。茂みは星形の葉の絵の板を球状に並べ、内側ほど暗く上ほど明るく塗る | 茂みを丸1つにすると綿あめに見える。小さく寄せて輪郭をでこぼこにし、茂みの間から陰と幹を見せる。幹を見せたいときは `trunk: 1.6` |
| もみ `pine` | 上から見た一段の枝の絵（中心から羽のような枝が放射状）を、水平な大きい板1枚＋外へ垂れる小さい板数枚で一段とし、8段重ねる。上の段ほど小さく明るい | 縦の板で作ると暗いテントになる。幹は高さの 85% で止める（てっぺんから棒が出る） |
| クローバーの茂み `cloverBush` | ハート形の小葉3枚の葉を丸く集めた絵を、低く横に広い茂みに | 茂みは道の脇と木の根元に置く |
| ソテツ `cycad` | 短い幹の先から、専用の葉の絵 `frond`（まっすぐな軸に細い小葉）を描いた細長い板（幅は長さの 0.36）を 12〜15 枚、放射状に | シダの絵を流用したり板を2枚に分けたりすると、幅の広い葉っぱに見える |
| シダ `fern` | 根元から垂れる葉を放射状に | 多すぎると画面がうるさい。崖の下と木の根元に少しだけ（再現では 90 か所試して条件に合うものだけ） |
| 草の房 `tuft` | 十字に組んだ2枚の板 | 多すぎ・大きすぎは毛羽立った画面になる。道の縁に多く、あとはまばら（残す確率 0.02 + 群生ノイズ × 0.1 + 道の縁 × 0.3、大きさ 0.8〜1.6） |

木の下には草の房の色を暗め（0.95, 0.95, 0.8）、日なたは黄みの強い色（1.25, 1.12, 0.9）にします。

### 3.7 影を作る

- 木漏れ日: 3.6 の `customDepthMaterial` で自動的に出ます。
- 大きな木陰: 見本の暗い木陰は、たいてい画面の外の木の影です。**映らない枝葉**を置いて影だけ落とします（`ref-forest.js` の「見えない枝葉」）。材質を clone して `colorWrite = false; depthWrite = false` にし、`castShadow` だけ残します。影を落としたい地面の点 p に対して、枝葉は `p + 高さ × (sun.x / sun.y, 1, sun.z / sun.y)` に置きます。
- 木の下の地面を暗くする: 地面の `shade` を木の半径の 1.15 倍の範囲で最小 0.72 にします。

### 3.8 手前の木を抜く

カメラと注目点（人物）の間にある葉と幹は、点描（4×4 のディザ）で抜きます。`FOLIAGE_U.uOccR` に抜く半径（歩くとき 2.6、決まった視点では 4）を入れます。カメラの近くの木を抜くときは、`uOccNear` にカメラから注目点までの距離の 0.55 倍を入れます。

- 抜く芯は全部消す（`k * 1.2 > しきい値`）。薄い膜が残ると画面全体が汚れて見えます。
- 草とシダは抜かない（視線をさえぎらないのに、抜くと穴が開いて見える）。
- `uOccNear` が 0 のときに `smoothstep(0, 0, d)` を計算しない（未定義になり、葉が全部消える）。

### 3.9 人物

人物は `toon()` と `outline()` のままにし、`gradientMap()` を複製して自分用の段を持たせます（背景用にグラデーションをなだらかにしても、人物はくっきりのまま）。

## 4. 見本の一枚を再現する手順

1. 見本から UI の帯を切り落とす範囲を決める（例: 2556×1179 のスクリーンショットなら `230,0,2326,1179`）。
2. カメラを先に決める（3.2）。
3. 配置は見本の画面上の位置（u: 左0〜右1、v: 上0〜下1）で書きます。`at(u, v, y)` がカメラから光線を投げ、高さ y の面での世界の位置を返します。地形の上に置くときは `onGround(u, v)` を使います（高さを4回詰め直す）。崖の縁・道の中心線も、画面上の折れ線 `line([[u, v], ...])` で書きます。**これで位置と大きさが一回目からほぼ合います。**
4. 撮る:
   ```sh
   PORT=8091 npm start &
   node tools/ro-look/shot.mjs "http://localhost:8091/ref-forest.html" out/ours.png
   python3 tools/ro-look/compare.py 見本.png out/ours.png out/cmp --crop 230,0,2326,1179
   ```
   ページは描き終えたら `window.__ready = true` にしてください（shot.mjs はそれを待ちます）。
5. `out/cmp/overlay.png`（半分ずつ重ねた画像）で位置と大きさのずれを、`side.png` で形と質感を、標準出力の平均色で明るさと色味を比べます。`compare.py` の `REGIONS` は場面に合わせて書き換えます（道・崖・主役の木・茂み・草・全体）。
6. 差が一番大きいものを1つだけ直し、4 に戻ります。同時に複数を変えると、どれが効いたかわからなくなります。
7. 直すときは原因を考えます。「暗い」なら、光が足りないのか、材質の色か、影か。「緑すぎる」なら絵の色か、頂点色か、仕上げか。数値（明るさの比）で確かめます。

目安: 全体の平均色が見本の ±10% 以内、場所ごとの明るさの比が 0.8〜1.2 なら、並べて見て同じ場面に見えます。

## 5. 実験場（lab.html）で確かめる

- `?style=ro` で RO風、`?view=walk|all|forest|river|bridge|lane|cottage`、`?time=day|evening|night`、`?post=0` で仕上げなし。
- 撮るときは `node tools/ro-look/shot.mjs "http://localhost:8091/lab.html?view=walk&style=ro" out/walk.png`。
- 歩く視点・全景・川の夕方の3枚を毎回同じ条件で撮って比べます。

## 6. 失敗集（症状 → 原因 → 直し方）

| 症状 | 原因 | 直し方 |
|---|---|---|
| 木が綿あめ・ブロッコリーに見える | 茂みが丸1つで、輪郭がなめらか | 枝先ごとに小さな茂みを3〜4つ寄せる |
| 葉の板がぺらぺら・裏が暗い | 法線が板の向き。裏面で反転している | 法線を茂みの中心から外向きにし、反転させない |
| もみが暗いテント・ヒトデに見える | 縦の板で作っている | 上から見た枝の段の絵を水平に重ねる |
| 崖がしっくいの壁 | 地形の急な面に岩肌を貼っただけ | 角ばった岩の塊を面に張りつける |
| 崖が座布団・パンケーキの山 | 球を平たくした岩を積んでいる | `blockGeometry`（箱ベース）に替える |
| 岩が草の台に見える | 上面の苔が多い・上面が平ら | 苔 0.3〜0.4。崖用は上を平らにしない |
| 小石が緑の円盤 | 小石にも苔がのっている | 小石は `moss: 0` |
| 画面全体が点描で汚れる | 手前を抜くとき、芯に薄い膜が残る | 芯は全部抜く（`k * 1.2`）。カメラの近くも抜く |
| 葉が全部消える | `smoothstep(0, 0, d)` | `uOccNear > 0` のときだけ計算する |
| シェーダーが「'#' invalid character」で落ちる | 前に足した GLSL の最後に改行がなく、`#define` が行頭にない | 足す GLSL 文字列は改行で終える |
| 崖が逆側にできる・全部台地になる | 折れ線のどちら側か（符号）の取り違え | 線の進む向きと符号を確かめ、低い側・高い側を1点で試す |
| 画面全体が暗い | 半球光が弱く、影が黒い | 半球光 1.3、地面側の色を暖かい深緑に |
| 緑が派手・冷たい | 絵の緑が鮮やか、仕上げの彩度が高い | 彩度 0.88〜1.06、明部を黄みに、草に黄みを掛ける |
| 画面が毛羽立つ | 草の房が多く大きい | 道の縁以外はまばらにし、大きさ 0.8〜1.6 |
| 撮影がタイムアウトする | 板が多すぎて重い | 茂みの板の数を減らす（`14 * r * r + 3` 程度） |
| 見本より木陰が足りない | 画面の外の木の影がない | 映らない枝葉で影だけ落とす |
| 道の脇の色が見本と違う | 見本の道は黄緑がかる | 土に (0.86, 1.0, 0.8) を掛ける |

## 8. 仕上がりのチェックリスト

- [ ] 背景に輪郭線と段の陰影が残っていない
- [ ] 地面の模様の繰り返しが見えない。道の縁がぎざぎざ
- [ ] 木が丸いだけでなく、幹と茂みの間の陰が見える
- [ ] 木漏れ日のまだらの影が地面に落ちている
- [ ] 影が黒くない（暖かい深緑）
- [ ] 崖が割れた岩の塊の集まりに見える
- [ ] 草の房が毛羽立っていない
- [ ] 人物の手前の木が抜けていて、膜が残っていない
- [ ] 見本と並べて、全体の平均色が ±10% 以内

## 9. まだ届いていないこと

- 岩が少し幾何学的。見本は割れ目の陰影がもっと絵画的。
- 茂みの立体感（見本は葉の塊ごとの明暗がはっきりしている）。
- スマホ向けに草の房と葉の板を減らす設定がない。
- 夜の葉の色を詰めていない。
