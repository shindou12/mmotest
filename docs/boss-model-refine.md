# 第2層・第3層ボスの専用モデル

ブランチ：`codex/boss-model-refine`。グラズ改修済みの `codex/graz-model-refine` から分岐しているので、最初の3体すべてに専用モデルがある。

## 霧の大樹 ユグドラ

岩ゴーレムの共有造形から、ねじれた幹・枝の腕・根の脚・緑の樹冠を持つ古木に変更。
木に彫られた顔、光る緑の芯、苔の色面で特徴を出す。
ゆっくり根を踏み替え、予備動作で枝の腕を振り上げる。最も低い根の先が接地するよう幹の高さを補正する。
樹冠と小さな光点には控えめな揺れを付ける。

## 砂塵の大蠍 スコルピオ

翼付き四足獣の共有造形から、重なる砂色の甲殻・8本の脚・2つの鋏・巻き上がった節の尾を持つ巨大蠍に変更。
橙色の目と鋏の印、黒い鋏先と毒針で、背景との見分けを付ける。
脚を交互に持ち上げ、予備動作で鋏を開き、攻撃時に閉じて尾を前へ出す。
尾は6節が親子関係でつながり、毒針は最後の節の先に取り付く。

## ゲームへの組み込み

第2層・第3層のボス定義に `appearance: 'yugdra'` / `'skorpio'` を追加。
グラズと同じ `makeMob()` の外観引数から専用造形を選ぶ。
共有のトゥーン材質・4段階の陰影・法線押し出しの輪郭線を使う。
通常のゴーレム・獣・蠍、他の階層のボスには適用しない。

敵種、サイズ倍率3.0/3.2、HP、ダメージ、攻撃パターン、スタン値、ゲーム進行は変更しない。
描画用の歩行・鋏・尾などは、それぞれの新しい体に合わせて追加した。

通常どおりこのブランチのゲームを起動すれば、第2層・第3層で新モデルが使われる。
比較ページ：

- `http://localhost:8080/boss-refine.html?boss=2`
- `http://localhost:8080/boss-refine.html?boss=3`

比較画面は Root の下に SceneView と TextView を置く。表示パラメータを Presenter が作り、Root を通るイベントは状態機械の Mediator が処理する。

## 検証と素材

- 57件のテストが通過。既存のグラズ、プレイヤーのモーション、武器ツリー、協力プレイを含む。
- 2体それぞれ384状態をブラウザで確認。歩行・予備動作・攻撃・怒り・被弾発光を含む。
- 第2層と第3層で、2人のオンライン接続に同じ専用ボスが表示されることを確認。
- 地面リングを含む三角形数はユグドラ2,740、スコルピオ5,504。輪郭の追加描画は別。
- 各MP4は16秒、1280×720、30fps、H.264、yuv420p。

比較画像と動画はゲームの生成コードと材質を直接描画したもの。
配布GLBは静止ポーズの部品階層で、スキニングやAnimationClipを含まない。
GLBではトゥーン材質を標準PBR材質に変換しているため、別のビューアでは陰影が変わる。
ゲームはGLBを読み込まず、専用生成コードを使用する。
