# 片手剣の追加モデル

確認ページは `/swords-next.html`。初期表示は新モデル2種で、切り替えると現行7形状を並べて輪郭を比べられる。

| モデル | 形の狙い |
|---|---|
| 鬼牙 | 先端が前方へ張り出す一方向の鉤刃。刀の緩い反り、葉形の左右対称、レーヴァテインの波形と輪郭を分ける。 |
| 双星剣 | 細身の刀身が先端で二股に割れ、中央に大きな抜けを作る。結晶翼剣の鍔の翼や通常剣の直線シルエットと形の重心を分ける。 |

鬼牙と双星剣はレアリティ6の固有片手剣として登録済み。固有モデルIDを7・8に割り当て、装備・ドロップ・プレイヤー同期へ接続した。武器名・伝承・モデルを追加し、戦闘効果は付けていない。
