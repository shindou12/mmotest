# 依頼の札の書式（Luna への 1 回の依頼）

`sh tools/agents/luna.sh <この形の .md>` に渡す。規則は `docs/agents/collaboration.md`。下を複製して埋める（`.agents/cards/` に置くと git に入らない）。

```markdown
# <短い題>

## 目的
<何ができるようになれば終わりか。1〜3 行>

## 種類
A（純粋な処理） / B（描画に触れる処理）

## 触ってよいファイル
- <パス>

## 触ってはいけないもの
- docs/world-art/rulebook.md の数値、ほかの地図・生成物（GLB・.blend・art/shots/）、git のコミットとプッシュ
- <この作業に固有のもの>

## 守る約束
- <移植元の関数・規則集の節・README の対応の決まりを名前で。例: public/shared/areas.js の collide と同じ式>

## 完了条件
- <コマンド> → <期待する出力>
- （種類 B）撮影: <コマンド>。比較シート: <コマンド>。数値: <コマンド>。新しい仕組みは値を 2 段変えて画素が変わること

## 返してほしいもの
- 変えたファイルと要点、完了条件のコマンドと結果（生の出力の要所）、画像の保存場所、未解決・気になった点
```
