## 方針（Opus が決めた）
- **表は手で写さない**。武器・技・ツリー・スキル・敵の表は JavaScript から JSON に書き出す（`export_gamedata.mjs` を広げる）。試作の片手剣の武器スキルのクールタイムが、元の ×1.2（`skills.js` SKILL_CD_MULT）を抜かして写されていた。これが手写しの害の実例
- **数値は照合テストで確かめる**: 元の JavaScript で入力と期待値を作り、GDScript の結果と比べる（`tools/worldart/godot/golden_rules.mjs` → `scripts/tests/rules_golden.gd`）。技は `test/golden/skill-trace.mjs` の記録（later・arc・line・circle・proj・dash の呼び出し列）を生の値で書き出して比べる。姿勢は `test/golden/pose-trace.mjs` の行列を生の値で書き出して比べる（許容 1e-4）
- **モデルと動き**: 部品に名前をつけて glTF に書き出し（体・頭・腕・肘・手・脚・マント）、姿勢の関数（`player-motion.js`・`motions/`・`pose-rig.js`）を GDScript に移す。アニメーションの焼き込みはしない（技と武器の組み合わせが多すぎる）
- **音**: WebAudio の合成音を、ヘッドレスの Chromium の OfflineAudioContext で音声ファイルに書き出し、Godot で鳴らす（揺らぎ・間引きは GDScript）
- **見た目の正本はブラウザ版**（トゥーンの 4 段と輪郭線、エフェクト A+B）。比べるときはブラウザ版と同じ場面を撮って並べ、Opus が判断する
- 範囲外: クリスタロスと第 4 層以降（元のゲームも MAX_FLOOR=3 で入れない）、ワールドアートの地図の作り直し、比較・試作のページ（`*-refine.html` など）、タッチ操作（PC 版を先にする。必要ならあとで）
