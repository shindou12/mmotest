# goal（優先から外した）: ワールドマップのプロジェクトを Godot へ完全に移す

> **2026-10-21: ユーザーが目標を「大剣ブランチ全体を Godot へ完全に移す」（`docs/godot/goal.md`）に統一したため、この goal は優先から外した。** 止めた所までの状態は `docs/handoff/2026-10-21-godot.md` の 4。

**目標**: いまの three.js のワールドマップ（`public/worldart/`、地図 12 枚）を、Godot 4（`godot/worldart/`）で同じ見た目・同じ機能で動く状態にする。主要な機能・必要なアセット・実行できる状態まで。
**判断**: 見た目の最終判断は Opus。分担は `docs/agents/collaboration.md`（実装の一部は Sonnet のサブエージェント）。追加の従量課金・API キーは使わない。

## 完了の条件
1. 12 枚の地図すべてが Godot で開け、エラーなく描ける（`sh tools/worldart/godot/run.sh` の撮影が通る）。
2. 地図ごとの基準ビュー（views があればその全部、なければ地図のカメラ）で、three.js と Godot の数値が近い: 輝度の平均の差 ≤ 0.03、彩度の平均の差 ≤ 0.04、明暗比の差 ≤ 0.25（手前を抜く処理と影の方式の違いによる差は記録して許す）。
3. Opus が比較シートを見て、見た目の破綻（色・明暗・材質の取り違え・物の欠け・水・空の失敗）がないと判断する。
4. Godot のエディタで開いて F6（地図を見る）・F5（ゲームの試作）が動く。地図とビューを画面から選べる。
5. 手順と未解決が文書（この goal・`godot/worldart/README.md`・`docs/world-art/pipeline.md`）にある。

## 調査（2026-10-21）: 移植元と Godot の差
| 機能 | three.js（world.js） | Godot（開始時） |
|---|---|---|
| 地図 | 12 枚（すべて組み立て済み） | f1_field だけ書き出し済み |
| 階調 | linear（第 3 世代 7 枚）・aces（第 2 世代 5 枚） | linear だけ |
| 仕上げ | 露出・彩度・コントラスト・lift・gain・上下のぼかし・もや・周辺減光・上の暗がり | 露出・彩度・上下のぼかし |
| 水 | 高さマップから深さ・浅瀬と深みの色・岸の泡・寄せる波（orc_meadow・south_coast と _g3）。地面は水際を濡れた色に | なし |
| 葉 | wrap・lift（日陰の持ち上げ）・trans（透け）・影を受けない（第 2 世代）・葉の色味 | wrap・葉の色味だけ。影はいつも受ける |
| 地面 | alt（砂・石畳・敷石）・岩（face・crack・rock）・rockPix の有無 | 同じ式（alt・岩の種類は地図から） |
| MSAA | 地図ごと（第 2 世代はなし・alphaTest 0.5） | いつも 4x |
| ビュー | views・区画・ビューごとの光の上書き（B03・B04）・標準ビュー | views の位置だけ（光の上書き・標準ビューなし） |
| 影 | VSM 半径 6（第 3 世代）・PCF ソフト（第 2 世代）、影だけ落とす木 | Godot の平行光の影。影だけの木は対応済み |
| 選ぶ画面 | URL の `map=`・`view=` | シーンの map_name を手で変える |

## 進め方
1. 道具: 全地図の書き出し（`export_godot.py` を全地図に）と、three.js と Godot の一括の比較（`tools/worldart/godot/port_check.py`）。→ Sonnet のサブエージェントに（種類 A）
2. 描画の中心（Opus）: 階調 ACES、仕上げの残り、葉の lift・trans・影を受けない、MSAA の地図ごとの切り替え、ビューの光の上書き・標準ビュー
3. 水（種類 B）: world.js の waterMaterial と同じ式。→ Sonnet のサブエージェントに、Opus が画像で判断
4. 地図とビューを選ぶ画面（種類 A）→ Sonnet のサブエージェントに
5. 全地図を撮って比べ、差の大きい所から直す（Opus）。結果をこの文書へ

## 経過
- 2026-10-21: 全地図を Godot へ書き出し（コミットはしていない、作り直せる）。階調 ACES・仕上げの残り・葉の lift と trans と影を受けない・水際の濡れ・MSAA の閾値・ビューの光の上書き・標準ビュー・地図の選択（main.gd・viewer_menu.gd）を実装したが、画面での確認の前に止めた（south_coast の撮影が 600 秒で終わらない。原因は未調査）。水面（scripts/water.gd）と比較の道具（port_check.py）は未完成
