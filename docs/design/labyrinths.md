# 迷宮区の作り直し（1〜3層）

> ステータス：立案・自己評価済み（2026-10-15）。要望：規模を大きく、敵を単体で強く、迷路感は減らす。

## 目指す体験
ダクソの「銀騎士がいる通路」のように、**1体ずつが手強い敵** と、**まとわりつく雑魚** をさばきながら、
広い部屋を一つずつ制圧して奥（ボス部屋）へ進む。道に迷う楽しさではなく、**戦う場所を選ぶ楽しさ**。

## 1. 形：広い部屋＋太い通路
| | 今 | 作り直し |
|---|---|---|
| 大きさ | 23 × 22 マス（迷路部分） | **31 × 40 マス**（約1.7倍の面積、道のりは約2倍） |
| 形 | 幅1マスの曲がりくねった迷路 | 6〜12マス四方の **部屋** を、幅 **3〜4マス** の通路でつなぐ |
| 迷いやすさ | 行き止まりが多い | 分かれ道は「寄り道の部屋」へ1〜2本だけ。本道は見ればわかる |

各層のギミックはそのまま残す。
- 1層：寄り道の部屋の奥の **レバー** で扉が開く（レバーの部屋は近衛兵が守る）
- 2層：交互に作動する **罠床の通路** を抜け、扉の前の **門番** を倒す
- 3層：左右に離れた2つの **感圧板** を50秒以内に踏む（手分け）

## 2. 敵
### 精鋭「番兵」（新しい強い敵）
層ごとに見た目と名前が違う、騎士型の精鋭。1部屋に1〜2体。
| 層 | 名前 | 見た目 |
|---|---|---|
| 1層 | コボルドの近衛兵 | 茶色の鎧（グラズの手下） |
| 2層 | 苔むした番兵 | 苔の緑 |
| 3層 | 砂漠の処刑人 | 砂色 |

動き（銀騎士の手触り）：
- **盾で守る**：正面からの攻撃は大きく減る（3割しか通らない）。当てると火花と金属音。
- **3連斬り**：正面に扇を3回。避ける／盾で受ける。
- **踏み込み突き**：離れていると、直線の予兆のあと一気に詰めてくる。
- **攻撃の後の隙**：攻撃を出し切った直後の約1.2秒は盾が下がる → ここを狙う、または背後に回る。
- 体力は普通の精鋭よりさらに多い。倒すと装備が出やすい（既存の精鋭と同じ扱い）。

### まとわりつく雑魚「群れ」
- 足の速い敵（1層：コウモリ／2層：ウィスプ／3層：サソリ）が **3体まとめて** 湧く。1体ずつは弱い（体力4割）。
- 番兵と同時に相手にすると厄介、という配置にする（部屋の入口側に群れ、奥に番兵）。

### 普通の雑魚も少し強く
- 迷宮区の敵のレベルを +2、体力を 1.3 倍。

## 3. 立案：比べた案
| 案 | 中身 | 評価 |
|---|---|---|
| **A. 部屋と太い通路＋番兵＋群れ**（採用） | 上のとおり | 要望（規模・単体の強さ・迷路感を減らす）にそのまま応える。既存のギミックも置ける |
| B. 一本道の長い回廊 | 部屋なしで、番兵が並ぶ長い通路 | 迷わないが単調。群れを避ける場所がなく、ただの消耗戦になる |
| C. 自動生成の部屋 | 毎回違う部屋の並び | 100層構想には合うが、ギミック（レバー・感圧板）の置き場が保証しにくい。今回は手作り、仕組みは後で |

## 4. 自己評価（採用案 A）
| 観点 | 評価 | 理由・対策 |
|---|---|---|
| 規模 | ◎ | 面積約1.7倍、入口から扉まで道のり約2倍 |
| 敵の単体の強さ | ◎ | 番兵は「盾＋連撃＋隙」の読み合いがあり、1体で緊張感が出る。体力だけ多い敵にはしない |
| 迷路感を減らす | ○ | 本道は太く見通しがよい。寄り道は宝箱・レバーなど目的があるものだけ |
| 協力の意味 | ○ | 1人が番兵の正面で盾を引きつけ、もう1人が背後を取る、が自然に生まれる |
| ボス戦との差 | ○ | ボスは「予兆を読む」、番兵は「隙を読む」。違う種類の手応え |
| 文章で説明しない | ○ | 盾で弾かれたら火花と金属音だけ。隙は盾が下がる動き（姿勢）で見せる |
| 工数 | △ | 新しい敵の動き（盾・連撃・突進）とマップ3つ。マップは部屋と通路を並べる道具で作り、到達できるかを自動テストで確かめる |
| 性能 | ○ | 壁はまとめて1つのメッシュに描くので、マップが広くても重くなりにくい |

**懸念と対策**
- 盾の判定はサーバー側：画面に先に出るダメージの数字と、実際に減る量がずれる → 盾で弾いたときは火花を出し、数字の代わりに「弾かれた」ことがわかるようにする。
- 番兵が強すぎて詰まる → 攻撃の後の隙を長めにし、背後からは盾が効かない。
- マップが長くなりすぎる → 入口近くと中ほどに休める小部屋（敵なし）を置く。
