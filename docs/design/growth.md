# キャラクターの成長（レベル・キャラツリー）を完結させる

> ステータス：立案・自己評価済み（2026-10-16）。合意待ち。

## 1. 今の仕組み
| 部分 | 中身 |
|---|---|
| レベル | 1〜50。上がるたびに攻撃力・HPの基礎が ×1.065、スキルポイント（SP）+1。今の中身（3層・最後のボスはLv24）で届くのは Lv25〜30 くらい |
| キャラツリー：ステータス | 8項目・合計36ポイント。攻撃力 +3%、会心率 +2% など、数字が増えるだけ |
| キャラツリー：プレイスタイル | 3列（回避・守護・攻撃）×4段・合計26ポイント。3段目に共通のスキル（残像・ウォークライ・バーサク） |
| 武器ツリー | 武器ごと。その武器で戦うと熟練度が上がる（最大20）。武器の技・クラス・マスター |

## 2. 困っていること
1. **ゴールがない**：上限の Lv50 には届かず、意味もない。「育ち切った」と感じる地点がない。
2. **ビルドの決め手がない**：プレイスタイルの一番上の段（カウンター・不屈・背水）が控えめで、
   「短剣×攻撃速度×吸血」のような組み合わせを、キャラツリー側から後押しするものがない。
3. **ステータスは振るだけ**：数字の積み増しなので、選ぶ楽しさが薄い（これは受け皿としては悪くない）。

## 3. 案
| 案 | 中身 | 評価 |
|---|---|---|
| **A. 完成形を決める＋奥義**（採用） | 下の4つ。今のツリーはそのまま残し、上に「奥義」を足して、上限を中身に合わせる | 工数が小さく、今のセーブとビルドを壊さない。「育ち切った」と「ビルドの決め手」の両方に効く |
| B. 1枚の大きなツリーに作り直す | ステータスとプレイスタイルを星座のような1枚にまとめ、道を選んで進む | 見た目は楽しいが大工事。今のビルドが全部やり直しになる |
| C. Lv10・20・30で職業を選ぶ | 職業ごとに能力が付く | 武器ツリーのクラス・マスターと役割がかぶる |

### 採用案 A の中身
1. **レベル上限を中身に合わせる：Lv30**
   - 上限 = 最上層の基準レベル + 13（今は 17 + 13 = 30）。層が増えたら自動で上がる。
   - Lv30 で SP は 29。ステータス（36）とプレイスタイル（26）を全部は取れない＝選ぶ必要がある。
   - 上限に着いた後の経験値は、ゴールドに変わる（経験値が無駄にならない）。
2. **プレイスタイルの最上段に「奥義」を3つ（1つだけ選べる）**
   - 条件：プレイスタイルに10ポイント以上振ってから。1ポイント。ほかの奥義を取っていると取れない（振り直せば替えられる）。
   - ルールを変える強い効果で、ビルドの方向を決める：

   | 列 | 奥義 | 効果 | 後押しするビルド |
   |---|---|---|---|
   | 回避（ダンサー） | 流水 | JUST回避のあと、次の3回の攻撃が必ず会心 | 会心・回避 |
   | 守護（ガーディアン） | 不動 | 被ダメージ -10%。ダメージを受けると、受けた量の30%を次の攻撃に上乗せ | 盾槍・重い武器・タンク |
   | 攻撃（バーサーカー） | 血の宴 | 攻撃速度の上昇分（%）だけ、HP吸収が上がる（攻撃速度+20%なら吸収+20%＝1.2倍） | 攻撃速度×吸血（短剣など） |

3. **ステータスは受け皿のまま**：中身は変えない。奥義を取ったあとの残りポイントの行き先。
4. **成長の完了を見せる**：Lv30 でレベルの欄に「MAX」、経験値バーは金色。キャラツリーの上に「残りSP」と「奥義」の欄。

## 4. 自己評価（採用案 A）
| 観点 | 評価 | 理由・対策 |
|---|---|---|
| 育ち切った感 | ◎ | 上限が中身と一致し、Lv30・奥義・MAX表示で「完成」が見える |
| ビルドの決め手 | ○ | 奥義3つが3列それぞれの方向を強める。友人の「短剣×攻撃速度×吸血」は「血の宴」でさらに伸びる |
| 選ぶ楽しさ | ○ | SP 29 に対して 62＋1 ポイントの行き先がある。奥義は1つだけ |
| 武器ツリーとの役割分担 | ○ | キャラツリー＝全武器に共通するビルドの方向、武器ツリー＝その武器の技、で分かれる |
| 今のセーブ | ◎ | ノードを足すだけ。Lv30 を超えているキャラはいない想定（いても上限で止めるだけ。SPは減らさない） |
| 協力プレイの釣り合い | △ | 奥義は強いので、ボスの体力・攻撃の調整が要るかもしれない → まず入れて遊んでから数字で直す |
| 工数 | ○ | ノード3つ・上限の計算・表示の小さな変更 |

**懸念と対策**
- 奥義が強すぎてほかの列が死ぬ → 3つとも「条件付き」の強さにする（JUST回避のあと／被弾のあと／攻撃速度を上げたとき）。
- 上限で経験値がゴールドになると稼ぎ場所が偏る → 変換率は低め（経験値の10%）。
