# クラスツリー（武器ツリー）の評価：生存力を入れて

> ステータス：評価（2026-10-16）。数値の変更はまだしていない。基準は 3層のボス戦（Lv24・プレイヤーの最大HP 約700・ボスの基本威力 436）。

## 1. 生存力の物差し
| 物差し | 中身 | 目安 |
|---|---|---|
| 軽減 | 受けるダメージが何割になるか | 0.5 で「HPが2倍になったのと同じ」 |
| 回復 | 1秒あたり最大HPの何%を回復できるか | 3%/秒 で、ふつうの被弾をほぼ打ち消す |
| 無敵 | 戦っている時間のうち、無敵でいられる割合 | 30% を超えると「避けるゲーム」でなくなる |
| 保険 | 倒れるはずの一撃を耐える回数 | 1分に1回まで |
| 条件の重さ | 効果を出すのに何が要るか（タイミング・位置・クールタイム） | 条件が軽いほど強い |

## 2. 被ダメージの計算（今のしくみ）
```
受けるダメージ = 元のダメージ × (1 − 被ダメ軽減[上限65%]) × (1 − 一時的な軽減[上限90%])
```
- 被ダメ軽減（防御）: 装備の特性（1つ最大 9%）・防具の基本値・キャラツリー（鉄の肌 最大10%、頑強 最大9%）・生存本能 8%・武器の重さ・不撓/鉄壁の心得 最大10%
- 一時的な軽減（足し算）: ウォークライ 40%・鉄壁の構え 60%・挑発 30〜40%・迎撃の構え 35〜60%・旗手 20%・受け流し・一撃（溜め中 30%）・称号（古代の守護 8%・甲殻の守り 12%）・特性「守護」 など
- 2つの段は **掛け算** なので、両方を上限まで積むと **0.35 × 0.10 = 3.5%**（HPが約29倍と同じ）
- 盾のガードは正面なら、さらに ×0.25

## 4. 強すぎるもの（優先度の高い順）

### 問題 1：回避の連打で、ずっと無敵（最優先）
- 回避の無敵 0.32秒（軽身 +0.2秒、身のこなしB +0.1秒）。回避の待ち時間 = 0.75秒 × 重さの係数（軽量 0.7）×（1 − 短縮%、上限60%）。
- 軽量で短縮60%なら待ち時間 **0.21秒 < 無敵 0.32秒** → 連打すれば無敵が途切れない。
- 短縮60% はキャラツリーの「軽業」3ポイント（36%）＋短剣「身軽」（25%）で届く。片手剣も「軽業」＋「早足」（20%）＋軽身でほぼ届く。
- 攻撃はできないが、ボスの大技・刻印・砂嵐をすべて「待つだけ」でやり過ごせる。
- 対策案：**無敵時間より待ち時間を必ず長くする**（待ち時間の下限 = 無敵時間 + 0.15秒）。または短縮の上限を 60% → 35%。

### 問題 2：HP吸収に上限がなく、継続ダメージ・範囲・攻撃の速さで増える
- 吸収 = 与えたダメージ × 吸収% × 0.55。**1秒あたりの上限がない**。
- 毒・出血の継続ダメージにも効き、範囲攻撃は当たった敵の数だけ効く。
- 吸収% の出どころ: 装備の特性（1つ最大 5%）・固有の効果「吸収」4%（村正・月詠ノ小太刀・ダーインスレイヴ・ミョルニル）・キャラツリー「血の渇望」最大 3%・竜革の鎧 1%・大斧「血の心得」3%（HP半分以下で2倍）・ブラッドラスト 8%・狂剣士 最大 10%。
- 試算（短剣・Lv24・攻撃力 約100・連撃と特性で攻撃の速さ +50%・会心込み）: ボスへの与ダメ 約500/秒。吸収 20% なら **約55 HP/秒（最大HPの約8%/秒）**。ボスの攻撃を半分ほど受けても、回復のほうが上回る。雑魚の群れ（範囲・毒）なら上限なく回復する。
- 友人の「短剣・攻撃速度・吸収」ビルドが楽しかったのは、ほぼこれのおかげ。**楽しさの源でもある**ので、消すのではなく天井を付けるのがよい。
- 対策案：**吸収の回復に1秒あたりの上限**（最大HPの 3%/秒）。継続ダメージは吸収の対象外（または半分）。範囲は1振りにつき最初の3体まで。

### 問題 3：軽減の2段が掛け算で、合わせて 3.5% まで下がる
- 防御（上限65%）× 一時的な軽減（上限90%）。盾槍は「迎撃の構えB 60% ＋ 挑発 40%」だけで90%に届き、旗手やウォークライでさらに余る。
- 防御65% のときに一時的な軽減90% が乗ると、ボスの一撃（約350）が **約12** になる。タンク役としては楽しいが、ボスの大技・頭割りが意味を失う。
- 対策案：**一時的な軽減の上限を 90% → 60%**。または2段を足し算で合わせて上限 75%。

### 問題 4：聖騎士（片手剣のマスター）は、受けるとHPが増えることがある（中）
- ガードで受けると最大HPの 5%（約35）回復。**1.5秒に1回まで**（毎秒 最大HPの約3.3%）。
- ガード（×0.25）×防御 65% で、ボスの小技（約350）は **約30** になり、回復（約35）のほうが多い。受けるたびにわずかに増える。
- ただし1.5秒に1回までなので、続けて受けると減っていく。ガードゲージも減る。**単体では許容範囲**。問題 3（軽減の重ね掛け）を直せば自然に収まる。
- 対策案（必要なら）：回復量を「ガードで減らした分の 30%」にする（受けた攻撃が弱いほど回復も少ない）。

### 問題 5：カウンター（大剣のクラス）は待ち時間のない無傷
- 強攻撃を押した直後 0.35秒に受けると無傷＋反撃350%。強攻撃は何度でも押せるので、タイミングさえ合えば毎回無傷。
- JUST回避（回避の待ち時間がある）より条件が軽い。明鏡（+30%）・居合と合わせると火力も上がる。
- 対策案：受け流しのあと 1.5秒は次の受け流しが出ない。または受け流し後の強攻撃を強制で出す（動きを固定して代償にする）。

### 問題 6：倒れない保険が重なる
- 大斧「不死身」（60秒に1回・2秒無敵）、キャラツリー「不屈」（90秒に1回）、アイギス系の「25%で無効化」、這いずりからの復帰。
- 不死身と不屈を両方持つと、1分半に2回は倒れない。単体ならよいが重なると、ボスの「初見半殺し」や砂嵐が効かない。
- 対策案：保険（HP1で耐える）は1つしか効かない（両方持っていても早いほう1つ）。

### 対応済み：ガードゲージの戻りと構え直しの隙（武器ごと）

遊んでの実感「ガードとカウンターで死ぬ気がしない」への最初の手当て。受けたときの軽減（×0.25）は変えず、**ゲージの戻り**と**構え直しの隙**で締めた。数値は `game/input.js` の `GUARD_BY`。

| | 盾槍 | 守護騎士（片手剣） | 前 |
|---|---|---|---|
| ゲージの減り | ×1 | ×1.3 | ×1 |
| 回復が始まるまで | 1.6秒 | 2.2秒 | 1.0秒 |
| 毎秒の回復 | 20 | 13 | 34 |
| 構えてから効くまで | 0.06秒 | 0.12秒 | 0 |
| 解いてから構え直せるまで | 0.3秒 | 0.55秒 | 0 |
| カウンター後に構え直せるまで | 0.7秒 | 1.0秒 | 0 |

- 回復の待ちは「最後に受けた」か「ガードを解いた」の遅いほうから数える（細かく構え直してもゲージは戻らない）。
- 盾槍だけ、ツリーで締め具合を選べる: 盾の心得（減り -20/-35%）、盾の心得A 立て直し（回復 +60%・待ち半分）、鉄壁A 不動（構え直し半分）、反撃の心得A 反撃の守り（カウンター後も普通の構え直し）、騎士（カウンターでゲージ +20）、挑発A 威圧（効果中は減らない）。

### 問題 7：足元の円の攻撃は、向きに関係なくガードできてしまう
- ガードは「攻撃してきた方向が正面なら軽減」だが、攻撃の出どころが分からない円（頭割り・離れる印・砂の雨など、足元に出る円）は **円の中心を出どころとみなし、中心が自分の足元なら必ずガード扱い** になる。
- そのため、盾槍は **頭割りを1人で受けても 1/4、離れる印も 1/4** にでき、仲間と集まる・離れる理由がなくなる。
- 対策案：足元に出る円（出どころのない攻撃）はガードの対象外にする。または頭割り・離れる印だけはガードできないようにする。

### 問題 8：ガードが攻撃の形を見ず「ボスの方向」だけで決まる（最優先・遊んでの実感「死ぬ気がしない」の主な原因）
- ガードは、攻撃の出どころ（ボス）が正面 ±80°（160°の扇）にあれば効く。**攻撃の形（足元の円・輪・部屋全体）は見ていない**。
- そのため、ボスを向いて構えているだけで、避けるはずの攻撃も **1/4** になる：叩きつけ・砂の雨（足元の円）、輪、潜行の飛び出し、大砂嵐（部屋全体）。吹き飛ばしの大技もガード中は吹き飛ばされない。
- ガードゲージは「元のダメージ ÷ 最大HP × 120」減る（ボスの一撃で60〜80、盾の心得で -35%）。ガードをやめて1秒後から毎秒34戻る（約3秒で満タン）。ガードカウンターで構えを解くたびに戻り始めるので、受ける→反撃→戻る、で回り続ける。減り方が最大HP比なので、HPを積むほどガードも固くなる。
- ガードごとにゲージが回復する処理はない。
- 対策案：
  1. **ガードできるのは正面から来る攻撃（直線・扇・突進・弾）だけ**。足元の円・輪はガードしても半分、部屋全体はガード不可。問題 7 もこれで直る。
  2. ゲージの戻りを遅く（待ち 1秒→2秒、毎秒 34→20）。
  3. ゲージの減り方を最大HPから切り離す（ボスの基本威力に対する比率で減らす）。

## 5. 問題になっていないもの（参考）
- ポーション（最大 3＋2、30%、待ち時間8秒）: 1分で約2本分。妥当。
- （訂正）盾のガードは問題 8 のとおり、形を見ないために強すぎる。ゲージの仕組み自体は妥当。
- 竜騎士の空中無敵: 強攻撃の溜めが要るので連打できない。
- 捨て身・狂剣士の「被ダメ増」: 代償として機能している。

## 6. 進め方の提案
1. 問題 1（回避の連打）と問題 3（軽減の上限）は、ほかのすべてのビルドの土台なので先に直す。
2. 問題 2（吸収）は「上限を付ける」だけにして、楽しさは残す。友人のビルドで遊んでもらって数字を詰める。
3. 問題 4〜7 は、それぞれ1か所の変更で済む。問題 7 は頭割り・離れる印の意味に関わるので、1・3 と同じくらい優先度が高い。
4. 問題 8（ガードが形を見ない）は遊んだ実感に直結しているので最優先。対策 1 で問題 7 も一緒に直る。
