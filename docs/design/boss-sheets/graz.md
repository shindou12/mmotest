# ボス定義：コボルド王 グラズ（1層）

> ステータス：合意済み（2026-10-15）。方針は「工数の少ない実装」。

## 流れ（HPバー3本）
| 場面 | 内容 |
|---|---|
| 登場 | **大剣投げ**：正面に直線の予兆 → 吹き飛ばし。ダメージは中くらい（そこまで大きくない） |
| 1本目 | 通常技 |
| 1本目が割れる | **詠唱「近衛兵召集」**（約4秒）。詠唱中に一定ダメージを与えると中断してスタン（DPSチェック）。間に合わなければ雑魚3体 |
| 2本目 | 通常技＋大技「王の裁き」 |
| 2本目が割れる | **暴走**：大剣を振り回す大振りをくり返す。毎回大きな隙。簡単だけどミスると大ダメージ |
| 3本目 | 暴走のまま撃破まで（王の裁き・突進も使う） |

## 常に働く癖：弱った者を狙う
- 誰かのHPが **3割未満** になると、その人にターゲットを切り替える（10秒に1回まで）。
- 切り替えた瞬間に **走って近づく**（ダメージなし）。
- 合図は全ボス共通の「！」マーク（このボス専用の演出はなし）。
- タンクは盾槍の **挑発** で取り返せる。

## 技
| 技 | 中身 | 使う場面 |
|---|---|---|
| 叩きつけ | 狙った相手の足元に円 | 1・2本目 |
| 薙ぎ払い | 正面に扇 | 1・2本目 |
| 突進 | 直線の予兆 → 突進。盾槍のガードで止まる | 全部 |
| 3連斬り | 追いかけてくる連続の円 | 1・2本目 |
| ブレス | 予備動作のあと、扇状に弾を飛ばす | 1・2本目 |
| **王の裁き**（大技・名前表示） | 弱っている人へ、ゆっくり向きを合わせながら溜める → 極太の直線衝撃波。範囲外へ逃げる。吹き飛ばし・大ダメージ | 2・3本目 |
| 暴走・回転斬り | 自分の周りを大剣で一周。大ダメージ → 大きな隙 | 3本目 |
| 暴走・叩き斬り | 正面の広い扇。大ダメージ → 大きな隙 | 3本目 |

外したもの：弾幕・地割れ・今の激昂（65%）／最終形態（35%）／ultimate（グラズのみ。他のボスは今のまま）

## 共通の部品として作るもの（他のボスでも使う）
- HPバー複数本と、バーが割れたときの出来事
- 詠唱バー（名前表示・中断ゲージ）
- ターゲット変更の「！」マーク
- ボスごとの行動ロジックの登録（`brain`）
