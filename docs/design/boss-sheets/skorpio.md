# ボス定義：砂塵の大蠍 スコルピオ（3層・最後のボス）

> ステータス：立案・自己評価済み（2026-10-15）。グラズ・ユグドラと同じ方針（基本ルール＋1体1つの大きな裏切り＋文章で説明しない）。**頭割りを必ず入れる。**

## 0. ひとことで
- 何者か：砂の下を泳ぐ大蠍。迷宮区の奥の、細長い砂の回廊に棲む。
- **なにこれ！？**：部屋に入っても誰もいない。砂の盛り上がりがこちらへ走ってきて、足元から飛び出してくる。部屋は細長く、逃げても逃げても追ってくる。
- **なるほど？！**：頭上に黄色い輪が出た人のところへ **みんなで集まると、痛みが分け合える**。最後は輪が2つ、順番に来る → 集まったまま次の輪へ **一緒に走る**。

## 1. ステージ：砂の回廊（形を変える）
今までのボス部屋は 44m × 36m の長方形（グラズ）と十字（ユグドラ）。スコルピオは **縦に細長い回廊**。

```
#####.....#####   ← 奥（北）
#####.....#####
#####.....#####      幅5マス = 20m
#####.....#####      長さ17マス = 68m
#####..B..#####   ← 大蠍は奥寄りに潜っている
#####.....#####
  …（同じ幅で続く）
#####.....#####
#######D#######   ← 扉（南）＝入口
```
- 形に意味を持たせる：
  - 左右に逃げ場が少ない → 突進・尾の突きは「横へ」かわす。
  - 縦に長い → 潜って追ってくる大蠍から「回廊を走って」逃げられる。
  - 細い → 頭割りで集まりやすいが、集まった塊ごと狙われる。
- 迷宮区（3層）の上のボス部屋を、この回廊に差し替える（迷宮区の迷路部分はそのまま。地図は上に伸びる）。

## 2. 戦いの流れ（HPバー3本）
| 場面 | 起きること | 体験として何を学ぶか |
|---|---|---|
| 登場 | 部屋は空っぽ。奥から砂の盛り上がりが走ってきて、先頭の人の足元で **飛び出す**（円の予兆→吹き飛ばし。痛いが死なない） | ボスは地中にいる／追ってくる |
| 1本目 | 基本の技（鋏・尾の突き・突進・砂の雨）＋**毒針の刻印**（頭割り） | 黄色い輪に集まると軽くなる |
| 1本目が割れる | **潜行**：砂に潜り、盛り上がりが狙った人を追いかけ、最後に飛び出す | 回廊を走って逃げる。盛り上がりの通った後は安全 |
| 2本目 | 1本目の技＋潜行 | （新しいことは潜行の1つだけ） |
| 2本目が割れる | 怒り。**連なる刻印**：黄色い輪が2人に付き、順番に弾ける | 集まったまま、次の輪の人のところへ一緒に走る |
| 3本目 | 連なる刻印＋潜行＋基本の技 | （新しいことは増やさない） |

## 3. 技
| 技 | 中身 | 予兆 | 威力 |
|---|---|---|---|
| 鋏の挟み撃ち | 正面の扇 | 扇 | 中 |
| 尾の一突き | 狙った人へ、細く長い直線。溜め短め | 直線 | 中 |
| 突進 | 回廊の縦方向に一直線に突っ込む（回廊が細いので横へかわす）。盾槍のガードで止まる | 太い直線 | 大・吹き飛ばし |
| 砂の雨 | 全員の足元に小さな円（全ボス共通の技） | 円 | 小 |
| **毒針の刻印**（頭割り・名前表示） | 1人の頭上に **黄色い輪**。足元の黄色い円がその人に付いてまわり、約5秒で縮み切って弾ける。円の中にいる人数で **ダメージを割る**（1人なら重い、3人なら軽い） | 黄色い輪（頭上）＋縮む黄色い円（足元） | 合計で特大（人数で割る） |
| 潜行（1本目が割れてから） | 砂に潜って姿を消す（その間は攻撃が当たらない）。盛り上がり（小さな円が続く）が狙った人を約4秒追いかけ、最後に飛び出す | 盛り上がり＝連続する小さな円、飛び出す所は大きな円 | 大・吹き飛ばし |
| **連なる刻印**（2本目が割れてから・名前表示） | 黄色い輪が **2人**（なるべく離れた2人）に付く。縮む速さが違い、先に縮み切った方から順に弾ける（間は約2秒） | 黄色い輪×2。足元の円の縮み具合で順番がわかる | 各回、合計で特大（人数で割る） |

## 4. 共通の部品として作るもの：頭割り（集まる）
- 予兆の色と形は全ボス共通のルールどおり：**黄色の輪（誰かの頭上）＝集まる**。
- 足元の円は「ゆっくり縮む＝時限（縮み切ったら発動）」（boss-ideas.md の B の文法）。
- 弾けた瞬間に **サーバーが** 円の中の人数を数え、合計ダメージを人数で割って配る（画面ごとに数えると、人によって人数が食い違うため）。
- 音：付いたときに鐘の音（集まる＝鐘）。文章は出さない。
- 他のボスでも使えるように、ボスの共通部品（`sim/boss.js`）に置く。

## 6. 立案：比べた案
| 案 | 中身 | 評価 |
|---|---|---|
| **A. 砂の回廊＋毒針の刻印（頭割り）＋潜行**（採用） | 上のとおり | 形に意味がある（細長い＝横にかわす・走って逃げる・集まりやすい）。頭割りが戦いの中心で、3本目で「集まって一緒に動く」に育つ |
| B. すり鉢の流砂 | 円形の部屋の中心へ砂が流れ、外へ歩き続けないと引き込まれる。頭割りもある | 「引き込まれながら集まる」が忙しすぎる。引き込みの物理と見た目の作り込みが重い |
| C. 尾の部位破壊 | 尾を壊すと毒の技が消える。頭割りもある | 部位ごとの当たり判定が新しく要る。頭割りが脇役になり、要望（頭割りを必ず）の重みが薄れる |

3本目の案も比べた：
| 案 | 評価 |
|---|---|
| **輪2つを順番に**（採用） | 「集まる」を「集まって一緒に走る」に伸ばすだけ。新しい色・形は要らない。順番は縮み具合で見える |
| 輪2つを同時に（二手に分かれる） | 重ねると得をしてしまう（3人なら全員で両方受けた方が軽い）。防ぐには「重ねると痛い」別ルールが要り、ややこしい |
| 頭割り＋散会（青い輪）を同時に | 協力らしいが、最後に新しい色の意味が増える。1つずつ覚える方針に反する |

## 7. 自己評価（採用案 A）
| 観点 | 評価 | 理由・対策 |
|---|---|---|
| 前の2体との違い | ◎ | グラズ＝人を追う剣士、ユグドラ＝動かず場所を襲う。スコルピオ＝**地中から追ってくる**＋**みんなで集まる**。避け方が「位置取り」から「隊列（まとまって動く）」に変わる |
| ステージの形の意味 | ◎ | 細長い回廊が、突進の向き・潜行から逃げる道・集まりやすさの3役を持つ |
| 頭割り | ◎ | 1本目から出し、3本目で育てる。戦いの中心になっている |
| ややこしさ | ○ | 新しい考えは3つ（集まる／潜って追ってくる／輪が2つ順番に）。バーごとに1つずつ |
| 文章なしで伝わるか | ○ | 黄色＝集まるは共通のルール。人数で軽くなるのは「受けたダメージの数字」で体感できる。順番は円の縮み具合で見える |
| 協力の意味 | ◎ | 集まらないと重い、という協力の理由が一番はっきりしたボス |
| 理不尽さ | ○ | 刻印は約5秒あり、細い回廊なので集まりやすい。潜行の盛り上がりは足が遅めで、走れば振り切れる |
| 最後のボスらしさ | ○ | 演出を盛らず、仕組みの「集大成」で見せる（集まる・かわす・走る、を全部使う） |
| 工数 | ○ | 新しく要るのは「細長い部屋」「頭割り（共通部品）」「潜る」の3つ。他は既存の予兆で作れる |

**懸念と対策**
- 集まった塊に突進・鋏が来て全滅する → 刻印の最中は、塊を狙う大技（突進）を出さない。刻印と同時に出るのは小さな技だけ。
- 潜行中に攻撃が当たらない時間が長いと退屈 → 潜るのは約4秒だけ。飛び出した直後に隙を作る。
- 回廊が長すぎて走るだけになる → 大蠍は回廊の真ん中寄りで戦い、奥の端・入口の端は逃げ場として使う程度にする。
- 遠距離（弓）が安全すぎる → 突進が回廊の縦方向に走るので、後ろに離れている人ほど危ない。

## 8. 演出
- 登場：砂の盛り上がり（砂ぼこり）が走り、足元から鋏を広げて飛び出す。
- 刻印：尾を高く掲げて、狙った人へ毒針を向ける（輪が付く）。
- 潜行：脚をたたんで砂へ沈む → 盛り上がりが走る → 飛び出す。
- 鋏：両の鋏を開いて、閉じながら前へ。尾の一突き：尾を後ろへ引いて、まっすぐ突く。
- スタン・撃破：全ボス共通。
