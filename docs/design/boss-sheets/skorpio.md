# ボス定義：砂塵の大蠍 スコルピオ（3層・最後のボス）

> ステータス：合意済み（2026-10-15）。グラズ・ユグドラと同じ方針（基本ルール＋1体1つの大きな裏切り＋文章で説明しない）。**頭割りを必ず入れる。**

## 0. ひとことで
- 何者か：砂の下を泳ぐ大蠍。迷宮区の奥の、細長い砂の回廊に棲む。
- **なにこれ！？**：部屋に入っても誰もいない。砂の盛り上がりがこちらへ走ってきて、足元から飛び出してくる。部屋は細長く、逃げても逃げても追ってくる。
- **なるほど？！**：黄色い円（内向きの矢印）が付いた人のところへは **みんなで集まると、痛みが分け合える**。赤い円（外向きの矢印）が付いた人からは **離れる**（足元から大蠍が飛び出す）。
- 「集まる」と「離れる」の2つの印を対にして使う。**同時には出さない**。

## 1. ステージ：砂の回廊（形を変える）
今までのボス部屋は長方形（グラズ）と十字（ユグドラ）。スコルピオは **縦に細長い回廊**。

```
########.......########   ← 奥（北）。大蠍はここで砂に潜っている
########.......########      幅7マス = 28m
########.......########      長さ18マス = 72m
########...B...########   ← 回廊の真ん中（魔法陣）
  …（同じ幅で続く）
########.......########
###########D###########   ← 扉（南）＝入口
```
- 形に意味を持たせる：
  - 横に逃げ場が限られる → 尾の突き・突進は「横へ」かわす。
  - 縦に長い → 潜って追ってくる大蠍から「回廊を走って」逃げられる。
  - 細い → 頭割りで集まりやすいが、集まった塊ごと狙われる。
- 迷宮区（3層）の上のボス部屋を、この回廊に差し替える（迷宮区の迷路部分はそのまま。地図は上に伸びる）。
- 部屋の中にいるか・ボスが外に出ないかの判定は、この部屋だけ円ではなく **回廊の長方形** で行う。

## 2. 戦いの流れ（HPバー3本）
| 場面 | 起きること | 体験として何を学ぶか |
|---|---|---|
| 登場 | 部屋は空っぽ。奥から砂の盛り上がりが走ってきて、狙った人の足元で **飛び出す**（円の予兆→吹き飛ばし。痛いが死なない） | ボスは地中にいる／追ってくる |
| 1本目 | 基本の技（尾の一突き・鋏・突進・砂の雨）＋**毒針の刻印**（頭割り） | 黄色に集まると軽くなる。方向のある攻撃は横へかわす |
| 1本目が割れる | **潜行（砂喰らい）**：砂に潜り、狙った人に **赤い円（外向きの矢印）** が付いてまわる。盛り上がりがその人へ向かい、最後にその人の足元から飛び出す | 赤い印の人から離れる（印の人は仲間から離れる） |
| 2本目 | 1本目の技＋潜行（砂喰らい） | （新しいことは「離れる印」の1つだけ） |
| 2本目が割れる | **大砂嵐**（DPSチェック）：回廊の真ん中で身を丸めて詠唱（約6秒）。詠唱中に一定ダメージを与えると中断してスタン。間に合わなければ回廊全体に砂嵐（大ダメージ・吹き飛ばし。HP満タンなら倒れない） | 全員で一気に削る |
| 3本目 | 怒り：尾の一突きが **3連突き** になり、技の間が詰まる。刻印・潜行も続く | （新しいことは増やさない） |

## 3. 技
攻撃の頻度は範囲の広さと釣り合わせる：**細い方向攻撃（尾の突き）は高い頻度**で次々に来る（ユグドラの奔流の手応え）。広い攻撃（突進・潜行・刻印）は間をあける。

| 技 | 中身 | 予兆 | 威力 | 出やすさ |
|---|---|---|---|---|
| 尾の一突き | 狙った人へ、細く長い直線。溜め短め | 直線（幅3.5m・長さ26m） | 中 | 高い |
| 尾の三連突き（3本目） | 尾の一突きを3回。狙い直しながら突く | 直線×3（0.45秒おき） | 中 | 高い |
| 鋏の挟み撃ち | 正面の扇 | 扇 | 中 | 普通 |
| 突進 | 狙った人の方へ、回廊の端まで一直線に突っ込む（回廊が細いので横へかわす）。盾槍のガードで止まる | 太い直線 | 大・吹き飛ばし | 低い |
| 砂の雨 | 全員の足元と回廊のあちこちに小さな円（全ボス共通の技） | 円 | 小 | 普通 |
| **毒針の刻印**（頭割り・名前表示） | 1人の足元に **黄色い円** が付いてまわる。外側の輪が **内向きの矢印** といっしょに約5秒で円まで縮み、縮み切ると弾ける。円の中にいる人数で **ダメージを割る**（1人なら重い、3人なら軽い） | 黄色い円＋縮む輪と内向きの矢印＋頭上の黄色い輪 | 合計で特大（人数で割る） | 約16秒に1回 |
| **砂喰らい**（潜行・1本目が割れてから・名前表示） | 砂に潜って姿を消す（その間は攻撃が当たらない）。狙った人の足元に **赤い円** が付いてまわり、外側の輪が縮み切る（約5.4秒）と、その人の足元から飛び出す。**割らない**：円の中の人は全員まるごと受ける | 赤い円＋縮む輪と外向きの矢印＋頭上の赤い輪、盛り上がり（小さな円）がその人へ向かう | 大・吹き飛ばし | 約14秒に1回 |
| 登場の潜行 | 盛り上がりが狙った人を約4秒追いかけ、最後に飛び出す（走れば振り切れる。印は付かない） | 盛り上がり＝連続する小さな円、飛び出す所は大きな円 | 中・吹き飛ばし | 最初の1回だけ |
| **大砂嵐**（2本目が割れたとき・名前表示） | 詠唱（中断ゲージ付き）。失敗すると回廊全体に砂嵐 | 詠唱バー → 回廊全体 | 大・吹き飛ばし | 1回だけ |

- 刻印が付いている間は、集まった塊を狙う大技（突進・潜行）を出さない。刻印と重なるのは小さな技だけ。
- 集まる印（刻印）と離れる印（砂喰らい）は同時に出さない。片方が弾けてからも少し（刻印のあと1.5秒・砂喰らいのあと3秒）はもう片方を出さない。

## 4. 共通の部品として作るもの：人に付く印（集まる／離れる）
- 予兆の色は全ボス共通のルールどおり：**黄色＝集まる**。
- 見た目：足元に黄色い円（弾ける範囲）。その外側の輪が、**内向きの矢印**（「ここへ集まれ」）を並べたまま縮んでいき、円の縁まで縮み切ったら弾ける。頭上にも黄色い輪。
- 弾けた瞬間に **サーバーが** 円の中の人数を数え、合計ダメージを人数で割って配る（画面ごとに数えると、人によって人数が食い違うため）。
- 音：付いたときに鐘の音（集まる＝鐘）。文章は出さない。
- **離れる印**（`awayMark`）：赤い円。矢印は円の縁から **外向き** に流れる。人数で割らず、中にいる人は全員まるごと受ける。音は低くうなる音（避ける＝低い音）。
- 他のボスでも使えるように、ボスの共通部品（`sim/boss.js` の `stackMark` / `awayMark`）に置く。

- 考えない（協力プレイ前提。2026-10-15 決定）。ただし「初見で死なない」は守る：刻印と大砂嵐は、HP満タンなら1人で受けても倒れない量にする。

## 6. 立案：比べた案
| 案 | 中身 | 評価 |
|---|---|---|
| **A. 砂の回廊＋毒針の刻印（頭割り）＋潜行＋大砂嵐**（採用） | 上のとおり | 形に意味がある（細長い＝横にかわす・走って逃げる・集まりやすい）。頭割りが戦いの中心 |
| B. すり鉢の流砂 | 円形の部屋の中心へ砂が流れ、外へ歩き続けないと引き込まれる。頭割りもある | 「引き込まれながら集まる」が忙しすぎる。引き込みの物理と見た目の作り込みが重い |
| C. 尾の部位破壊 | 尾を壊すと毒の技が消える。頭割りもある | 部位ごとの当たり判定が新しく要る。頭割りが脇役になる |

外した案：
| 案 | 理由 |
|---|---|
| 連なる刻印（輪2つを順番に） | 面白いが難しい（2026-10-15 ユーザー判断で外す） |
| 輪2つを同時に（二手に分かれる） | 重ねると得をしてしまう。防ぐには別ルールが要り、ややこしい |
| 頭割り＋散会（青い輪）を同時に | 最後に新しい色の意味が増える |

DPSチェックの置き場所：
| 案 | 評価 |
|---|---|
| **2本目が割れたとき（大砂嵐）**（採用） | 頭割り（1本目）・潜行（2本目）と重ならず、3本目の怒りへの区切りになる。グラズの近衛兵召集（1本目）とも位置がずれる |
| 潜行中に地面から出た尾を叩く | 潜行の「走って逃げる」とぶつかる |

## 7. 自己評価（採用案 A）
| 観点 | 評価 | 理由・対策 |
|---|---|---|
| 前の2体との違い | ◎ | グラズ＝人を追う剣士、ユグドラ＝動かず場所を襲う。スコルピオ＝**地中から追ってくる**＋**みんなで集まる** |
| ステージの形の意味 | ◎ | 細長い回廊が、突進・尾の向き、潜行から逃げる道、集まりやすさの3役を持つ。幅は 28m と広めにとり、詰まりすぎない |
| 頭割り | ◎ | 1本目から出し続ける戦いの中心。縮む輪と内向きの矢印で「集まれ」が文章なしで伝わる |
| 攻撃の頻度 | ○ | 細い尾の突きを高い頻度で（ユグドラの奔流の手応え）。広い技は間をあけ、刻印中は出さない |
| ややこしさ | ○ | 新しい考えは3つ（集まる／潜って追ってくる／詠唱を止める）。バーごとに1つずつ |
| 文章なしで伝わるか | ○ | 黄色＝集まるは共通のルール。人数で軽くなるのは受けたダメージの数字で体感できる。詠唱の中断ゲージはグラズと同じ |
| 協力の意味 | ◎ | 集まらないと重い・全員で削らないと砂嵐、と協力の理由がはっきりしている |
| 理不尽さ | ○ | 刻印は約5秒。潜行の盛り上がりは走れば振り切れる速さ。砂嵐はHP満タンなら倒れない |
| 最後のボスらしさ | ○ | 演出を盛らず、仕組みの「集大成」で見せる（集まる・かわす・走る・削る、を全部使う） |
| 工数 | ○ | 新しく要るのは「細長い部屋（長方形の判定）」「頭割り（共通部品）」「潜る」。詠唱・予兆は既存のもの |

**懸念と対策**
- 集まった塊に突進・潜行が来て全滅する → 刻印が付いている間は出さない。
- 潜行中に攻撃が当たらない時間が長いと退屈 → 潜るのは約4秒だけ。飛び出した直後に隙を作る。
- 回廊が長すぎて走るだけになる → 大蠍は狙った人へ歩いて詰めてくる。端は潜行から逃げるときに使う程度。
- 遠距離（弓）が安全すぎる → 尾の突きは長く（26m）、突進は回廊の端まで走るので、離れていても狙われる。

## 8. 演出
- 登場：砂に潜った状態から始まり、盛り上がり（砂ぼこり）が走って、足元から飛び出す。
- 尾の一突き：尾を後ろへ引いて、まっすぐ突く。
- 鋏：両の鋏を開いて、閉じながら前へ。
- 刻印：尾を高く掲げて、狙った人へ毒針を向ける。
- 潜行：脚をたたんで砂へ沈む → 盛り上がりが走る → 飛び出す。
- 大砂嵐：身を丸め、尾を高く掲げて震わせる。
- スタン・撃破：全ボス共通。
