# ボス定義：霧の大樹 ユグドラ（2層）

> ステータス：立案・自己評価済み（2026-10-15）。グラズと同じ方針（基本ルール＋1体1つの大きな裏切り＋文章で説明しない）。

## 0. ひとことで
- 何者か：迷宮区の奥に根を張った大樹。**動かない**。部屋そのものが根の上にある。
- **なにこれ！？**：ボスが一歩も動かないのに、部屋の「通路ごと」根が噴き上がる。途中で根瘤が光り、削ったHPが戻っていく。
- **なるほど？！**：根は「通路」に沿って走る → 別の通路に逃げればいい。光る根瘤が回復の源 → 手分けして切れば止まる（全部切ると大樹がよろける）。

## 1. ステージ：十字の間（形を変える）
今までのボス部屋は 44m × 36m の長方形（全ボス共通）。ユグドラだけ **十字形** にする。

```
  ...      ← 北の通路（幅3マス=12m、長さ3マス）
  ...
  ...
.........  ← 西・東の通路
....B....     B: 大樹（中心3×3マスの広場の真ん中）
.........
  ...
  ...
  ...      ← 南の通路（扉＝入口につながる）
```
- 中心から各通路の端まで約 18m。通路が4本 = 「逃げ場」「手分け」の単位になる。
- 形に意味を持たせる：大技は「通路1本まるごと」を襲う。安全なのは別の通路。

## 2. 戦いの流れ（HPバー3本）
| 場面 | 起きること | 体験として何を学ぶか |
|---|---|---|
| 1本目 | **根の奔流**（狙った人がいる通路を、中心から端まで根が噴き上がる）＋**枝払い**（足元の円。近づきすぎを罰する）＋**樹冠の雨** | ボスは動かない／通路ごと来る → 別の通路へ |
| 1本目が割れる | **吸い上げ**：4本の通路の端に **根瘤** が1つずつ生え、光る線で大樹とつながり、大樹のHPが戻り始める。根瘤を全部切ると回復が止まり、大樹がよろける（スタン） | 光る線＝回復の源。手分けして切る |
| 2本目 | 1本目の技＋**根の波**（細い線が部屋の端から端まで、縦か横に横切る） | 走って逃げられない波は、回避でくぐる |
| 2本目が割れる | **森の怒り**：根の奔流が **通路を時計回りに1本ずつ** 襲い続ける（回る奔流）。逃げ場は「いま弾けた通路」 | 回る向きを読み、弾けた直後の通路へ入る |
| 3本目 | 回る奔流＋1本目の技 | （新しいことは増やさない） |

## 3. 技
| 技 | 中身 | 予兆 | 威力 |
|---|---|---|---|
| 根の奔流 | 狙った人のいる通路を、中心から端まで（幅12m）。溜め 1.6 秒 | 通路いっぱいの赤い帯 | 大・吹き飛ばし |
| 枝払い | 大樹の周り 8.5m の円 | 円 | 中 |
| 樹冠の雨 | 全員の足元と部屋のあちこちに小さな円 | 円 | 小 |
| 根の波（2本目〜） | 幅 1.6m・長さ 40m の細い線が、4方向のどれかから部屋を横切る（1.5m ずつ、秒速約 9m）。部屋いっぱいなので逃げ切れず、回避でくぐる | 弾ける 0.55 秒前から見える細い帯 | 中 |
| 回る奔流（2本目が割れてから） | 通路を時計回りに1本ずつ、0.9 秒おきに4本。各溜め 1.2 秒 | 帯 | 大・吹き飛ばし |
| 吸い上げ（バーが割れたとき） | 根瘤4つ（各通路の端）。生きている根瘤1つにつき毎秒 最大HPの0.35% 回復 | 光る線（根瘤→大樹）、詠唱バー「吸い上げ」 | — |

## 4. ソロでの扱い
- 根瘤のHPは人数で増減（雑魚と同じ式）。ソロでも1つ数秒で切れる。
- 手分けできないので回復は進むが、1つ切るごとに回復量が減るので「近い順に切る」で間に合う。
- 回る奔流は1人でも「弾けた通路へ入る」で避けられる。

## 5. 立案：比べた案
| 案 | 中身 | 評価 |
|---|---|---|
| **A. 十字の間＋吸い上げ＋回る奔流**（採用） | 上のとおり | 形に意味がある（通路＝逃げ場・手分け）。グラズと体験が真逆（動かない・場所の読み合い） |
| B. 円環の回廊 | 太い幹の周りの輪だけで戦う。根が輪を回って追い立てる | 新鮮だが、幹が太いと近接の手が届かない。輪の幅が狭く、他の技の置き場がない |
| C. 霧の森 | 霧で大樹が見えず、灯り役が照らす | 「予兆は必ず見える」と衝突。描画の作り込みが重い |

## 6. 自己評価（採用案 A）
| 観点 | 評価 | 理由・対策 |
|---|---|---|
| グラズとの違い（新しさ） | ◎ | グラズ＝動き回る剣士・人を追う。ユグドラ＝動かない・場所（通路）を襲う。避け方が「位置取り」中心に変わる |
| ステージの形の意味 | ◎ | 十字の通路が、奔流の単位・逃げ場・根瘤の置き場の3役を持つ |
| ややこしさ | ○ | 新しい考えは3つ（通路ごと来る／根瘤を切る／回る向き）。バーごとに1つずつ増えるので一度に覚えるのは1つ。初案の「3本目にも吸い上げ」は盛りすぎと判断して外した |
| 文章なしで伝わるか | ○ | 回復は「HPバーが戻る＋光る線」で見える。対策：根瘤は大樹と同じ色に光らせ、線を太くする |
| 協力の意味 | ◎ | 4本の通路に散る理由がある（根瘤）。タンクは中心で枝払いを受け持つ |
| ソロ | ○ | 根瘤のHPと回復量を人数で調整。1人でも近い順に切れば間に合う量にする |
| 回避の見せ場 | ○ | 根の波は「回避でくぐる」ための技。線は細く、弾ける前から見えるので、タイミングさえ合えば必ず抜けられる（ユーザー要望で追加。種の弾と入れ替えて、2本目で増える新しいことは1つのまま） |
| 理不尽さ | ○ | 奔流の溜めは 1.6 秒（回る奔流は 1.2 秒）。部屋の端（通路の外）はない＝必ずどこかの通路が安全 |
| 工数 | ○ | 新しく要るのは「十字の部屋」「ボスの手下（根瘤）」「動かないボス」だけ。技は帯・円・弾の既存の予兆で作れる |

**懸念と対策**
- 中心の広場（3×3）にいると、どの奔流も通る → 中心は枝払いもあって危険。これは意図どおり（ずっと張り付けない）。
- 入口（南の通路）に根瘤が立つ → 入ってきた人がすぐ切れる。南を最初に切る流れが自然にできる。
- 回る奔流で「時計回り」を読ませる手がかり：1本目が弾けた直後、次の通路の床がうっすら光る（予兆が先に出る）。

## 7. 演出
- 動かない：歩きのモーションは使わず、根を張った立ち姿。
- 奔流：両腕を振り上げて地面へ叩きつける → 床の帯が弾ける。
- 吸い上げ：両腕を広げ、樹冠が脈打つ。
- 撃破・スタン：全ボス共通。
