# ボス戦のアイデア集（案出し）

> ステータス：案出し（2026-10-15）。採用・不採用はまだ決めていない。
> 方針は [bosses.md](bosses.md)。ソロの釣り合いは考えない（協力プレイ前提）。表の「ソロでの扱い」は参考として残す。

## A. 基本ルール（全ボス共通）の候補
| # | ルール | ねらい |
|---|---|---|
| A1 | HPバーは複数本。1本割れるたびに出来事が起きる | 段階変化を何度も作れる（SAO風） |
| A2 | バーが割れた瞬間、ボスが数秒ひるむ | 「削った！」の手応えと、攻撃のチャンス |
| A3 | すべての攻撃に溜め（予兆）がある。色と形の意味は全ボス共通 | 初見でも読める |
| A4 | 溜めが長いほど強い／範囲が広い | 見ただけで危険度がわかる |
| A5 | 初見で死なない（不意打ち印の技はHP1で止まる） | 驚かせても理不尽にしない |
| A6 | 大技の後には必ず隙がある | 避けたら殴れる、のリズム |
| A7 | 画面の外から予兆なしで攻撃しない（画面外は音と矢印で知らせる） | 理不尽の排除 |
| A8 | 大技は名前を表示する（詠唱バー） | 覚えられる・話題にできる |
| A9 | 登場時に名前・二つ名・ひとことを出す | ボスの印象づけ |

## B. 予兆とエフェクトの文法
| 見た目 | 意味 |
|---|---|
| 赤い範囲 | 避ける |
| 黄色の輪（誰かの頭上） | 集まる（頭割り） |
| 青い輪（各自の頭上） | 散る（散会） |
| 紫 | 向き・視線（見る／見ない） |
| 白い線（ボスと人をつなぐ） | 線（離れる・渡す） |
| 数字 | 順番 |
| 足元の円がゆっくり縮む | 時限（縮み切ったら発動） |

- 音にも意味を持たせる：避ける＝低い音、集まる＝鐘、散る＝高い音
- ボスの体にも溜めポーズを付けて、地面を見なくても読めるようにする

## C. 協力メカニクス（FF14系）
| # | 名前 | 内容 | ソロでの扱い |
|---|---|---|---|
| C1 | 散会 | 各自の足元に範囲。重なると大ダメージ | 普通の「避ける」範囲になる |
| C2 | 頭割り | 1人に付いた範囲に集まると、ダメージを人数で割る | 軽減付きで1人で受けられる |
| C3 | 塔 | 床の円を決まった人数で踏まないと全体ダメージ | 必要人数が1になる |
| C4 | 線 | ボスとつながった人は離れないと痛い／味方に渡せる | 離れるだけ |
| C5 | 視線 | 紫の予兆中にボスを見ていると石化・混乱 | 同じ |
| C6 | ノックバック | 外へ吹き飛ばす。壁や場外に注意 | 同じ |
| C7 | 強攻撃（タンク向け） | 1人に重い一撃。盾槍のガードで受けられる | ガードか回避 |
| C8 | 時限爆弾 | 付いた人の足元の円が縮み切ると爆発。人のいない所へ運ぶ | 同じ |
| C9 | 順番 | 1・2・3…の数字が付き、その順に範囲が来る | 同じ（順番に避ける） |
| C10 | 前か後ろか | ボスの溜めポーズで前方か後方かを当てる | 同じ |
| C11 | 分断 | 壁でパーティを2つに分ける。両側で対応が必要 | 片側だけになる |
| C12 | 吸い込み／押し出し | 中心へ引き寄せ、または外へ押し出したあとに範囲 | 同じ |

## G. 固有の解き方（観察すればわかる癖）

|---|---|---|---|

| G2 | 背中が弱い | 回り込む。ボスは振り向きが遅い | 背中が光っている |

| G5 | 足元に毒を残す | 部屋の端へ誘導してから戦う | 床の色 |
| G6 | 走る音に反応する | 歩いて近づく | 耳が動く |
| G7 | 正面は盾で防ぐ | 横・後ろから／盾を壊す | 正面で弾かれるエフェクト |

## H. 驚かせる・楽しませる
- 戦場が壊れる、天候が変わる、BGMがバーごとに変わる
- ボスがしゃべる。こちらの行動に反応する（「背中ばかり狙いおって！」）
- 撃破演出。最後の一撃をスローにする
- 撃破で称号（既存の称号の仕組み）、次の層への伏線
