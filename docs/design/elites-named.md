# エリート（精鋭）とネームドの仕組み

## 1. 今の状態と課題

| 種類 | 今 | 課題 |
|---|---|---|
| 精鋭 | ダンジョン（古井戸など）の敵が全部「精鋭」。HP×3.2・威力×1.5・少し大きい | 屋外には出ない。見た目も動きも普通の敵と同じで、「強いのが出た！」という出来事にならない |
| ネームド | 秘境（静かな湖畔・流砂の谷）にだけ1体。決まった場所に6分ごと。大きい雑魚 | 技がない。出方が時計まかせで、探しに行く動機が弱い。普通のフィールドにはいない |
| 番兵 | 迷宮区の精鋭（盾と3連斬り） | 良くできている。今回は触らない |

## 2. 方針

- **精鋭 = 「変わり種」との遭遇**。屋外でときどき、性質（アフィックス）を1〜3個持った精鋭が、手下を連れて現れる。性質で戦い方が変わる。
- **ネームド = 「狩りに行く相手」**。各フィールドに1体の主。**エリアで敵を倒すと「気配」が溜まり**、満ちると主が目を覚まして知らせが出る。地図に印が出るので、みんなで向かう。固有の技を2〜3個持つ。
- 報酬は「わざわざ戦う価値」がはっきり分かる量に。精鋭は性質の数だけ増える。ネームドは初討伐で称号。

## 3. 精鋭

### 出方
- 屋外（フィールド・狩場・谷）で、敵が湧くとき 6%（狩場は 9%）で精鋭になる。エリアに同時に2体まで。
- 精鋭は**手下を2体連れて**湧く（群れのリーダー）。
- 性質の数: 第1層 1個 / 第2層 1〜2個 / 第3層 2〜3個。

### 性質（アフィックス）

| 性質 | 動き | 見た目 |
|---|---|---|
| 俊足 | 移動 ×1.5、攻撃の間隔 ×0.75 | 水色の残像 |
| 鉄壁 | 受けるダメージ ×0.6（攻撃の予兆中は ×1） | 灰色の岩の殻（縁の光） |
| 炎の足跡 | 動いた跡に、少し遅れて燃える小さな円 | 足元の火の粉 |
| 雷鳴 | 6秒ごとに、近くのプレイヤーの足元へ雷の円（3つまで） | 黄色の火花 |
| 分裂 | 倒すと小さく素早い分身3体に分かれる | 緑のしずく |
| 再生 | 3秒攻撃を受けないと、毎秒 最大HPの3% 回復 | 緑の光の粒 |
| 号令 | 攻撃するたび、周り10mの敵の威力 +25%（5秒）。仲間を呼び寄せる | 赤い旗の光 |
| 狂化 | HP 40% 以下で 移動 ×1.3・攻撃の間隔 ×0.6・赤く光る | 赤い縁の光 |

- 組み合わせの禁止: 分裂＋再生（倒しにくすぎる）。
- 能力: HP ×3.2（性質が2個目から +20% ずつ）・威力 ×1.5。

### 報酬
- 経験値 ×2.5 ×（1 + 0.4 ×（性質の数 − 1））
- 金貨袋（×3 → ×3 ×性質の数）
- 装備: 必ず1つ（良品以上が出やすい。性質1つにつき出やすさ +0.15）。性質2個以上なら、もう1つ 50%。

## 4. ネームド

### 出方（気配）
- エリアで敵を倒すと「気配」が溜まる（雑魚 1・精鋭 5）。しきい値（フィールド 30）に達すると、主が巣で目を覚ます。
  - 全員に知らせ「地響きがする…『暴れ大猪ドルガ』が目を覚ました」。地図に ★ の印。
- 倒すと気配は 0 に戻り、5分は溜まらない。
- 秘境の主（湖・流砂）は今までどおり時間で出る（秘境は「探して見つける」場所なので）。

### 主（各フィールド）

| エリア | 名前 | もと | 巣 | 技 |
|---|---|---|---|---|
| ひだまりの谷 | 暴れ大猪ドルガ | イノシシ | 台地の見張り塔のそば | 突進（長い直線→駆け抜ける）・地響き（広がる3重の輪）・呼び声（イノシシ3体） |
| 霧の森 | 霧喰いの大狼フェンリ | 霧の狼 | 森の奥 | 突進・遠吠え（狼3体＋自分が速くなる）・霧の牙（周りに扇を4方向） |
| 砂塵の荒野 | 砂岩の巨人ガルム | 砂のゴーレム | 荒野の外れ | 地響き・岩落とし（狙った人の周りに円5つ）・呼び声（ゴーレムの欠片3体） |

- 能力: HP ×8・威力 ×1.75（今のネームドと同じ）。技は普通の攻撃3回に1回くらい。HP 50% で怒り（技の間隔が短くなる）。

### 報酬
- 経験値 ×8・金貨袋 ×15（今と同じ）
- 装備: レア以上確定（アイテムレベル +2）＋ もう1つ（良品以上）＋ 20% で さらに1つ（エピック以上が出やすい）
- **初討伐で称号**（キャラごと）: ドルガ「大猪殺し」・フェンリ「霧を裂く者」・ガルム「巨岩砕き」。3つとも「精鋭・ネームドへのダメージ +10%」（重ならない）。

## 5. 見た目

- 精鋭: 大きさ ×1.3、足元に性質の色の回る輪、性質ごとの粒子。名前は「精鋭〔俊足・雷鳴〕フレンジーボア」（金色）。
- ネームド: 大きさ ×2.1、王冠／角／鎧の飾り（敵の種類ごと）、光る目、縁の光、立ちのぼる光の粒、足元の紋章の輪（桃色）。名前は「★ 暴れ大猪ドルガ」（桃色）。怒ると赤。
- 地図: 目覚めている主の位置に ★。

## 6. 自己評価

| 観点 | 評価 | メモ |
|---|---|---|
| 遭遇の楽しさ | 高 | 性質で「どう戦うか」が変わる（雷鳴は散開、号令は先に倒す、分裂は範囲で）。協力プレイで声を掛け合う理由になる |
| 冒険感 | 高 | 気配→目覚め→地図の★→みんなで向かう、の流れ。谷の台地のような「行く価値のある場所」と合う |
| 難しさ | 中 | 第3層の性質3個は強い。手下つきなので、ソロだと厳しいことがある（協力優先なので許容） |
| 報酬の釣り合い | 中 | 精鋭が出る割合 6% × 装備確定で、装備の出る量が全体に少し増える。様子を見て割合で調整 |
| 手間 | 中〜大 | サーバーの性質（8種）・ネームドの技（6種）・見た目（輪・粒子・飾り）・地図・称号 |
| 既存への影響 | 小 | ダンジョンの精鋭・番兵・秘境の主はそのまま。屋外の湧きに精鋭の抽選を足すだけ |
| 記録テスト | 要作り直し | 屋外の湧きに抽選が入るので、サーバーの記録・戦闘の記録が変わる |
