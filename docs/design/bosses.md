# ボス戦の設計方針（仮案）

> ステータス：仮案（2026-10-15）。発案メモを元に整理。実装はまだ。

## 目指す体験
**「なにこれ！？」→「なるほど？！」**
初めて見たときに驚き、観察すると意味がわかり、わかると対応できる。

## 1. 基本ルール（全ボス共通。崩さない）
| ルール | 中身 | 今の実装との差 |
|---|---|---|
| HPバーは複数本 | SAOのようにHPを数本に分ける。1本削るたびに何かが起きる（段階変化・ギミック・増援など） | 今は 65% / 35% の2回だけで、全ボス共通 |
| 溜めと範囲とエフェクトを統一 | すべての攻撃に「溜め（予兆）」があり、色と形の意味がどのボスでも同じ。適当な連打・ただの弾・避けるだけの範囲にしない | 予兆の仕組み（tele）はあるが、色や形の意味が決まっていない |
| 初見で死なない（初見“半殺し”） | 不意打ち・初見殺し系の技はピンチにはするが、それだけでは倒れない | 仕組みなし |

### 予兆の色と形（叩き台）
| 見た目 | 意味 |
|---|---|
| 赤い範囲 | 避ける |
| 黄色の輪（誰かの頭上） | 集まる（頭割り：人数で割る） |
| 青い輪（各自の頭上） | 散る（散会：重ならない） |
| 紫 | 向き・視線（見る／見ない、背を向ける） |

## 2. 想定通りを崩すデザイン
「ボス戦ってこうだよね」という思い込みを1つ裏切る。
- 円形ステージ → 縦長で、ボスが追いかけてくる
- 1体 → 取り巻きがいる（または2体）
- 削れば減る → HPを回復してくる（バーが1本戻る など）

## 3. 初見“半殺し”
突然出てきて驚かせる、ピンチにする、動揺させる。でも初見で死ぬことはない。
- 実装案：「不意打ち」印の付いた技は、HPを1残して止める（または最大HPの一定割合までしか削らない）。

## 4. FF14風のメカニクス
- 散会（各自の足元に範囲。離れないと巻き込む）
- 頭割り（1人に付いた範囲に集まると、ダメージが人数で割られる）
- その他の候補：塔（踏む人数が決まっている円）、視線（見ると状態異常）、ノックバック、タンク向け強攻撃
- 注意：ソロでも遊べること。1人のときの頭割り・散会の扱いを必ず決める。

## 5. 固有の「解くべき」ギミック
ボスごとに、観察すれば理解できる癖を1つ以上持たせる。
- 弱い人（HPが低い・レベルが低い）を狙ってくる
- 背中側へのダメージが大きい
- 理解の手がかり（光る弱点・セリフ・予兆の違いなど）を必ず用意する

## 仕組み（データ）にすると必要になるもの
- ボス定義に：HPバーの本数、バーが割れたときの出来事、狙い方、弱点（向き・部位）、ステージの形、取り巻き、回復
- 技に：溜め時間、予兆の種類（避ける／集まる／散る／向き）、不意打ち印、出す条件（距離・人数）、重み
- プレイヤーに付く印（散会・頭割り・塔など）の仕組み
