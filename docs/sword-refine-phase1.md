# フェーズ1：通常の片手剣の比較試作

元ブランチは `refactor/solid` (`a06f958`)。作業先は `codex/sword-refine-phase1`。
通常の直剣（片手剣 style 0、品質「並」）だけを対象に、現行と改良2案を比較する。

| 案 | 解釈 | 主な変更 |
|---|---|---|
| 現行 | 細身の直剣・弧を描く鍔・鍔元の宝石 | ゲーム本体の `makeWeapon('sword', 1, 0)` をそのまま表示 |
| A / Refined | 基本の剣として端正に整える | 刃の菱形断面、小さく反った鍔、円形の柄頭。細い外形と控えめな金具 |
| B / Bold | 小さく映っても読めるようにする | 幅のある刃、広い明暗の面、角張った鍔。細かな模様を増やさず外形で区別 |

以前の直剣試作（slim / broad）を出発点に、現行の刃の長さ、握り位置、材質と輪郭へ合わせた。
両案は閉じた菱形の刃を持ち、面の色は頂点色でまとめて描く。
同じトゥーン階調・銅色の金具・暗い革を使い、握り位置 `GRIP_Y.sword` を維持する。

## 見る方法

このブランチを通常どおり起動し、次を開く。

`http://localhost:8080/sword-refine-phase1.html`

- 接写、動作を確認する近景、ゲームの最寄りズーム、ゲームの標準ズームを選べる。
- 待機、通常3段、溜めと強攻撃、既存のスラントラッシュを切り替えられる。
- Pauseで止め、Restartで最初から比較する。
- 画面はRootの配下に描画と操作のViewを置く。入力はバブリングでMediatorへ届け、状態機械が再生・停止・切り替えを裁定する。
- スマートフォン幅では3案を縦に並べる。

比較に動画の書き出しは使わず、HTMLと代表スクリーンショットを成果物とする。
接写と動作用近景は確認用のカメラで、ゲームカメラの場面とは表示名を分ける。
ゲームカメラは本体のFOV 50、距離 `19.5 × zoom`、ピッチ計算を使う。
照明と色調は第1層の半球光・主光とACESトーンマッピングを使う。比較画面はBloomを追加しない。

## モーションと採用範囲

キャラクターと骨格は本体の `makePlayer`、動きは既存の `animatePlayer` を使う。
通常攻撃の速度とコンボ順、溜めの入力、強攻撃の0.5秒、スラントラッシュの既存トラックを共通に再生する。
スラントラッシュの前進は3mの踏み込みを3回。デモの切り替わりで開始位置へ戻す。
命中判定や戦闘効果を発生させる画面ではない。

候補は `models/prototypes/straight-sword-candidates.js` に独立して置く。
本体の武器登録表、装備データ、通信、モーション、スキル性能、セーブは変更しない。
このフェーズでは、採用する形を決めるための比較までを扱う。

## 確認

既存の武器・プレイヤー・ボスの形と動作の記録テストを維持する。
追加テストでは、両候補が既存の全片手剣技と基本姿勢で同じ骨格・握り位置を保つこと、通常の直剣の寸法と描画予算に収まることを確認する。
画面の再生・停止・カメラ・動作切り替え、PC幅とスマートフォン幅も確認する。

次のフェーズは、この比較結果から通常直剣の採用形を選び、既存style 0への正式接続を行う。
