# 片手剣の握りと細身直剣（フェーズ2）

基点: `refactor/solid` の `4ee6b49`。作業ブランチ: `codex/sword-grip-phase2`。

## ゲームで変わること

- 通常直剣（sword / style 0）を、前回比較で選んだAの細身モデルへ置き換えた。
- 刀・葉形・ユニークの刃や金具は既存形状を維持し、握りだけ共通で改善した。
- 片手剣では既存の丸い右手の代わりに、柄を包む指・親指・手甲を表示する。武器と同じ掌の子に置き、柄の回転に追従させる。手首の骨は追加しない。
- 待機・歩行では肘を曲げ、刃を斜めに起こす。溜めは体の右前で構え、通常斬りは既存の腕の振りを基準に少し肘を曲げる。
- ガード、専用スキルの姿勢、回避・被弾・ダウンには握りの追従だけを適用する。
- 弓・槍などへ持ち替えたら既存の手を復帰させる。再度片手剣にしても握り手を重複生成しない。
- レア度による色・発光を維持。名前による0〜2の形状選択、伝説・神器の専用形3の割り当ても継続する。

通常直剣を共有する一般の騎士型の敵と、直剣の落とし物も新しい形になる。
他の武器種の形・骨格姿勢、戦闘数値・判定・タイミング、通信形式、保存形式は変更していない。
オンラインでは双方がこのブランチを配信する同じサーバーに接続すれば反映される。

## HTMLで確認する

通常通り `npm start` し、`http://localhost:8080/sword-grip-phase2.html` を開く。

- 待機、溜め、スラントラッシュを並べて表示する。実際のゲームのモデル・姿勢処理を呼ぶ。
- 初期表示は静止。Playで動き、Pauseで止まる。
- 全身・握りの接写・横・ゲームカメラを切り替えられる。
- 4種類の片手剣を切り替えられる。
- Root配下のPassive Viewに描画パラメータを渡し、操作は親へ伝播してMediatorの状態機械で処理する。

- モデル・姿勢の期待値は、直剣の形、片手剣装備者、一般騎士、直剣の落とし物と片手剣の基本姿勢だけを更新。他武器の骨格とスキル・サーバーの記録は既存値のまま。

これは指の骨を動かすアニメーションではなく、既存リグに接続する軽量な握り手。刀などの形状リファイン、固有武器を個別に選ぶ経路は後続フェーズで扱う。
