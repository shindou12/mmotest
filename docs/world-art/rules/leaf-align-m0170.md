# Codex の広葉樹の葉の向きを揃えた記録（M-0170）

M-0169 で手描きの絵に替えた `tree-full-v1` の葉を、塊の表面に沿った屋根瓦の重なりに置き直した。向きの乱れが消え、塊も読めるようになった。

## 結果
- 11,992 三角形（元は 16,822）。暗い菱形の小片を消した分だけ減った
- 道具: `tools/worldart/blender/leaf_align.py`
- 比較: `art/shots/leaf_m0170/compare.png`（左が M-0169、右が揃えた版）、横からは `side.png`

## わかったこと
- **葉を面の中で回すだけでは揃って見えない。** 面の傾きがばらばらなので、1 回目はむしろ荒れた
- **面を塊の表面に沿わせ、先端を頂点から外と下へ流すと揃う。** 先端を 16° 持ち上げると屋根瓦の重なりになる
- **法線を塊の丸みから作り直すと、塊ごとの明暗が出る。** 塊が 1 つずつ読める
- **暗い菱形は 3 面の小片だった。** 消しても葉の形は崩れない

## 残した差
- 塊のつなぎ目にすき間があり、枝が見える
- 輪郭が少し荒い
- 葉の色が黄に寄る（地図の `foliage.tint`）
- 幹が細く、根が棘のよう
- 重さは今の木（708）の約 17 倍
- Godot では未確認
