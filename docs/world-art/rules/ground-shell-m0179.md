# シェルの草と地面の手法を試した記録（M-0179）

草はシェルだけにする前提で（ユーザー、2026-11-06）、`ground-look-survey.md` で見つけた RO3 との差に効きそうな手法を、web の `world.js` で試した。
- 場面: M-0177 の一時の地図 sdg の F01（道と森）・F02（広場）・F04（岩ともみ）
- 土台: すべて M-0178 の「影の色＋段」（`shtint=0.05,0.09,0.13&shpen=0.6&ramp=1&exposure=1.15`）
- 比べた相手: RO3 の画面の写し。中身は見ていない

Godot には M-0005 でシェルの草が入っている。web にはなかったので、同じ考え方で入れた（`gshell`）。

## 結論
| 手法 | 判断 | 見え方 |
| --- | --- | --- |
| A シェルだけ（16 層・高さ 0.18m・間隔 0.045m、房なし） | **効く（土台）** | 草地が毛並みになり、房のばらつきが消えて落ち着く |
| B 数 m の斑（`gpatch=5&gpatchc=0.9`。明るい黄緑で背が高い所と、深い青緑で背が低い所） | **効く。ただしまだ弱い** | 開けた所に明暗の斑が出る。数 m の明暗の量は広場で 0.030 → 0.040（RO3 は 0.09〜0.13） |
| C なびく筋（`gcomb=0.3`。上の層ほど向きの場へずらす） | **効く** | 上から見て、草がなでつけられた筋になる。RO3 の草地の筆の流れに一番近い |
| D 道の縁（`gedge=0.6&gdirt=0.82,0.86,0.8`。草を道へまだらにかぶせ、土を暗くオリーブへ） | 弱い | 土が少し落ち着くだけ。道の縁の重みが急に変わるので、かぶさる帯が細すぎた |
| E 根元の暗さ（`gcontact=0.6`。配置から地面の暗さの絵を作る） | 弱い | 切り株や茂みの根元が少し暗くなる。このカメラの距離では目立たない |
| F 際立つ所に大きな房（`gacc=1.7`。道の縁と物の根元の近くだけ残して 1.7 倍） | 弱い | 房が暗い塊になって点在し、RO3 のように「そこだけ茂る」見え方にはならない。房の絵と形を変えないと際立たない |
| G やわらかい影（`smap=vsm&srad=40`） | **効く** | 木の影の縁がぼけて、RO3 の影に近づく。半径 12 ではほぼ変わらない |
| 全部 | **一番近い** | 斑・筋・やわらかい影で、地面が塗った草原に見える |

## 使い方（world.js、すべて省略時は無効）
- `gshell=16`（`gsh` 高さ、`gsd` 間隔）。`grass=0` を付けると草の房をすべて消す。付けないで `gacc` を入れると、際立つ所だけ房を残す
- `gpatch` 斑の大きさ m、`gpatchc` 強さ
- `gcomb` なびく量 m
- `gedge` 道へかぶせる量、`gdirt=r,g,b` 土の色に掛ける値
- `gcontact` 根元の暗さ、`gcr` 半径の倍率
- `gacc` 房の倍率、`gaccr` 際立つ所以外に残す割合
- やわらかい影は既存の `smap=vsm&srad=40`

## 次に効きそうなこと
- B は強さか、斑の明暗の幅を上げる。RO3 の量まで、まだ 2 倍以上足りない
- D は、草の重みを決める前の道の重み（頂点色 R）から縁の帯を作り、もっと広く崩す。Godot の M-0006（縁までの符号つき距離）の考え方を使う
- F は房の形と色を変えないと際立たない（明るい黄の穂、背の高い葉など）。今の房では効かない
