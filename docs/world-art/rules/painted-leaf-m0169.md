# Codex の広葉樹に手描きの葉の絵を貼り直した記録（M-0169）

`tree-full-v1`（Broadleaf_Fuller）の形と UV はそのままに、葉の絵だけを image_gen の手描きに替えた。ゲームのカメラで、1 枚ずつ手で塗った葉に読めるようになった。

## 結果
- 三角形は同じ 16,822。GLB は 1.1MB → 2.6MB（絵を 2048x256 → 2048x1024 にしたため）
- 道具: `tools/worldart/leaf_strip.py`（下絵と帯の組み立て）、`tools/worldart/blender/leaf_repaint.py`（絵の差し替えと材質名）
- 絵: `art/painted-gen/leaf_m0169/`。比較: `art/shots/leaf_m0169/compare.png`（左から元・貼り替え・明暗 0.6）、葉の近接は `close.png`

## わかったこと
- **この木は葉 1,610 枚が 8 列の帯を共有している。** 帯を替えるだけで全部の葉の絵が変わる
- **帯は左右に約 2.4 倍引き伸ばされて貼られる。** そのまま塗らせると筆跡が伸びるので、普通の比率（384x512）で塗らせてから列へ縮めて組み込む
- **絵の上が葉の先、下が根元。** 赤と青の階調を貼って確かめた
- **材質名に `leaf` を入れて透明度を持たせると、絵だけで輪郭が丸くなる。** 三角形は増えない
- **1 枚の中の明暗は 0.6 倍に弱めるとよい。** 1.0 だと葉ごとの差が騒がしい。0.6 でも筆跡は残る

## 残した差
- 暗い菱形の小片が葉の間に見える（列 7 に割り当てられた 3 三角形の小片）
- 葉の色が黄に寄る。地図の `foliage.tint` が葉の材質に掛かるため（`f1_field` と同じ値で確認した）
- 樹冠全体の明暗の流れが弱く、塊が読みにくい
- 幹が細く、根が棘のよう
- 重さは今の木の 20 倍以上のまま
- Godot では未確認
