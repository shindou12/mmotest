# 今の広葉樹 maple2_t を 3 案で良くした記録（M-0171）

Codex の木で効いた手描きの絵と屋根瓦の置き方を、軽い `maple2_t` に移して比べた。比較は `art/shots/plate_m0171/compare.png`（左から元・A・B・C）。今の木と同じ位置、同じ高さの幹を使っている。

| 案 | やったこと | 三角形 | 見え方 |
|---|---|---|---|
| A | 房の絵を手描きの丸い葉に替えた | 708 | 星の模様が消え、放射状の葉の塊に読める。花や多肉植物にも見える |
| B | A に加えて板を水平寄りの屋根瓦に置き直した | 708 | A より塊の並びが整う。差は小さい |
| C | 葉 1 枚の板 497 枚に作り替えた | 1,550 | 塊の段が一番読める。葉が鱗に見え、松ぼっくりに近い。色が茶に寄った |

道具: `tools/worldart/plate_paint.py`、`tools/worldart/blender/tree_leaf_cards.py`、`leaf_align.py` の `--leaf-faces`・`--up`。絵は `art/painted-gen/plate_m0171/`。

## わかったこと
- **絵を替えるだけで印象の大半が変わる。** 三角形を増やさずに、尖った星から丸い葉の塊になった
- **絵の房の板は横を向くと棒に見える。** 塊の表面にそのまま沿わせると破綻した。上へ寄せて水平寄りに置く（`--up 2.2`）
- **頂点色は絵に掛かる。** 今の木の葉は 0.55 前後で、新しい葉を 1.0 近くにすると白く飛ぶ
- **葉 1 枚の板は、面を増やさず丸い葉を出せるが、揃えすぎると鱗になる。** 葉の大きさと向きのばらつきが効きそう（未検証）

## 残した差
- どの案も幹がほとんど見えない。背が高く葉が低くまで付く、`maple2_t` の幹の形のまま
- A・B は同じ房が繰り返して見える
- C の色は未調整
- 地図 `f1_field` の色味での確認だけで、実際の地図に並べていない。Godot も未確認
