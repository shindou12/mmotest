# L27: 暗部の測り直しと、「ぱきっと」の正体（仮説 A）

固定した条件: 見本②の地図データ・基準カメラ（B01・B02・B03・near@B01）と south_coast_g3（基準・近景）。変えるのは URL の引数 1 つだけ。撮影は `art/shots/ab/L27/`。
この回からの方針（ユーザー、2026-10-23）: **数値を見本に合わせる作業にしない。全体の印象と、それを統一しているルールを言葉にして見つけ、新しい手法を小さく試し続ける。** 数値は裏づけにだけ使う。

## 1. 暗部が浮く（rulebook 16 の A）は、半分が測り方のせいだった
- rulecheck の階調 p0.5 は画面全体で測っている。見本 B（スマホ撮影）は左右の黒い帯と UI で暗部が下がる。**UI の多い縁を除いた中央**（rulecheck の材質と同じ範囲）で測ると、見本② B01〜B03 は 41〜43、撮影は 37〜47 でほぼ同じ。
- 動画の見本（C01・C05・D03・D04・R01〜R04）は中央でも 18〜31。スマホ撮影は画面の黒を浮かせて写すので、ゲームそのものの暗さに近いのは動画のほう、と考える [暫定]。
- 見本の暗い所（下位 2%）は、もみ・茂み・樹冠の**内側の奥**に集まる。撮影も同じ場所が暗いが、見本ほど暗くならない。

## 2. 頂点 AO を環境光にも掛ける（aoamb、既定 0・未採用）
- アセットの頂点 AO は地色に掛かるため、日なたも日陰も同じ割合で暗くなり、明暗比を変えない。定番の AO（three の aoMap）は間接光だけを遮る。`?aoamb=<乗数>`（`aoset=leaf|all`）で、間接光に頂点色の明るさのべき乗を掛ける。
- 結果（明暗比 B01/B02/B03、見本 2.61/2.36/2.84）: 0 → 2.59/2.38/2.52、1 → 2.86/2.48/2.71、2 → 3.13/2.57/2.89。B03 のもみの内側が深くなって見本 R03 に近づくが、B01 は行き過ぎ、手前の樹冠（south_coast の近景）は日陰の葉がほぼ黒くつぶれる。対象を葉だけにしても全部にしても同じ（効くのは葉）。
- 比較: `sheet_B01_B03.webp`、`zoom_B03_a1.webp`、`zoom_scnear_a1.webp`。**未採用**（効かせ方を絞る案: 樹冠の内側だけ、森の地図だけ）。

## 3. 印象: こちらは「ぱきっと」、見本は「にじみ・淡さ」（ユーザーの指摘）
同じ大きさで切り出して並べた（`crisp_vs_soft.webp`、上 B01 の木箱のあたり・下 B03 の崖ともみ、左 = 見本）。
- **見本は物を量感で語る**: 岩は丸い塊で、明るさがなめらかに移る。木箱は角が丸く、上の縁に光、まわりの暖かい土の色がにじむ。葉は房ごとの明暗のかたまりが先に見える。
- **こちらは物を線と模様で語る**: 岩は平たい面に暗い割れ目の線（敷石のよう）、木箱は板のすき間が黒い線、茂みは葉の切り抜きの縁が細かい暗い点々、崖の上の日なたの形の縁が硬い。
- ルールの仮説 [未検証]: **細かい所ほどコントラストを弱くし、形は大きな明暗のかたまりで見せる。暗い線で区切らない。** 地面の淡さ・草と土の境のにじみも同じルールで説明できる。
- 見本のにじみの一部は撮り方（スマホ・動画の圧縮）による可能性がある。だから撮り方で出ない「形」の差（葉の縁・岩・小物の角）から試す。

## 4. 仮説 A: 葉の縁の暗い線を消す
葉の絵を測った（不透明な所のうち、透明から 3px 以内の縁 / 芯の明るさ）: spray_clover 0.59、spray_maple 0.72、clump_maple 0.74、frond_palm 0.83、plate_maple 0.87、leaf_broad 1.05、frond_fir3 1.01。原因は 2 つ。
1. **透明な所の色が黒**（RGB ≈ 0）。ミップマップと補間で黒が縁に混ざる。
2. **縁そのものが暗く描かれている**: `textures2.py` の `star_leaf` は葉を「外 = 暗・中・芯 = 明」の 3 段で塗る。これがトゥーンの輪郭線のように働く。

### A1: 色を透明な側へ広げる（alpha bleeding、`?ldil=1`、読み込み時に処理）
- B01 で画素の 4%、B03 で 2.5% が少し明るくなるだけ（|ΔL| 0.3〜0.5）。**効果は小さい**。黒の混ざりは主な原因ではない。
- south_coast の近景は差が大きく出たが、ヤシの葉の揺れの時刻がずれただけ（読み込みが遅くなった分）。近景の揺れる物は入／切の比較に向かない。

### A2: 縁の段をやわらかく描き直す（`tools/worldart/textures_soft.py` → `public/worldart/tex_soft/`、`?ltex=tex_soft`）
- 星形の葉 3 種と spray_clover を同じ乱数で描き直す。外側の段の色を中の段へ 75% 寄せ、色を透明側へ広げてから色だけを 3px ぼかす（形 = alpha はそのまま）。絵の比較: `leaf_tex_soft.webp`（上 = 今、下 = やわらか）。
- 結果: B02・B03 で画素の 15〜19% が明るくなる（|ΔL| 1.9〜2.2）。拡大（`zoom_soft_B02.webp`）では、樹冠の葉どうしを区切っていた暗い網目が消え、房の明暗のかたまりが先に見えるようになった。**見本の方向（淡い）へ動く**。
- ただし画面全体（`sheet_softleaf.webp`、左から 見本・今・やわらか）では印象の差は小さい。茂みの「細かい点々」が残る。残っている点々は、(a) leaf_broad（bush_a）・frond_fir3 など今回描き直していない絵、(b) 葉 1 枚が画面で 2〜4px と小さく、房ごとの陰影と小さな抜けが細かい模様になること、から来ていると見る [未検証]。
- **状態: 方向は合う・効きは小さい。未採用**（既定は切）。

## 次に試すこと（小さく 1 つずつ）
1. 茂みの点々: 葉 1 枚を大きくし、房の数を減らした茂みで、細かい模様が消えるか（rulebook 8.1 の「葉 1 枚 ≈ 樹冠の 1/10」を茂みで見直す）。
2. 岩を量感で描く（割れ目の線を弱め、丸い法線でなだらかな陰影。アイデア 12）。
3. 小物の角を丸め、縁に光を乗せる。すき間の黒を浅くする。
4. 画面全体のにじみ（薄くぼかした絵を 10〜20% 重ねる diffusion）。撮り方の影響との切り分けも。
