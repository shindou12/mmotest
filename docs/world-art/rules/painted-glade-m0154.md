# もらった手描きの絵で作った小さな地図（M-0154、2026-11-02）

地図は `painted_glade`（`public/worldart/index.html?map=painted_glade`）。元の絵は `art/painted-src/`（ユーザーの提供。見本にはしない）。切り分けは `tools/worldart/painted_textures.py`。光・カメラ・階調・仕上げは第 3 世代の雛形のまま。`?notex=1` で絵を切って比べられる。

## 判断: 方向は有望。規則にはまだしない
1 場面だけなので、rulebook 1.2 の採用の条件は満たしていない。

**良くなった所**
- 画面全体が同じ筆で描かれたようにまとまる。地面の細部が減り、見本の「地面は低い細部」に近づく。
- 岩が線でなく塊に見える。M-0153 で焼き込みでは動かなかった「量感」が、絵を変えると動いた。効いていたのは色の塗り分けより、黒い割れ目の線を消したこと。

**残っている欠点**
- 樹冠: 葉の板の丸い輪郭が見える。v1 の直線は消えたが、円の縁が目立つ（`art/shots/painted_glade/v2/main.webp` の右）。
- 切り株: オレンジが強く、切り口の下がくびれて見える。
- 土の道: 既存の絵のままで、丸い小石と細い筋が周りから浮く。もらった絵に道がない。
- 木の皮: 札に書いた `wood` の差し替えが world.js に入っていない。幹はこのカメラでほとんど見えないので、この場面の見え方には効かない。
