# RO3 の画面の作りを複数の場面で試し、アセットの作り方へつなげた記録（M-0176）

M-0175 の続き。`f1_field` の F01・F02・F04 で、画面の作りの要因をまとめて試し、そこから小物と草の房の作り方を試した。RO3 の中身は見ておらず、すべて画面からの推定。規則集には入れていない。

## 画面の作り: わかったこと

### 地面の明るさの幅が広い（新しい手がかり）
細部の少ない所（ほぼ地面）の明るさを測ると、RO3 は幅が広く、こちらはほぼ一定だった。

| 細部の少ない所の V | RO3（15 枚の平均） | こちらの元（F01〜F07） |
| --- | --- | --- |
| 中央 | 0.51 | 0.62〜0.76 |
| 明るい所（90%） | 0.79 | 0.73〜0.81 |

試しの `sc3` は中央 0.40、明るい所 0.76〜0.77（F01・F02）で、**幅は近づいたが、今度は暗くなりすぎている。** RO3 の中央は場面で 0.25〜0.93 と開きが大きく、平均は目安にとどまる。

明るい所は同じくらいで、中央だけが低い。RO3 の地面は半分近くが影か暗めの塗りの中にあるらしい。分け方は細部の量だけで大まかなので、値は目安。規則集の「暗い所 13〜17%」より多い可能性があるが、測り方が違うので直接は比べていない。

### やわらかい大きな影と金緑の色は、3 場面で同じ方向に効いた
F01・F02・F04 のどれでも、塗った絵の空気に近づいた。ただし影を増やしすぎると全体が暗くくすんだ（`sc1`・`sc2`）。影を 55% に減らし、彩度を 1.02 に戻した `sc3` が一番よかった。それでも RO3 より色の幅が狭く、緑の豊かさが足りない。

### 試したが差が小さかったもの
- **画面の位置で掛けるぼかしを切る:** 上端の鋭さは RO3 が高く見える（こちらの上端は平均の 0.41〜1.07 倍）。ただし見本の一部は上に文字があり、測定は確実でない。切っても全体の印象はあまり変わらなかった
- **画面全体のにじみ（`diff=0.2`）:** F01 では印象の差は小さい
- **透明な所の黒を埋める（`ldil=1`）:** 今の葉や草の絵は、調べた 8 種すべてで透明な所が黒い。ただし埋めても F04 の見た目はほとんど変わらなかった。L27 と同じ結論で、**葉の暗い縁は黒の混ざりより、絵の描き方から来ているらしい**

## アセットの作り方: RO3 の観察
拡大して見えたこと（目で見た判断）。
- **小物:** 大きな形が読め、細かい物は少ない。色の幅は狭く、絵の中に上から下への穏やかな明暗があり、角に細い明るさがある。黒い線はない
- **岩:** 淡い灰緑で、割れ目は細い暗い線だけ。苔は黄緑で、岩との境がにじんで溶ける。こちらの岩は青灰で濃く、苔の境がはっきりしている
- **草の房:** 地面より少し明るい程度の細い葉の束で、固まって帯のように流れる。1 房ずつは目立たない
- **地面:** 模様がほとんどなく、草と道の境は草の房で崩れて溶ける
