# 未解決 1〜3 の検証（L23）
固定した条件: 見本②の地図データ・各見本の基準カメラ（B01・B02・B03、01 は近景 near@B01 と south_coast の基準・近景も）・地形・配置・解像度。変えるのは URL の引数だけ（`ltint`・`gtint`・`llift`・`hemi`・`sunC`・`wrap`・`gblend`・`gbset`）。
数値は refstats（明暗比・彩度・輝度）と rulecheck（材質ごとの比・青の寄り・階調）。**色相は「同じ材質（緑: 色相 0.13〜0.32・彩度 > 0.3）の日なた/日陰の色相」で比べる**（画面全体の日なたの色相は、明るい土の道の割合で動く。B02 は全体の色相が目標に届き、B01・B03 は届かなかったが、緑だけで測ると差は 3〜10° だった）。
