# 第 2 世代の地図に第 3 世代の規則を当てた結果（L24）
目的: 見本②で決めた規則（rulebook.md、L23 の光と色）が、別の場面（草地・林・空き地・浜と崖・町）でも成り立つかを確かめる。
変換: `python3 -I tools/worldart/maps/to_gen3.py orc_meadow south_coast town_plaza forest_path palm_clearing` → `<名>_g3.json`（元の地図は残す）。
地図ごとの調整はしていない（構図・太陽の向き・地面の種類は元のまま、規則の値だけを当てた）。

## アセット（Blender で一から作り直した）
- `build_assets.py` で全 63 アセットとテクスチャをソースから作り直した。作り直しは決定的（同じ入力から同じ GLB）で、変わったのは新しく作った物と、古いまま残っていた `tarp_tent`（ソースが新しくなっていた。この地図には使わない）。
- **もみ 第 3 世代 `fir3_a`・`fir3_b`**（新規）: 見本（B03・R03）のもみは「短い小枝が詰まった、先のとがった円錐」。第 2 世代 `fir2` は細長いシダの葉で、羊歯に見えた。
  絵 `frond_fir3`（textures2.py）: 中軸に沿って、外へ下向きに垂れる 3〜5 裂の葉片を根元から先へ重ね、しずく形をほぼ埋める（輪郭の中の埋まり 99%）。先ほど明るい黄緑、根元は暗い青緑。
  形 `fir3()`（build_assets.py）: 22 段、段ごとに周りを 0.42m おきに埋める長さ 0.55〜1.35m の小枝を、外へ垂らす。幅 ≈ 高さの 0.55（Hc で幅 2.3・高さ 4）。法線は軸から外向き + 上（04）、頂点色は下・内側が暗い青緑、上の先が明るい黄緑（08）。
- **小石 `rock_s`**（新規）: 面のある `rock_c`（rock() のフラットシェーディング）をやめ、なめらかな形（smooth_rock）に（rulebook 7.2）。
- 置き換え（to_gen3.py の REP）: maple_* → maple2_*、fir2_* → fir3_*、rock_c → rock_s。

## わかったこと
**場面をまたいで成り立った規則**
1. **日陰は青寄り**（青い空の光 + ACES をやめる）: 第 2 世代は 5 枚とも暖色の日陰（青の寄り 0.76〜0.94、見本はどれも 1.01 以上）。第 3 世代は 4 枚で見本の範囲（1.20〜1.25）。町の石は暖かいクリーム → 青灰になる（見本 E04 の観察と同じ）。
2. **崖は地形の岩肌**: forest_path・orc_meadow・south_coast の岩の柱の列が、ひと続きの岩肌に。
3. **もみ・小石の第 3 世代の形**: どの地図でも、羊歯に見えたもみが詰まった円錐に。
4. **緑の色相**: 第 2 世代は ACES の黄へのずれで 59〜65°（見本 67〜78° より黄）。第 3 世代は palm_clearing・south_coast・町で見本 ±2〜8° の中。

**場面をまたいで成り立たなかった・残ったこと**
1. **暗部が浮き、明部が届かない**（全部の地図）: p0.5 が 21〜41（見本 14〜32）、p99.5 が 204〜241（見本 209〜253）。見本②（L23）でも同じ傾向（p0.5 39〜45）。空の光 1.6 と露出 1.25 の組が、見本②の B 系列（スマホ撮影で黒が浮く）に合わせた値になっている可能性がある。明暗比自体は第 2 世代と同じ（2.5〜3.0）で、見本の R 系列（3.1〜3.2）には届かない。
2. **orc_meadow の緑が強い**（77°、見本 67〜68°）。forest_path も 74°（見本 67〜72°）。見本②で決めた地色（草 [2.15,1.6,0.5]・葉 [1.18,1.0,0.76]）が、太陽の向きの違う地図（方位 135°）では緑に出る。太陽の向きで日なたと日陰の面積が変わるため。
3. **町の草の日陰が青すぎる**（1.49、見本 1.06〜1.11）。石畳の照り返し（地面からの光 `#6f7468`）がなく、青い空の光だけが日陰に入るため。町は地面の照り返しを暖色にする必要がある。
4. 南の海辺: 崖を地形の岩肌にしたため、水際の崖の面が暗い岩の帯になった。見本 C01 の浜の崖と、まだ比べていない。

## 次に確かめること
- 空の光・露出を、B 系列（スマホ撮影）ではなく C・D・E・R 系列（動画）の p0.5 / p99.5 でも合わせ、両方の見本の中に入る値を探す。
- 緑の地色を、太陽の向き（方位）ごとに変えるべきか、色相の測り方（日なたの面積）を直すべきかを切り分ける。
- 町の地面の照り返しの色。
