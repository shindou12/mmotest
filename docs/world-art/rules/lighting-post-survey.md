# 調査: 光と仕上げ（全 23 枚の見本から、L21）
比は sRGB の値どうし（線形ではおよそ比^2.2）。撮影の差（B はスマホ: 黒が浮く p0.5 ≈ 44、0.8 倍、ぼけ。動画は圧縮・色のにじみ 2px・UI の影）を避けるため、**同じ画面の同じ材質の日なたと日陰の比**で測る。

## 太陽の向き（0° = 影が右へ、90° = 上へ）
D01・D02 ≈153°（左上）、C04 ≈184°（左）、R04 ≈190°（左やや下）、B01・B03 150〜180°、E04 ≈125°、C03 ≈0〜350°（右）、D03・D04 は左上からの光の筋。
→ **向きは地図ごとに違う。** 変わらないのは「横から・逆光ぎみ、高度 ≈35〜55°、影は画面を横切って長い。カメラへまっすぐ向く影も真上の昼の光もない」。人物の影はほぼなく、足元の薄い接地の影だけ。

## 影の縁（10〜90% の幅）
C04 枝先 8〜11px、E04 塔 ≈15px、C03 もみ ≈16px、B01 ヤシ 18〜24px、R01 木漏れ日の縁 20〜30px、D03 崖の影 ≈45px、小物（木箱・岩）は接地の陰 6〜10px。**硬い縁はない。** 細い枝の影は真っ暗にならない（日なたの 0.72、面の影は 0.6）。
広葉樹の樹冠の影は**木漏れ日のまだら**（50〜100px の明るい穴、縁はやわらかい）、もみ・ヤシは形の読める塊の影。

## 仕上げ
- 遠くのもや: 青灰〜薄紫（C04 (110,122,147)・(177,183,189)、R03 (93,120,142)）。遠くまで見える場面だけ、画面の上 10〜20% の彩度が落ち（C04 0.49 → 0.12）暗部が浮く。近い場面（R04・D02）にはない。
- ぼけ: 上の帯（y < ≈15%）に 2〜4px の弱いぼけ（もやと一緒）、下の帯も少し。中央はくっきり。（測定は目視、確度 低〜中）
- 周辺減光: プレイ中はなし（あっても ≈10%）。カットシーン（E03、B04）は強い。
- ブルーム: 発光物（松明・水晶・きのこ）に小さな光の輪（≈20px）。D03・D04 の林に暖かい光の筋と黄緑の光だまり。日なたの砂に大きなブルームはない。
- 階調: 屋外 p0.5 = 20〜45、p50 = 60〜190、p99.5 = 190〜250。黒は浮き、明部はほとんど飛ばない、なだらかなフィルム調。洞窟は 0 まで沈む。

## 鏡面・縁の光
岩・葉・石畳に鏡面反射は見えない（つや消し）。葉は高さと上向きの明暗で読ませる（もみの先は明るい黄緑、内側は暗い青緑）。縁の光・逆光の透けは光の筋の場面以外にない。

## 洞窟
環境の光は暗い暖かい茶か無彩の紫（V 0.08〜0.28、E02 壁 72,39,24、E01・D05 ≈40,38,37）。穴は真っ黒。松明（E02）は (249,159,63) の発光と 20px の輪で、壁を照らす光は弱い。色のアクセントは発光する水晶・きのこ。E03 は暖かい光だまり 1 つと枝の影の模様、残りは輝度 ≈30、手前は黒い影絵と周辺減光。
