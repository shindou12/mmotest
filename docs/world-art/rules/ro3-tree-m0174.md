# RO3 の広葉樹はどう作られているか（M-0174）

ユーザーの依頼は、RO3 の木に寄せることではなく、雰囲気とデザインの作り方を解明すること。ゲーム画面の拡大から仮説を立て、自分たちの木で 1 つずつ試して、効いたものと効かなかったものを分けた。

RO3 の中身（モデルやテクスチャ）は見ていない。ここに書く「作り」は、画面から推定して同じ印象が再現できたもので、実物と同じ作りだとは確かめていない。

## 結論: 雰囲気は 5 つの決まりでできている

1. **葉は小さな星で、指が細い。** 樹冠の幅に星が 10〜15 個並ぶ大きさ。指は細くとがり、1 枚はほぼ単色。筆跡も葉脈もない
2. **奥行きは葉の絵でなく、同じ星を重ねた層で出す。** 暗・中・明の 3 層。層の間は暗い影で区切られ、手前の明るい星が浮く
3. **樹冠は球でなく傘の段。** 細い幹のまわりに傘が 2〜3 段。段の間から幹が見える
4. **隙間の奥は暗く、向こうが透けない。** 中に暗い塊があるように見える
5. **明暗は樹冠全体で太陽の側から反対へ流れる。** 葉 1 枚の明暗より、この大きな流れが立体感を作る。色相はあまり変えず明るさで落とす

木ごとの色の差（黄緑、緑、青緑）は、同じ絵に色を掛けるだけで出せた。

## 確かめた順

| 版 | 試したこと | 結果 |
| --- | --- | --- |
| `p1` | 傘の段、太い指の星を疎らに（Luna の絵） | 失敗。格子の籠と水玉に見える。頂上に穴 |
| `p2` | 同じ絵を重ねて密に、暗い塊を入れる | 穴は消えたが白っぽい。太い指のせいで別の植物に見える |
| `p3` | 指の細い小さな星を 3 層、段の間を開ける | **一気に近づいた。一番効いた変更** |
| `p4` | 樹冠全体の明暗を焼く、層の差を縮める | 中央の木で日陰の側が出た。層の差を縮めたぶん奥行きは減った |

## 間違っていたこと

- これまでの太い房や筆跡の方向は、RO3 の作りと違っていた。手描きらしさを葉の絵の中に求めていたが、RO3 の葉の絵は単純で、印象は重ね方と全体の明暗から来ている
- `maple2_t` の星模様を欠点と判断していたが、小さな星そのものは RO3 と同じ方向だった。違っていたのは大きさ、指の太さ、層の数
- 葉の間隔の計測は地面の色が混ざって当てにならなかった。色の計測も大まかな目安にとどまる

## 未解決

- `p3`・`p4` の葉の絵は確認用に機械で描いたもの（`tools/worldart/star_proc.py`）。手描きの絵で同じ印象が出るかは未確認
- 層の明暗は `p3` が強すぎ、`p4` が弱い。適切な強さは未定
- 焼いた明暗は太陽の向きに合わせるので、木を回して置けない（試しでは回転 0）。向きごとに作るか、シェーダーで出すかは未定
- 幹は暗くする指定が効かず、オレンジのまま。段の間に見える塊の面が平らに見える所も残る
- 枝の段の形は単純で、RO3 の垂れ下がる裾には届いていない
- 三角形は 482〜598。`lf_test` の 1 画面だけで、実際の地図、たくさん置いたときの重さ、Godot は未確認
