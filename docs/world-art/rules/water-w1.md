# 水の規則 w1（案、2026-10-22）

見本: `art/ref/W01〜W05.webp`（RO3 の南門の海辺の動画のキャプチャ。ユーザーが渡したもの。W04 は水際の寄り）。
状態: **条件付き**。湖（`f1_lake`）では沖・浅瀬の色が見本の範囲に入った。海辺（`south_coast_g3`）では波の線が岸の形に沿うが、見える水が岸から 5m 以内の細い帯だけで、浅瀬が明るすぎる（砂比 1.01、見本 0.77〜0.88）。浅瀬の色はユーザーの判断で W02・W04 の明るい水色に寄せる（2026-10-22）。

## 見本から読んだこと
1. 沖は砂より暗い青（砂の 0.6〜0.75 倍、hue 195〜210°、彩度 0.4〜0.5）。波の筋で明るさが少し揺れ、まばらな白いきらめき（横に細長い小さな点）がある
2. 白い泡は**岸に寄せる波の泡**: 波打ち際と同じ形の白い線が岸に沿い、その線と岸の間に崩れた泡が網目のレースで残る。沖に網目はない（ユーザーの指摘、W04 がわかりやすい）
3. 水際の砂は乾いた砂より明るく光る（W01・W04）。第 2 世代は暗くしていた（逆）
4. 浅瀬の色は見本で分かれる: W02・W04 は明るい水色、W01・W05 は暗い灰緑（底が沈んで見える）。どちらにするかは未定

## 規則（w1）
| 項目 | 値 | 根拠 |
|---|---|---|
| 沖の色 | 日なたの砂の 0.6〜0.75 倍の明るさ、hue 195〜210°、彩度 0.40〜0.50 | W01〜W05 |
| 浅瀬の色 | 砂の 0.77〜0.88 倍、hue ≈182°、彩度 ≈0.28（明るい水色） | W02・W04（ユーザーの選択） |
| 色の帯 | 底までの深さか、岸からの距離（2.5〜7m）の深い方で浅瀬 → 沖 | 底の浅い海でも沖が青くなるように |
| 岸の泡 | 岸からの距離場の帯: 岸と同じ形の線が岸から 0.6〜2.0m を寄せて引き（12.5 秒）、線と岸の間の細い帯だけに網目のレース。泡は半透明（白で塗りつぶさない、混ぜる量 ≈0.45〜0.6） | W01・W04、定番の shoreline distance field（sources.md） |
| 水際の砂 | 水の上の ≈0.5m の帯だけ少し明るい。水の下の底は沈んで暗い | W01・W04 |
| 影 | 水面は影を受けない | 透ける水面に VSM の影が縦の筋になった。見本でも水面に木の影はほぼ落ちない |
| 沖の模様 | 細かい明暗の粒（横 0.3〜0.4m・縦 0.15〜0.2m、横長 1.5〜2.8、揺れ 0.045〜0.066）に、明るい短い波頭がまばらに乗る（明るさの分布は明るい側に偏る: 歪度 1.3〜3.4）。浅瀬では揺らさない | W01・W02・W05 を `tools/worldart/water/` で測った |
| 沖の反射 | 横に長い波の法線で、太陽の映りをしきい値で切った小さな白い点がたまに出る程度（トゥーンの鏡面反射。ユーザーの判断で少なく小さく）と、控えめな明るみの筋、見る角度で空の色（フレネル）。光の当たり方に掛けず足す（emissive） | W01・W05、定番の toon specular・fresnel（sources.md） |

## 実装（`public/worldart/world.js` の `waterMaterialW1`、地図の `terrain.water.rule: "w1"` のときだけ。URL の `wrule=0/1` で入／切）
- 深さの帯 `shallowW1`（既定 #5b8f99 → 湖で #629aa3）→ `colorW1`（既定 #40778f）。帯の深さ `deepAt`（URL `wdeep`）。岸からの距離は height.png の G（`build_map.py` の `shore_distance`、上限 8m）
- 寄せる波の線: 岸からの距離の等しい線が 12.5 秒で沖から岸へ寄せ、1 つ前の線が岸寄りで薄れる。泡の届く距離 `causticAt`（m、URL `wcaus`）
- 線と岸の間のレース: ゆがめた細胞の縁（`wCell`）
- 水際の帯 `bandAt`（URL `wband`）、きらめき `glint`（URL `wglint`）
- 地面: 水際の砂を明るく（`uWater.y = 2`）

## 経過（south_coast_g3 B04、`.agents/water/`）
| 版 | 変えたこと | 結果 |
|---|---|---|
| w1a | 深さの帯・底の光の網・淡い帯・きらめき | 沖まで網目が出た（海の底が 1.2〜1.6m で、沖の深さに届かない） |
| w1b〜c | 帯の深さを浅く、沖を青く | 沖 0.76・190°（目標の範囲の端） |
| w1d〜f | 網目を「底の光」から「泡のレース」に、細く小さく | 見本の網目に近づいたが海全体に出る |
| w1g | 寄せる波の泡（岸と同じ形の線＋線と岸の間のレース） | 線は岸の形になった。底がでこぼこで線が島に切れる → 湖のなだらかな岸で確かめる |
| 湖 v01〜v04 | 湖の地形で w1。底の深さの線 → 焼いた岸からの距離場の線に | 線が岸と同じ形の一本につながった。縦の筋は水面の影（VSM）→ 影を受けない |
| 湖 v05〜v09 | 見本の数値に合わせて色を調整、浜の砂を rulebook 6.1 の色に | 沖 砂比 0.61・195°・0.45、浅瀬 0.78・181°・0.28（範囲内） |
| 湖 v10 | 浜を高さではなく湖の縁からの距離で塗る | 起伏の低い所すべてに砂が出ていたのが、湖のまわりの帯に |
| 海辺 w1h〜i | 海辺を距離場つきで組み直して w1 | 線は岸に沿う。浅瀬が明るすぎる（1.01）→ 条件付き |
| 湖 v12 | 泡の届く距離 3m → 1.3m（ユーザーの指摘: 網掛けが広く、泡の線が岸から遠い） | W04 と並べて、線とレースが岸のすぐそばの細い帯に |
| 湖 v13〜v17 | 泡の線を 2.0m に戻し半透明に、沖の反射（トゥーンの鏡面反射・フレネル）を足す（ユーザーの指摘: 近すぎ・白すぎ・沖の反射が足りない） | W05 と並べて、横長の波の筋と小さな横長のきらめき。沖 砂比 0.67・198°、浅瀬 0.80・184°（範囲内） |

| 湖 v19〜v21 | 画像を数値で分析し直した（`tools/worldart/water/`: 白い点の数・大きさ、模様の粒、明るさの分布）。きらめきは既定 0、大きな波の明るみはやめ、粒を合わせたノイズと明るい波頭に | 粒 15×5.2・横長 2.9・揺れ 0.046・歪度 2.2（見本の範囲）。v17 は筋がそろいすぎ（0.77）・細かいくり返し（間隔 12）・歪度 0.19 だった |
