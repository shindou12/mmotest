# 調査: カメラと尺度（全 23 枚の見本から、L21）
測り方: 見本の画素を直接測る（ゲーム部分の画素、B は x−176）。切り抜きは作業場所に置き、ここには数値だけ残す。Hc = 人物の画面の高さ（物差し）。

## 人物の画面の高さ（ゲーム部分の高さに対する割合、乗り物なし）
B01 0.114 / B03 0.115 / C02 0.115 / C03 0.133（逆立った髪）/ D02 0.122・0.124（奥の Kafra 0.098）/ D01 0.120 / D04 0.106 / D05 0.118 / E03 0.116・0.111 / E04 0.097・0.096 / R01 0.102 / B04（カットシーン）0.137。
→ 中央値 0.115、幅 0.096〜0.13。同じ人物が D02 0.123・D04 0.106 → ズームは ±12% ほど。俯角と画角は地図で変わらない。人物は 4 頭身で、1.7m より Hc を物差しにする。

## 俯角と画角
- 木箱（D02 1372–1440×723–812）: 上面/幅 0.71（sinθ）、前面/幅 0.70（cosθ）→ θ ≈ 45°。樽の口（R04）の短径/長径 0.64 → θ ≈ 40°。
- 縦の線の開き（E04 の柱 tan 0.23・0.128、C03 の灯柱 tan 0.085）と、同じ物の画面の上下での大きさの比（C03 の灯柱 1.12 倍、E04 1.05 倍）→ 焦点距離 ≈ 3000〜3500px（高さ 1079）→ **縦の画角 ≈ 18°（15〜22°）**。画面の下の物は上の物の 1.1〜1.45 倍しかない（望遠で、平行投影に近い）。
- 画面の縦は ≈ 6 Hc、映る地面は奥行き ≈ 8〜9 Hc・幅 ≈ 15 Hc。
- B04（カットシーン）は ≈ 1.2 倍近く、俯角 ≈ 45〜50°。

## 地平線
どの画面にも空・地平線はない。画面の上端を埋めるもの: 樹冠（B01・B02・D04・R02）、崖・岩壁（B03・D05・E01〜E03、上 30〜50% が黒に近い岩）、建物と屋根（C02・C03・E04）、地面の続き（D01・D02・C04）、崖の向こうの平らな青い水・虚空（R01・R04）。雲なし。
