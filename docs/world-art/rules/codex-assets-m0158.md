# Codex の手描き風アセットの評価（M-0158、2026-11-04）

対象はユーザーが Codex で作った 12 種類（ブランチ `codex/painterly-session-assets`、`art/session-assets/2026-11-04-painterly-01a197da`）。一時の地図に今のアセットと同じ位置で置き、第 3 世代のカメラ（俯角 45°・画角 18°・距離 33m）と光で撮った。上が Codex、下が今の版（`art/shots/codex_eval/`）。荷台は三角形数と手順書だけで、撮っていない。

## 判断: 作り方は採用する。アセットはそのまま入れず、物ごとに直して入れる

**作り方で良かった所**
- 灰色の形を何案も比べてから塗る。岩は 6 案から選び、262 三角形でも塊に読める。M-0155・M-0157 の「ブロックアウトの質が結果を決める」と同じ結論で、こちらの方が手順として具体的。
- 形は大きな面まで、細部は絵に描く。木箱の X は絵にして 684 → 444 三角形でも、ゲームのカメラで X が読める（M-0156 の「形は面、細部は絵」と一致）。
- 光を焼かず、色面と筆跡だけを焼く。第 3 世代の光の中で破綻しない。

**直す所（作り方の決まりにする）**
1. 確認はゲームのカメラと光でする。スタジオの光の見た目と違う。切り株は金茶色の皮が赤紫にくすみ、切り口は白く飛ぶ。
2. 色の絵だけに持たせる。ゲームの材質は three.js・Godot とも色の絵しか読まない（`fixMaterial`、`_material_for`）。切り株の法線・AO・粗さ、灯籠の発光は、今は捨てられている。
3. 絵の大きさはカメラから決める。距離 33m で 1m ≈ 83 画素なので、木箱は 66 画素、切り株でも 180 画素。2K〜4K は多すぎる。小物 512、大きい物 1K で足りる見込み（未検証）。GLB は今の版の 7〜30 倍ある。
4. 三角形の上限を決める。木は 16,000〜19,500 で、今の `maple2_t`（708）の 20 倍以上。草原の木 700 本に使うと、それだけで 1,000 万を超える。荷台も 16,380 ある。
5. 寸法は rulebook 3.2 に合わせる。灯籠・切り株は大きい。

## 物ごとの評価（33m のカメラ）

| 物 | 評価 | 入れ方 |
|---|---|---|
| 木箱 | 今の版より明らかに良い。見本の木箱に近い | 最初に入れる。絵を縮めるだけ |
| 岩 | 塊に読める。上面が白く飛び、面が宝石のように硬い | 上面の色を下げ、角の面を少し崩す |
| 柵 | 太さと絵は良い。ただし長さが固定 | 絵と太さを M-0156 の組み立て式へ移す（M-0157 と調整） |
| 灯籠 | 形と筆跡は良い。屋根が大きく重い。灯りの発光が消える | 縮める。発光は材質側の対応が要る |
| 切り株 | 根の形はこれまでで一番良い。色がくすみ、三角形 9,216 | 色を直し、2,000 前後へ減らす |
| ヤシ | 幹の量感が良い（2,004 三角形）。葉は見本より幅広 | 試す価値あり |
| 広葉樹 3 種・もみ | 形は読めるが、大きな色面のかたまりで葉に読めない。粘土や玩具に近く、見本の細かい葉や周りの茂みと並ばない | 今は入れない。幹の形と色の分け方だけ参考にする |

今の広葉樹も丸い板が目立つので、木の解決にはなっていない。木は別の研究にする。
