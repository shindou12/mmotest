# 岩の曲率と AO を頂点色に焼く実験（M-0153、2026-11-02）

きっかけ: Stylized Asset Suite（Blender のアドオン）の紹介図。アドオンは使わず、「曲率と AO を色の塗り分けに焼く」考え方だけを試した。

## 試したこと
- `tools/worldart/blender/rock_mask.py`: 曲率と自己 AO（BVH の光線 48 本）をマスクにして、`Col` 頂点色に掛ける。光ではなく色として焼く。
- 対象は `outcrop_a`（1280 三角形）。`build_assets.py --rockmask <強さ>` のときだけ掛かり、指定しなければ GLB はバイト単位で今と同じ。
- f1_field の視点 F04 で、強さ 0 / 0.5 / 1.0 を比べた。

## 結果
- 岩の画素の平均の差 |ΔL|: 0→0.5 が 1.31、0.5→1.0 が 1.35、0→1.0 が 2.66。頂点色は描画まで届いている。
- 強さ 1.0 で、縁に柔らかい暗い帯が入り、丸みは少し増す。ただし画面全体で見ると差は小さく、岩の印象は変わらない。

## 判断: 既定には入れない（棄却ではなく保留）
- **焼いても形以上のものは出ない。** この岩はなめらかに膨らんだ塊で、折れ目がないため、曲率のマスクに拾うものがない。紹介図の切り株は、焼く前の形にすでに溝と根がある。
- 見本 B03 との差で大きいのは、色の塗り分けより形（刃形の板と折れ目）と、割れ目が細い黒い線で描かれていること、硬い影の形。
- 頂点色は 25cm ほどの間隔なので、細い縁の光や隙間の暗さは描けない。テクスチャに焼く価値が出るのは、形に細部を足した後。

## 次の仮説（未検証）
岩の形に中くらいの折れ目を足してから、同じマスクを焼く。縁が明るく隙間が暗くなり、割れ目の線を薄くできるなら採用を考える。
注意: `rulebook.md` 7.2 は小物の岩を「なめらかに膨らんだ形」と決めており、`ab-L27.md` も見本の岩を丸い塊と書いている。一方で 7 章の崖は刃形の板。先に崖寄りの大岩だけで試す。
