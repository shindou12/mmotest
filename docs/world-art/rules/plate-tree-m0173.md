# 手描きの房の木を、太い幹と塊の形に組み直した記録（M-0173）

ユーザーの依頼は「自分で評価して、案を考えて直す」。柱に見えた `maple2_t` の形をやめ、太い幹と枝の上に房の塊を載せる木を新しく組んだ。三角形を今の木と同じに保ったまま、見本の形に大きく近づいた。

## 結果
- 624〜720 三角形（`maple2_t` は 708）。塊 5〜6 個、1 塊に板 23 枚と芯の球
- 形は 3 種（`--layout round / wide / tall`）。7 本並べても破綻しない
- GLB は約 1.9MB（絵 1024 の PNG と幹の絵が各 GLB に入る）
- 道具: `tools/worldart/blender/tree_plate_build.py`、`tools/worldart/key_sheet.py` の `--tint`・`--contrast`
- 絵: `art/painted-gen/fan_m0172/line_toned.png`（線画の土台から Luna が描いた絵を、色と明暗だけ調整）
- 比較: `art/shots/tree_m0173/compare.jpg`（左が柱の版、右が新しい版）、並べた画面は `grove.jpg`

## 自己評価と直した順
1. **形が柱:** 一番の差。幹を太く、塊を横へ広げ、奥行きを浅くした。45° のカメラで幹が見える
2. **塊が読めない:** 板の根元を頂点色で暗くし、下の段を垂らして暗くした。塊の間に影ができた
3. **頂上に暗い多角形:** 向こうが透けないように入れた芯の球が大きかった。小さく、低くした
4. **黄色が強くトゲトゲ:** 地図の `foliage.tint` が赤を上げ青を下げるので、絵の方で打ち消し（R 0.84、B 1.12）、明暗を 0.82 倍にした

## わかったこと
- **印象を一番変えたのは形で、次が色、絵はその次。** 絵だけを詰めても RO3 らしさに届かなかった
- **板を面で並べず、塊ごとに段で垂らすと、少ない枚数で量感が出る。**
- **芯の球は透け防止に効くが、見えると一気に壊れる。** 大きさの上限に注意

## 残した差（自己評価）
- 塊の頂上が星や花の形に見える
- 葉の色が明るい黄緑に揃い、木ごとの色の幅がない
- 幹がオレンジ色で単調。節や渦がなく、根も短い
- 奥の古い茂みと並ばない
- 容量。同じ絵を GLB ごとに持っている
- `lf_test` の 1 画面でしか見ていない。実際の地図、たくさん置いたときの重さ、Godot は未確認
