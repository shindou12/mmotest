# 見本の樽を、ブロックアウトの展開図に絵を入れて作る（M-0164、2026-11-04）

岩（M-0163）は不合格だった。札で Luna に形を任せ、見本なしの乱数の塊から始めたため。樽は Opus が Blender を直接動かし、見本から作った。

## 流れ
1. **1 段目:** 見本の輪郭から高さごとの半径を測り、断面を回転する（`tools/worldart/blender/barrel_blockout.py`）。輪郭の重なり 96.6%。
2. **2・3 段目:** 板の幅と厚みのばらつき、硬い谷、傾いたたが、鋲。段階ごとにゲームのカメラで確かめる。
3. **展開図:** 板を順に並べ、たが・縁・ふた・鋲を決まった場所に置く。自分で作った形なので、場所を数値で決められる。
4. **形の情報:** Cycles で奥まり（AO）と角（Bevel と法線の差）を UV へ焼き、色の下絵に重ねる（`tools/worldart/barrel_paint.py`）。
5. **絵:** 下絵と手本を image_gen に入力して 1 枚を生成する（Luna）。板の線のずれは最大 3 画素で、貼るだけで合う。

## わかったこと
- **下絵を入力にすると配置が崩れない。** ずれは数値で測れるので、Luna に判断を任せられる。
- **形の情報を入れると、角の擦れや金属の傷が角に乗る。** 入れない版は全面が同じ塗りだった。
- **明暗を絵に入れても、ゲームの光で破綻しなかった**（樽 1 個での確認）。
- **向かない物:** 岩や切り株のような不定形の物は、展開図が細切れになる。別の方法（Tripo、投影）を考える。

## 失敗と対処
- 色の絵が無い GLB はゲームで真っ白になる。灰色の小さな絵を貼る。
- たがの段差の面を絵の縁に置くと、明るい擦れを拾って白い帯になった。帯の内側の色を使う。鋲の跡の高さも避ける。
- Blender の出力先は絶対パスにする（相対だと C ドライブの直下にできた）。
- Luna は `.agents` の下に書けない。出力先は `art/` の下にする。

## 残り
- 1,104 三角形。見本の目安 600 の約 2 倍。うち鋲が 288。
- 鋲の輪郭は六角形。
- 本番の樽は置き換えていない。絵は 1024 四方で、512 への縮小は未検証。
