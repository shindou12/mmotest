# ワールドアートの規則集（第 3 世代、L25 時点）

このアートスタイル（Ragnarok Online 3 のワールドマップ）を、Blender と three.js で**繰り返し作る**ための規則・数値・判断基準をまとめたものです。
新しい地図を作るとき、直すとき、規則を変えるときは、まずこの文書を読みます。

- 古い文書との関係: `style-spec.md`（第 1〜2 世代）と食い違うところは**この文書が優先**です。食い違いの一覧は末尾の「付録 A」。
- 根拠: 見本 23 枚の測定は `rules/*-survey.md`、入／切の比較は `rules/ab-L22.md`、アイデア 18 項目の状態は `rules/ideas.md`、見本②の作業の記録は `goal-mihon2.md`、失敗の一覧は `pipeline.md` の 5（F1〜F25）。
- 確度の印: **[確定]** 複数の場面で撮って比べ、採用した。**[測定]** 見本から測ったが、実装での確認がまだ。**[暫定]** 1 場面だけで決めた、または値の幅が大きい。**[未検証]** 仮説のまま。

---

## 1. 目的と判断基準

### 1.1 目的
見本を 1 枚似せることが目的ではありません。**どの地図にも当てはまる規則（地面の絵・光・カメラ・アルファ・尺度・配置）を見つけ、手順にすること**が目的です。見本の再現は、規則を測るための手段です（ユーザーの指示、L21）。

### 1.2 規則を採用する条件
次の 4 つがそろったときだけ「採用」にします。どれかが欠けたら「条件付き」か「未検証」と書き、推測で埋めません。
1. **効く向きが見本と同じ**: 入れると見本の特徴に近づく（数値か拡大した画像で示せる）。
2. **複数の場面で成り立つ**: 少なくとも林・草地・崖・道のうち 3 つと、別の地図 1 つ（見本②の B01・B02・B03 と south_coast が標準の組）。
3. **副作用がない**: 他の物（茂み・岩・地面）を崩さない。崩す物があれば、効かせる対象を絞る（例: アイデア01 は草の房だけ）。
4. **見本の範囲に入る**: 数値の目標（13.2）の幅の中。

### 1.3 比べ方の原則
- **絶対値ではなく比で比べる** [確定]: 見本はスマホ撮影（B）と動画（C・D・E・R）が混ざり、明るさ・彩度・細部量が撮り方で大きく違う（輝度 0.36〜0.66、彩度 0.13〜0.55）。撮り方に左右されないのは、**同じ画面の中の、同じ材質の日なたと日陰の比**、色相の関係、明部・暗部の分位点。道具: `tools/worldart/rulecheck.py`。
- **1 回に 1 つだけ変える**: URL の引数か地図の JSON の 1 項目。入／切は地形・配置・カメラ・光・解像度を固定して撮る（`tools/worldart/abshoot.sh` と `abcompare.py`）。
- **1 枚・1 方向で決めない**: 見本と同じカメラ 4 つ + 固定ビュー（斜め・横・俯瞰・歩行者・近景・遠景）で撮り、比較シートで見る（13.1）。
- **差の大きい所から直す**: 評価表（0〜3 点）で一番低い項目を 1 つ直し、全ビューを撮り直す。
- **色相は同じ材質どうしで比べる**: 画面全体の日なたの色相は、明るい土の道の割合（構図）で動く。緑（色相 0.13〜0.32・彩度 > 0.3）の日なたと日陰の色相で比べる（L23: 全体では 0.205 対 0.19 に見えた差が、緑だけでは 3〜10°）。
- **効いているかを先に確かめる**: 新しい仕組みは、値を 2 段変えて画素が変わることを確かめてから測る。L21 の階調の方式は、実は効いていなかった（F25）。
- **見本に見えない物は足さない**: 見本にない効果（逆光の透け・ブルーム・強い周辺減光）は、場面の種類を限って別に扱う。

### 3.3 作り方
- アセットは目標の大きさで作り、置くときの倍率は 0.9〜1.1 に留める。大きく縮めると絵の細かさが画面とずれ、雑音になる（F18）。
- 縮めた木が骨だけに見えたら、倍率で縮めず、**小さく詰まった別の木を作る**（L11: `maple2_s`・`maple2_t`、樹冠 ≈3m、房を 1.5 倍）。

## 4. 光
### 4.1 太陽 [確定（向きの考え方）/ 暫定（高度）]
- **向きは地図ごとに違う**（見本: 左上、左、右など）。変わらないのは「横から・逆光ぎみ。影は画面を横切って長く伸びる。カメラへ真っすぐ向く影も、真上の昼の光もない」こと。
- 高度は 35〜55°。林・草地は **40°**（5m の木の影が ≈6m 伸び、暗い所が画面の 13〜17% になる。55° では 5〜10% しかない）。
- 色はほぼ白 `#fff0d4`、強さ 4.0。黄色い太陽にすると葉まで黄土色になる（E17）。
- 人物の影はほぼなし（足元の薄い接地の影だけ）。

### 4.2 空の光と地面からの照り返し [確定]
- 半球光: 空 `#a9bfdc`（青）、地面 `#6f7468`、強さ **1.6**（L23。2.1 では明暗比 2.2、1.6 で 2.4〜2.6）。
- 日陰は**必ず青寄り**: 同じ材質の日陰の B/R の比が、日なたに対して 1.02〜1.4 倍（砂 1.02〜1.08、草・土 1.16〜1.37、灰の石 ≈1.25）。暖かい石は日陰で青灰になる。緑がかった日陰・真っ黒な日陰はない。
- 日陰の明るさは日なたの **0.45〜0.65 倍**（sRGB）。
- 2.6（L21）・2.1（L22）では日陰が浅すぎた。灰緑の空の光（`#c4ccc8`、第 2 世代）は、ACES と組むと日陰が暖色になった（L20 の青の寄り 0.73〜0.80）。

### 4.3 影 [確定]
- やわらかい影: VSM、半径 6（`"shadowMap": "vsm", "shadowRadius": 6`）。見本の影の縁は 8〜25px（木・建物）、崖は ≈45px、小物の接地の陰 6〜10px。**硬い縁はない。**
- 広葉樹の樹冠は**木漏れ日のまだら**（葉の切り抜きを影にも使う。`customDepthMaterial` に葉の絵と alphaTest）。もみ・ヤシは形の読める塊の影。
- 画面の外の木の影も構図に使う。地図の `shadow_casters`（映らず影だけ落とす木、名前に `@shadow`）。
- 葉は影を受ける（`foliage.receiveShadow: true`、L07）。房どうしの影で、上が明るく下が暗い段ができる。ただし**もみは暗くなりすぎる**（残課題）。第 2 世代の「葉は影を受けない」（F10）は、丸い房の木の規則。

### 4.4 葉の光 [確定]
- **球状の法線（アイデア04）**: 葉カードの法線を、房・樹冠の中心から外向きにする。切ると草の房に暗い面が出て、樹冠は面ごとの明暗が消えて平たくなる（ab-L22、見本②で画面の 25〜37% が変化）。
- **回り込む光（アイデア05）**: `foliage.wrap 0.5`。葉と草の房の影側を持ち上げる（材質名に leaf・frond・grass を含むものに効く）。**値は 0.25〜0.75 で結果がほとんど変わらない**（L23: 階調 p50 ±2、比は不変）。樹冠の暗い所は落ち影の中で、回り込む光が効かないため。0.5 のままでよい。
- **葉の持ち上げは 0**（`foliage.lift 0`、L23）: 第 2 世代の 0.14（E26、葉の日陰だけを明るくする）は、第 3 世代の青い空の光と線形の階調では樹冠の日陰を浅くしすぎた（B03 の樹冠の日陰 V 0.37、見本 0.22）。0.14 → 0 で明暗比 +0.18、明暗比を浅くしている一番の要因だった。
- **葉の透け（アイデア02）は使わない** [確定]: 固定カメラと太陽の向きでは画素が 1 つも変わらない（ab-L22）。見本にも、光の筋の場面を除いて透けは見えない。`foliage.trans 0`（第 2 世代の地図は 0.3 のまま。効果はない）。

## 5. 階調と色 [確定]
### 5.1 階調
- **線形（露出を掛けて 0〜1 で切る）+ 露出 1.25**（`"tone": "linear"`, `post.exposure 1.25`）。
- ACES は使わない: 明るい所の彩度を落とし、日なたが日陰より青く見える（見本と逆）。
- 輝度だけを曲線で圧縮する方式（`tone: "lum"`）は不採用: 明暗比 1.9〜2.0、明部 180〜194 と見本（2.4〜2.8・217〜231）から遠ざかる（L22）。
- 見本の階調: 屋外の p0.5 = 20〜45、p50 = 60〜190、p99.5 = 190〜250。黒は少し浮き、明部はほとんど飛ばない。

### 5.2 色の作り方
- 仕上げの彩度 0.92（L23。地色の色味で上がった分だけ。全体の彩度を大きく下げない。F9）、地色の彩度 `albedoSat 0.9`、葉の地色の彩度 `foliage.sat 0.95`。
- **地面の草の金色は地色で作る**: `ground.grassTint [2.15, 1.6, 0.5]`（L23。線形の階調では [1.8, 1.6, 0.62] が緑すぎた）。茂った緑の大きな斑（28m 前後のノイズ）`lushTint [0.55, 0.92, 0.95]`・`lushAmt 1.3`・`lushBias 0.12`。草の房も同じ斑の色に従う。
- **葉は地色で色を決める**: 見本の緑の日なたの色相は 68〜72°、日陰は 78〜82°。光や仕上げで色相を動かさず、葉の絵の色か葉の色味 `foliage.tint [1.18, 1.0, 0.76]`（L23 で新設、葉の地色に掛ける）で合わせる（E30）。**太陽を暖色にしても色相はほとんど動かず、日なたが暗くなって明暗比が浅くなる**（L23）。
- **階調の方式を変えたら色相を測り直す**: 第 2 世代の葉・草の色は、ACES の黄へのずれ（10〜15°）を先に打ち消して緑寄りに描いてある（E18）。線形に変えた L22 では緑の日なたの色相が 74〜78° と緑に出すぎ、L23 で地色の色味を足して 70〜74° にした。
- 樹冠の色の階調（頂点色）: 上は黄緑 (1.12, 1.04, 0.74)、下・内側は青緑 (0.78, 0.96, 1.10)。
- 土 `dirtTint [0.92, 1.0, 0.42]`、岩肌 `rockTint [0.92, 0.94, 0.78]`、草の房 `tuftTint [1.12, 1.05, 0.8]`。

### 6.2 材質の境 [測定]
| 境 | 幅 | 形 |
|---|---|---|
| 草 → 土の道 | 0.6〜0.9m | 泥の板の形に沿ってまだら。草の房は ≈1m かけて道へ間引かれ、縁にかぶさるが中央にはない。縁の草は少し黄・オリーブ寄り。**暗い縁取りはない** |
| 草 → 砂・開けた土 | ≈2m | 中間の黄緑のまだら（手描きの塗り分け） |
| 敷石 → 砂 | 1〜2m | 敷石の線が途切れながら消える |
| 草 → 石畳（町） | 0 | 縁石・植え込み・花壇の**メッシュで硬く区切る** |
| 砂 → 岩 | ≈0.5m | 岩の根元の割れ目に砂色が入る |

### 6.3 実装 [確定]
- 地形は 0.5m の格子。頂点色 **R = 土の道、G = 砂/敷石（`ground.alt`）、B = 岩肌（傾きから）、A = 岩肌を残す割合（草の垂れの分だけ下げる）**。
- 境は草の絵の明るさで崩す（筆でなぞったぎざぎざ）。道は `soft`（縁のぼかし）と `jag`（ノイズで崩す量）。
- 草の絵は**三方向から貼る**（上からだけだと崖の面で縦に伸びる。F23）。
- 岩肌は `ground.rockPix: true`: 岩か草かを**画素ごと**に、三角の面の向き（`dFdx`/`dFdy` の外積）で決め、苔は三方向から貼ったノイズの斑で抜く。頂点ごとに決めると、細い崖の面で三角の対角線が歯の列になる（F23）。
- **アイデア03（高さで混ぜる方式）は未導入**。いまは傾き・ノイズ・塗り分けだけ。

## 7. 崖と岩
### 7.1 崖 [確定（林・草地）]
- **崖は「ひと続きの岩肌の一部に草が乗っているだけ」**（ユーザーの指摘、L15）。岩を置いた列（柱・積んだ板）で作らない。置くと灰色の歯の列に見える（F21）。
- 見本の岩肌: 細長いレンズ形・刃形の板（幅 0.4〜0.9m × 長さ 0.7〜1.8m）が**斜面の下る向きにそろう**（1 つの面で 1 方向）。板の間に枝分かれする暗い割れ目、板の上の縁が明るい。林は青灰、砂漠は暖かい灰茶 [測定]。
- 実装: 地形の急な面そのもの + `ground.rock: "face"`（角ばった板と真っすぐな割れ目、割れ目は半分ほど途切れる。4.5m で 1 回）+ 面の起伏 `relief`（0.3〜0.45）+ 苔の斑（rockPix）。面の高い崖（B03）だけ、頂点で草を垂らす `drape 0.5`。
- 崖の上: 草の敷物と茂みが縁から張り出し、苔の筋が割れ目を下る [測定]。崖の上の茂み・草のかぶさりは[未導入]。
- 岩肌の網目（ボロノイ）について: 閉じた網目を等しい大きさで敷くと敷石に見える（F6）。`rock_face` は縦に引き伸ばした大小の胞で、割れ目を途切れさせ、大きな明暗のむらを掛けて、敷石に見えないようにしている。
- 崖の地図の書き方: `terrain.cliffs[]` に `screen`（または `world`）の線、`low`（低い側）、`drop`、`width`、`jag`、`raise`（高い側を持ち上げる）、`radius`（効く範囲）、`relief`、`drape`。

### 7.2 岩・洞窟

## 13. 検証の手順と合格の目安
### 13.1 手順（1 回のループ）
1. 地図を組み立てる: `python3 -I tools/worldart/maps/make_<地図>.py`（あれば）→ `blender -b --factory-startup --python tools/worldart/blender/build_map.py -- <地図>`。
2. 全ビューを同じ条件で撮る: `node tools/worldart/views.mjs <地図> art/shots/<地図>/Lnn B01,B02,B03,B04,oblique@B01,side@B01,top@B01,walker@B01,near@B01,far@B01,oblique@B04,walker@B04`。
3. 比較シート: `python3 -I tools/worldart/viewsheet.py art/shots/<地図>/Lnn art/shots/<地図>/Lnn/sheet.png`（見本 | 撮影 | 3 段階の明るさ、ほかのビュー）。
4. 数値: `python3 -I tools/worldart/refstats.py <画像>`（輝度・彩度・明暗比）と `python3 -I tools/worldart/rulecheck.py <画像>`（材質ごとの日陰/日なたの比・青の寄り・階調・上の帯）。見本も同じ道具で測る。
5. 評価表に 0〜3 点（地形と道、構図、建物・目印、木・岩・小物の形と密度、尺度、色と材質、光と影、奥行きと遮蔽）。一番低い項目を次に直す。
6. 規則を変えたら、入／切で比べる: `sh tools/worldart/abshoot.sh art/shots/ab` → `python3 -I tools/worldart/abcompare.py <切> <入> <拡大.png>`。
7. 記録: `goal-<地図>.md`（ループの記録・評価表・差分一覧）、`rules/ideas.md`（アイデアの状態）、失敗は `pipeline.md` の 5、規則が変わったらこの文書。撮影は `python3 -I tools/worldart/pack_shots.py <フォルダ>` で webp にしてコミットする。
8. 歩いて確かめる: 比較ページ（`tools/worldart/compare/`、Artifact「見本② 版くらべ」）で版を切り替えながら同じ場所を見る。
