## 支配的な因子（どれが画面の印象を一番決めるか）

| ID | 仮説 | 予想される画面の変化 | 状態 | 根拠 |
|---|---|---|---|---|
| H1 | **光と影の配置**が一番効く。低めの太陽ひとつと、画面の外の物が落とす大きな投影影が明暗の構図を作る | 影の配置を変えると、同じアセットでも「それらしさ」が大きく変わる | 未検証 → E03 | 〔観察〕全場面で大きな投影影。〔計測〕輝度比 3.1〜3.4 |
| H2 | **形と葉の読める大きさ**（アルファ抜きの葉カード、杭、石畳）が効く | 葉の形が読めないと「手描きのブロッコリー」に見える | 未検証 → E04 | 〔観察〕R02/R03 の葉 |
| H3 | **色の配分**（日なた=黄、日陰=緑、彩度 0.4）が効く | 彩度と影の色相を外すと、別のゲームに見える | 未検証 → E02 | 〔計測〕先行研究は彩度 0.6〜0.7 でずれている |
| H4 | **カメラ**（透視、俯角 45〜55°、空なし）が前提を決める | ここが合わないと他の比較ができない | 先に固定 → E01 | 〔観察〕 |
| H5 | **地面の立体の草の房**が質感を決める | 房をなくすと、地面が平らな絵に見える | 未検証 → E05 | 〔観察〕R01 下 |
| H6 | **奥と手前のぼけ**（被写界深度）が奥行きを決める | ぼけを切ると、ジオラマ感が消える | 未検証 → E06 | 〔観察〕R02, R03 |

## 競合仮説（同じ見た目を説明する別の方式）

| ID | 対立する説明 | どちらかを決める実験 |
|---|---|---|
| C1 | 影の中の明るさ: (a) 環境光（半球光）が強い / (b) 影そのものの色を付けている（影の色をシェーダーで指定） | E02: 半球光だけで色相 80〜98°・彩度 0.4 の影が出るか |
| C2 | 葉の陰影: (a) カードの法線を樹冠の中心から外向きにした実時間の光 / (b) テクスチャと頂点色に焼き込んだ陰影 | E04: 法線を外向きと板の向きで比べ、焼き込みのみとも比べる |
| C3 | 奥のぼけ: (a) 被写界深度 / (b) 距離の霧 / (c) ティルトシフト（画面の位置でぼかす） | E06 |
| C4 | 地面の明暗: (a) テクスチャに描き込んだ明暗 / (b) 実時間の影だけ | E03 で影を消したときに参考の明暗がどれだけ残るか |
