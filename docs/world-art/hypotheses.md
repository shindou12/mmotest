# 仮説一覧

状態: 採用 / 棄却 / 未検証 / 一部採用。根拠の種類: 〔観察〕画像から、〔計測〕refstats、〔実験〕撮影した比較、〔外部〕資料。

## 支配的な因子（どれが画面の印象を一番決めるか）

| ID | 仮説 | 予想される画面の変化 | 状態 | 根拠 |
|---|---|---|---|---|
| H1 | **光と影の配置**が一番効く。低めの太陽ひとつと、画面の外の物が落とす大きな投影影が明暗の構図を作る | 影の配置を変えると、同じアセットでも「それらしさ」が大きく変わる | **採用**（E03） | 〔実験〕影を消すと明暗の構図が消える |
| H2 | **形と葉の読める大きさ**（アルファ抜きの葉カード、杭、石畳）が効く | 葉の形が読めないと「手描きのブロッコリー」に見える | **採用**（v05→v06、E04） | 〔実験〕葉を大きくすると読める房になる |
| H3 | **色の配分**（日なた=黄、日陰=緑、彩度 0.4）が効く | 彩度と影の色相を外すと、別のゲームに見える | **採用**（E02） | 〔実験〕光の色と地色の彩度で合う。仕上げの一律の彩度は棄却 |
| H4 | **カメラ**（透視、俯角 45〜55°、空なし）が前提を決める | ここが合わないと他の比較ができない | 暫定（E01: 25°/52°/22m） | 〔観察〕町の縦線 |
| H5 | **地面の立体の草の房**が質感を決める | 房をなくすと、地面が平らな絵に見える | 弱い（E05） | 〔実験〕消しても差が小さい |
| H6 | **奥と手前のぼけ**（被写界深度）が奥行きを決める | ぼけを切ると、ジオラマ感が消える | 一部採用（E06） | 〔実験〕細部量が見本に近づく |

## 競合仮説（同じ見た目を説明する別の方式）

| ID | 対立する説明 | どちらかを決める実験 |
|---|---|---|
| C1 | 影の中の明るさ: (a) 環境光（半球光）が強い / (b) 影そのものの色を付けている（影の色をシェーダーで指定） | E02: (a) で出た（日陰 90°/0.47/0.21）。(b) は未検証 |
| C2 | 葉の陰影: (a) カードの法線を樹冠の中心から外向きにした実時間の光 / (b) テクスチャと頂点色に焼き込んだ陰影 | E04: (a) を支持（板の向きにすると崩れる）。焼き込みのみは未検証 |
| C3 | 奥のぼけ: (a) 被写界深度 / (b) 距離の霧 / (c) ティルトシフト（画面の位置でぼかす） | E06: (c) 画面位置のぼかしで細部量が近づく。(a)(b) は未検証 |
| C4 | 地面の明暗: (a) テクスチャに描き込んだ明暗 / (b) 実時間の影だけ | E03: 影を消すと明暗の塊がほぼ消える → (b) 実時間の影が主 |

## 先行研究（docs/ro-look-method.md）の主張と検証状態

| 先行研究の主張 | 今回の判定 | 根拠 |
|---|---|---|
| 光はやわらかく、影の中も明るい（半球光 1.3） | **棄却**。輝度比 2.4 はゆるい。見本は 3.1〜3.4、空と太陽の比 1:2.4 で合う（E02） | 〔計測〕 |
| 彩度 0.88〜1.06 の仕上げ | **棄却**。仕上げではなく地色の彩度 0.7 と光の色で作る（E02） | 〔計測〕 |

| 葉カードの法線を外向き | **採用**（E04-d で崩れる） | E04 |
| テクスチャを全部 canvas で描く・外部モデルなし | 今回は Blender でアセットを作る。テクスチャは Python で描いて Blender で貼る | 指示 |
