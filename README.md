# 浮遊城エテルナ（プロトタイプ）

友達5人くらいで遊ぶ、10階層を登るブラウザMMOの試作です。
three.js で描画し、BGM・環境音・効果音はすべて WebAudio でその場で合成しています（音声ファイルは使っていません）。

## 起動

```bash
npm install
npm start
# → http://localhost:8080
```

- 同じLANの友達は `http://<ホストPCのIP>:8080` を開けば同じワールドに入れます。
- 外のネットの友達とは、ポート開放するか、`ngrok http 8080` のようなトンネルを使って URL を共有してください。
- サーバーにつながらないときは、自動でブラウザ内のソロモードになります（`?solo` を付けると強制的にソロ）。
- PCが重いときは `?low` を付けるとブルームと影を切った軽量モードになります。

## 操作

| キー | 動作 |
|---|---|
| WASD | 移動 |
| マウス | 向き・狙い |
| 左クリック | 通常攻撃（3段コンボ、3段目が強い） |
| 左クリック長押し → 離す | 強攻撃（溜めるほど強い。武器種ごとに技が違う） |
| 右クリック / E | 武器スキル（武器ごとに付いているスキル）。盾槍は E |
| 右クリック長押し | 盾槍のみ：ガード（正面からの攻撃を軽減。構えた直後はジャストガード） |
| 1 / 2 | スキルツリーで覚えたスキル |
| Space / Shift | 回避ロール（無敵時間あり。クールタイムは装備重量で変わる） |
| Q | ポーション（町・野営地で補充） |
| I / Tab | 装備・インベントリ |
| K | スキルツリー |
| M | エリアマップ |
| F | 調べる（転移門・NPC・レバー・宝箱・共有ボックス） |
| ホイール | ズーム（寄るほど低い角度から見る） |
| Esc | 設定（音量・画質など） |
| Enter | チャット |

### スマホ（横持ち）
スマホで開くと、自動でタッチ操作になります（PCで試すときは `?touch` を付けます）。縦持ちのときは「横向きにして」と案内が出ます。

- **左側**：アナログスティックです。左の好きな場所に親指を置くと、そこが中心になります。倒した量で歩く速さが変わります。
- **右側**：半透明のボタンです。いちばん大きい攻撃ボタンの周りに、ほかのボタンが並んでいます。
  - **攻撃**：タップで通常攻撃、長押しで強攻撃です。
  - **スキル（武器スキル・1・2）**：離した瞬間に発動します。
  - 狙いは自動で、近くの敵（スティックを倒している方向を優先）を狙います。狙っている敵の足元に赤い輪が出ます。
  - 攻撃・スキルのボタンを**押したまま引っぱる**と、その方向に狙えます（アローレインは引っぱった距離の場所に降ります）。真ん中に戻すと自動の狙いに戻ります。
  - ほかに、回避、ポーション、ガード（盾槍のみ）があります。近くに調べられるものがあると「調べる」ボタンが出ます。
- **右上**：装備・スキル・マップ・チャット・設定のボタンです。
- **ズーム**：画面を2本指でつまみます。
- **インベントリ**：1回目のタップで詳細が出て、「装備する / 分解」ボタンで操作します。同じ装備をもう一度タップしても装備できます。
- 遊び始めると全画面＋横向き固定になります（対応しているブラウザのみ。iPhone の Safari は「ホーム画面に追加」で起動すると全画面になります）。

## ゲームの流れ

- 今は品質を固めるため、**第3層まで**で遊べるようにしています（第4層以降のデータは残してあります）。
- 各階層はいくつかの**エリア**に分かれています。光る門（出口）を通ると隣のエリアへ移動します。
- 階層ごとにつながり方が違います。
  - 第1層：町を中心に枝分かれ
  - 第2層：霧の一本道（野営地 → 森 → 群生地 → 迷宮区。森の脇にダンジョン）
  - 第3層：オアシスの野営地から放射状
- 屋外エリアは円形ではなく、横長・縦長・いびつな形をしています。中には次のものがあります。
  - 障害物：岩・大樹・遺跡・池
  - **毒沼**：踏んでいる間ダメージを受けます。
  - **流砂**：足が遅くなります。
  - 小さな宝箱：10分ごとにレア以上が1つ出ます。
- エリアの種類
  - **町 / 野営地**：転移門とNPCと**共有ボックス**がある安全地帯です。NPCに話しかけるとサブクエストを受けられます。
  - **フィールド**：各エリアをつなぐ広い場所です。
  - **狩場**：敵が多く、湧きが速く、経験値が1.6倍です。
  - **秘境**：ネームド（強力な主）が棲んでいます。倒すと良い装備が必ず出ます（4分で再出現）。
  - **ダンジョン**：精鋭の敵が出ます。最奥の宝箱から、そのダンジョン固有のユニーク装備が出ます（5分ごとに中身が戻ります）。
  - **迷宮区**：迷路の最奥にボスがいます。ボス部屋は直径40mほどの広さです。層ごとにギミックがあります。
    - 第1層：レバーで扉を開ける
    - 第2層：罠床と門番
    - 第3層：離れた2つの感圧板を15秒以内に踏む

### 共有ボックス（装備の受け渡し）
- 町と野営地にある青い箱です（F で開く）。全員で1つの箱を共有していて、どの町の箱からでも同じ中身にアクセスできます。
- 自分の持ち物をクリックすると箱に入れ、箱の中をクリックすると取り出します。入れた人の名前が表示されます。
- 最大60個まで入ります。中身はサーバー（ソロではブラウザ）に保存されます。
- ボスを倒すと、サーバー全体で次の階層が解放されます。解放状況は `world-save.json` に保存されます。
- ボスは倒してから40秒後に再挑戦できるので、装備掘りの周回にも使えます。
- 死んでも5秒後に、そのエリアの入口（町では転移門）で復活します。デスペナルティはありません。

### ヘイトとパーティの役割
- 敵は**ヘイト（敵対心）**が一番高いプレイヤーを狙います。ヘイトは与えたダメージで溜まり、時間とともに少しずつ減ります。
- **盾槍**はヘイトが溜まりやすい盾役です。ガードで攻撃を受けたり、シールドバッシュや挑発を使ったりすると、さらにヘイトを稼げます。
- ボスが誰を狙っているかは、ボスのHPバーの下に表示されます。自分を狙っている雑魚は、名前が赤く表示されます。

### 装備重量
- 装備には重さがあり、合計で「軽量 / 普通 / 重い / 過重」が決まります。重いほど回避のクールタイムが長くなり、過重だと転がる距離も短くなります。
- 防具には**軽装 / 中装 / 重装**があります。重装は重い代わりに、HPと被ダメ軽減が高くなります。
- 防具の種類は18種類あり、それぞれに**特性**が1つ付きます（例：忍び装束＝移動速度、魔導ローブ＝スキル短縮、大鎧＝攻撃力、城塞の重甲冑＝被ダメ軽減）。アイテムレベルが上がるほど、良い種類が出るようになります。

### 武器と武器パッシブ
装備しているだけで効くパッシブがあります。弓以外の近接武器には、全部に**生存本能**が付きます。HPが35%を切ると、6秒間 被ダメージが50%減ります（クールタイム90秒）。

| 武器 | 重さ | パッシブ |
|---|---|---|
| 片手剣 | 4 | 回避の無敵時間+0.1秒 / 当てるたびにスキルのクールタイムが0.15秒縮む |
| 大剣 | 9 | 強攻撃ダメージ+20% / 溜め中はひるまない |
| 大斧 | 11 | 強攻撃ダメージ+25% / 与ダメージの3%を回復 |
| 盾槍 | 8 | 被ダメージ-10% / ガードしていた時間に応じて、次の攻撃が最大+50% |
| 短剣 | 2 | 回避のクールタイム-25% / 当てるたびに攻撃速度+4%（最大+40%・3秒） |
| 弓 | 3 | 回避中も撃てる / **適性エリア**の敵にだけ本来のダメージ |

#### 弓の適性エリア
- 足元に2つの円が出ます。外の円は適性距離（10m）です。
- 2つの円の間にいる敵にだけ本来のダメージが出ます。外れると35%に下がります。
- 通常攻撃では円の間は2mしかありません。強攻撃で引き絞るほど、内側の円が内へ広がり、最大8mになります。
- スキル「集中」を使うと引き絞る速さが2倍になります。弓ツリーの「鷹の目」で最大幅が広がります。

- 1回で最大HPの10%以上のダメージを受けると、少しの間**ひるみ**ます（大剣の溜め中を除く）。

### ボス戦の駆け引き
- **正面が危険**：敵の正面で攻撃を受けるとダメージ1.3倍、背後なら0.7倍です。
- **ヘイトのリセット**：ボスのヘイトは12秒（雑魚は15秒）ごとにリセットされます。狙われている人がそのボスの攻撃を受けたりガードしたりすると、リセットまでの時間が少し延びます。盾役が「維持する」か、他の人が「取り直す」かが腕の見せどころです。
- **狙いの変更**：ボスはときどき、離れた位置にいる人へ遠距離弾や突進を撃ちます。弾は盾槍のガードで消せ、突進は正面でガードしている盾槍に当たると止まります。
- **スタンゲージ**：攻撃するとボスのスタンゲージが溜まります。満タンになると4秒間動けなくなり、被ダメージが1.3倍になり、出している最中の攻撃もすべて取り消されます。
  - 強攻撃で大きく溜まり、通常攻撃ではあまり溜まりません。
  - 武器ごとの溜まりやすさは、大斧 > 大剣 > 盾槍 > 片手剣 > 短剣 > 弓 の順です。
  - ステータスツリーの「崩しの心得」、ウォーストンプやシールドバッシュでも大きく溜まります。
  - スタンするたびに、次に必要な量が増えます。

### 装備掘り
- レアリティは コモン → アンコモン → レア → エピック → **伝説** → **神器** の6段階です。
- 伝説と神器は名前付きの固有装備で、特殊効果が付きます（天叢雲剣、グングニル、エクスカリバー、デュランダル、村正 など）。
- ドロップは**プレイヤーごと**に抽選されるので、友達と取り合いになりません。伝説以上が出ると全員に告知されます。
- レア以上のドロップには、レアリティの色の光の柱が立ちます。

### 戦闘
- 敵の攻撃の前には、地面に赤い**予兆**が出ます。ゲージが満ちたタイミングで中にいると被弾します。
- 回避の無敵時間で攻撃を抜けると「**JUST回避**」になります（八咫鏡などを付けていると反撃が出ます）。
- ボスには3つのフェーズがあります。HP50%で**激昂**、HP25%で**最終形態**になり、そのたびに大技で割り込んできます。フェーズが進むほど攻撃の間隔が短くなり、連続攻撃が増えます。
- ボスの攻撃パターン：追いかけ連続叩きつけ、回転薙ぎ払い、広がる衝撃波、連続突進、安全地帯が狭い爆発、範囲の雨、十字、螺旋、召喚など。最終形態になると技の種類が増えます。

### スキル
- 武器には**武器スキル**が1つ付いています。同じ武器種でも、ドロップした武器ごとにスキルが違います。
- レベルが1上がるごとにスキルポイントが1もらえます。**スキルツリー（K）**は3種類あります。
  - **武器種ツリー**（片手剣・大剣・槍・短剣）：その武器を装備しているときだけ有効です。使うスキル2つと、強化系のスキルがあります。
  - **ステータスツリー**：筋力・体力・技量・敏捷・精神など、基本能力を上げます。
  - **プレイスタイルツリー**：回避型・守護型・攻撃型の3系統です。それぞれに使うスキルがあります。
- 段階が進むほど、そのツリーにポイントを多く振っておく必要があります。振り直しは無料です。
- 使うスキル（◆）は、1 / 2 のスロットにセットして使います。

### レベリング
- 敵を倒した経験値は、近くにいる全員がそれぞれ満額もらえます（分割されません）。
- 自分よりレベルの高い敵からは経験値が多めに入り、低すぎる敵からは減ります。上限は Lv50 です。

## 構成

```
server.js              HTTP + WebSocket サーバー（20Hz でワールドを更新）
public/shared/data.js  階層・敵・装備・成長曲線などのデータ（サーバーとクライアントで共通）
public/shared/areas.js 各階層のエリア定義（迷路のマップ、出口、NPC、ギミック、当たり判定、経路探索）
public/shared/sim.js   ワールドのシミュレーション（エリアごとの敵AI、ヘイト、ギミック、ボスの行動パターン、ドロップ）。ソロモードではブラウザで動く
public/js/main.js      クライアント本体（入力の処理、戦闘、カメラ）。DOM にはさわらず、UI へは窓口（game）経由
public/js/ui/core.js   UI の土台: View（Passive View）/ link（Chain of Responsibility）/ Root / Mediator（ステートマシン）
public/js/ui/app.js    UI の組み立て: Root 配下のコンポーネント階層、Presenter、Mediator の状態と裁定
public/js/audio.js     BGM、環境音、効果音の合成
public/js/fx.js        パーティクル、斬撃、光の柱、雷、予兆
public/js/env.js       階層ごとの地形、プロップ、空
public/js/models.js    プレイヤー、武器、モンスターのモデル（プリミティブの組み合わせ）
public/js/toon.js      トゥーン調のマテリアル、輪郭線、メッシュの結合
public/js/skills.js    強攻撃、武器スキル、ツリーのスキル、スキルツリーの定義
public/js/quests.js    サブクエストの定義と進行
```

### UI の構成
- 画面のコンポーネントは、すべて Root を頂点とする階層に置いています。
  - Root の下：ゲーム画面 / ログイン / HUD / 各パネル / 浮かぶ文字 / ツールチップ
  - HUD の下：ホットバーのスロット、チャットなど
- 各コンポーネントは **Passive View** です。描画に関わるパラメータ（文字・表示・クラス・スタイル）を `set()` で受け取るだけです。値の計算は Presenter が行います。
- クリックやキー入力は **UIイベント**として親へバブリングします（Chain of Responsibility）。途中のコンポーネントが文脈を足していきます（例：「インベントリのセル」「箱の中のセル」）。
- Root に届いたイベントは、ステートマシンの **Mediator** が裁定します。
  - 状態：`login / play / inv / tree / settings / map / dialog / gate / box / chat`
  - 例：同じアイテムのセルのクリックでも、インベントリでは「装備」、共有ボックスでは「箱に入れる」になります。

### 見やすさ
- カメラと自キャラの間にある敵・木・岩・壁は、ディザで透かして自キャラが見えるようにしています。設定でオフにできます。
- カメラのすぐ近くにあるものも透かします。
- 屋外の端ではカメラが崖に埋まらないよう、真上寄りから見下ろします。

プレイヤーのデータ（レベルと装備）は各自のブラウザの localStorage に保存されます。友達同士で遊ぶ前提なので、チート対策はしていません。
