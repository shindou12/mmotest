# 浮遊城エテルナ — 協力ハード

友達3〜5人で第3層まで攻略する、難易度を上げたブラウザMMOの試作です。
three.js で描画し、BGM・環境音・効果音はすべて WebAudio でその場で合成しています（音声ファイルは使っていません）。

## このブランチの変更

`codex/coop-hard-mode` は通常版から独立した協力プレイ向けバランスです。

| 項目 | 協力ハード |
|---|---|
| キャラの基礎成長 | 1レベルごとに約6.5%（通常版は10%）。装備の基礎値も同じ成長率 |
| 必要経験値 | `65 × Lv^1.6`（通常版は `30 × Lv^1.55`） |
| 討伐経験値 | `7 × 敵Lv^1.25`。クエストXPは通常版の60% |
| 各層の基準敵Lv | 1 / 9 / 17。ボスLvは8 / 16 / 24 |
| 人数補正 | 同じエリアの参加人数。最低3人・最大5人基準。途中参加で強化、退出・戦闘不能で弱体化しない |
| 雑魚HP | 3人で単体基礎値の2.1倍、5人で3.2倍。敵自体のHP・攻撃力と層ごとの補正も強化 |
| ボスHP | 基礎係数28→48、人数補正も強化。3人2.7倍・5人4.4倍 |
| ボス行動 | HP65%で激昂・35%で最終形態。攻撃間隔短縮。予兆は残す |
| ボススタン | 必要量を増加、停止時間4秒→2.5秒。スタンごとの耐性増加は維持 |
| 回復 | ポーション30%・再使用8秒。ダメージ吸収系回復は通常版の55%効率 |
| 戦闘不能 | HP0でまず這いずり状態になり、仲間が攻撃を当てて起こせる。同じエリアの全員が倒れると戦闘不能で、キャラのレベル・装備・所持金・スキル・クエスト等のセーブを削除。5秒後に新規作成へ |
| 報酬 | 近くの生存者へXP共有、個人ドロップを維持。低レベル狩りのXPをさらに減衰 |

推奨攻略Lvは第1層6〜8、第2層14〜16、第3層22〜24を出発点にしています。自動・接続テスト済みですが、3〜5人での全層クリア時間や体感難度はまだ実測していません。
スキルツリーは通常版のままです。武器の握りと構えを修正し、弓は左手保持・右手で弦を引く形、大剣・大斧は両手持ち、盾槍は前向きの盾と安定した槍先にしています。
初期武器は開始ボタンに明示します。「つづきから」は既存装備を引き継ぐので、武器を選び直す新規開始とは区別してください。

## Windowsで一番簡単に起動する

Node.js LTSを先にインストールしてください。ZIP取得でもGitからの取得でも使えます。

### 今のcloudflaredとURLをそのまま使う

1. 元のゲームの `npm start` の画面で **Ctrl+C**。cloudflaredの画面は閉じません。
2. このブランチのZIPを展開し、`package.json` があるフォルダの **`start-game.cmd` をダブルクリック**。
3. 初回は依存パッケージを自動取得して、8080番で起動します。自分・友達とも既存のURLを再読み込みします。

### ゲームとcloudflaredをまとめて新しく起動する

1. 元のゲームとトンネルを停止します。
2. **`start-online.cmd` をダブルクリック**。
3. `D:\ChromeDownLoad\cloudflared.exe` を自動起動します。表示される新しい `https://...trycloudflare.com` を共有してください。

起動中はゲームの画面とトンネルの画面を開いたままにし、PCのスリープを避けてください。
8080番を別のゲームが使用中なら、ランチャーは上書きや強制終了せず案内を出します。
パッケージの取得や起動に失敗した場合は赤いエラーを確認してください。
トンネルの停止・再起動後は前のURLは引き継げません。

## セーブデータ

- 通常版のキャラを読み込まず、新しいキャラで開始します。同じブラウザでも通常版のデータは残ります。ハード版のキャラは戦闘不能で削除されます。
- サーバーは `world-save-coop-hard.json`、ブラウザのキャラは `eterna_coop_hard_char_v1` を使います。
- キャラを失っても、協力ワールドの共有ボックスと階層解放は残ります。
- 共有ボックスと階層解放も通常版とは別です。更新後もこれらを削除しなければ進行を保持します。
- 接続失敗時は10秒待ってソロへ移行します。ソロも3人基準です。HUDの `協力ハード / ONLINE` を全員が確認してください。
- 設定（音量・画質）は通常版と共有します。

## 検証

```bash
npm ci
npm test
```

成長曲線、人数補正、途中参加・退出、スタン耐性、報酬分配、フェーズ移行、3層の解放と、HTTP配信・5人のWebSocket接続・共有戦闘報酬を確認します。

## 手動起動

```bash
npm install
npm start
# → http://localhost:8080
```

- 同じLANの友達は `http://<ホストPCのIP>:8080` を開けば同じワールドに入れます。
- 外のネットの友達とは、ポート開放するか、`ngrok http 8080` のようなトンネルを使って URL を共有してください。
- サーバーにつながらないときは、自動でブラウザ内のソロモードになります（`?solo` を付けると強制的にソロ）。
- PCが重いときは `?low` を付けるとブルームと影を切った軽量モードになります。

- 尽きると**ガードブレイク**：1.5秒動けず、その間の被ダメージは1.5倍。
- ガードしていない間、1秒たつと回復し始め、約3秒で満タンに戻ります。

### スマホ（横持ち）
スマホで開くと、自動でタッチ操作になります（PCで試すときは `?touch` を付けます）。縦持ちのときは「横向きにして」と案内が出ます。

- **左側**：アナログスティックです。左の好きな場所に親指を置くと、そこが中心になります。倒した量で歩く速さが変わります。
- **右側**：半透明のボタンです。いちばん大きい攻撃ボタンの周りに、ほかのボタンが並んでいます。
  - **攻撃**：タップで通常攻撃、長押しで強攻撃です。
  - **スキル（武器スキル・1・2）**：離した瞬間に発動します。
  - 狙いは自動で、近くの敵（スティックを倒している方向を優先）を狙います。狙っている敵の足元に赤い輪が出ます。
  - 攻撃・スキルのボタンを**押したまま引っぱる**と、その方向に狙えます（アローレインは引っぱった距離の場所に降ります）。真ん中に戻すと自動の狙いに戻ります。
  - ほかに、回避、ポーション、ガード（盾槍のみ）があります。近くに調べられるものがあると「調べる」ボタンが出ます。
- **右上**：装備・スキル・マップ・チャット・設定のボタンです。
- **ズーム**：画面を2本指でつまみます。
- **インベントリ**：1回目のタップで詳細が出て、「装備する / 分解」ボタンで操作します。同じ装備をもう一度タップしても装備できます。
- 遊び始めると全画面＋横向き固定になります（対応しているブラウザのみ。iPhone の Safari は「ホーム画面に追加」で起動すると全画面になります）。

## ゲームの流れ

- 今は品質を固めるため、**第3層まで**で遊べるようにしています（第4層以降のデータは残してあります）。
- 各階層はいくつかの**エリア**に分かれています。光る門（出口）を通ると隣のエリアへ移動します。
- 階層ごとにつながり方が違います。
  - 第1層：町を中心に枝分かれ
  - 第2層：霧の一本道（野営地 → 森 → 群生地 → 迷宮区。森の脇にダンジョン）
  - 第3層：オアシスの野営地から放射状
- 屋外エリアは円形ではなく、横長・縦長・いびつな形をしています。中には次のものがあります。
  - 障害物：岩・大樹・遺跡・池
  - **毒沼**：踏んでいる間ダメージを受けます。
  - **流砂**：足が遅くなります。
  - 小さな宝箱：10分ごとにレア以上が1つ出ます。
- エリアの種類
  - **町 / 野営地**：転移門とNPCと**共有ボックス**がある安全地帯です。NPCに話しかけるとサブクエストを受けられます。
  - **フィールド**：各エリアをつなぐ広い場所です。
  - **狩場**：敵が多く、湧きが速く、経験値が1.6倍です。
  - **秘境**：ネームド（強力な主）が棲んでいます。倒すと良い装備が必ず出ます（6分で再出現）。
  - **ダンジョン**：精鋭の敵が出ます。最奥の宝箱から、そのダンジョン固有のユニーク装備が出ます（5分ごとに中身が戻ります）。
  - **迷宮区**：迷路の最奥にボスがいます。ボス部屋は直径40mほどの広さです。層ごとにギミックがあります。
    - 第1層：レバーで扉を開ける
    - 第2層：罠床と門番
    - 第3層：迷路の両端にある2つの感圧板を50秒以内に踏む（2人で手分けすると楽）
  - 迷路は入口からボス部屋の扉まで200〜280mほどあり、途中に敵の湧く部屋や行き止まりがあります。

### 共有ボックス（装備の受け渡し）
- 町と野営地にある青い箱です（F で開く）。全員で1つの箱を共有していて、どの町の箱からでも同じ中身にアクセスできます。
- 自分の持ち物をクリックすると箱に入れ、箱の中をクリックすると取り出します。入れた人の名前が表示されます。
- 最大60個まで入ります。中身はサーバー（ソロではブラウザ）に保存されます。
- ボスを倒すと、サーバー全体で次の階層が解放されます。解放状況は `world-save.json` に保存されます。
- ボスは倒してから40秒後に再挑戦できるので、装備掘りの周回にも使えます。
- 戦闘不能になるとキャラクターデータを失い、5秒後に新規作成画面へ戻ります。

### 這いずりと救助
- HPが0になってもすぐには戦闘不能になりません。**這いずり状態**になり、ゆっくり這って動けます（攻撃・回避・ポーション・出口は使えず、敵にも狙われません）。
- 同じエリアの仲間に「仲間が倒れた」と通知が出ます。倒れた人の足元に**円のゲージ**が出て、仲間が攻撃を当てるとゲージが減り、なくなると HP30%・2秒無敵で起き上がります。
- 減る量は攻撃の**スタン値**で決まり、ダメージは関係ありません。最初は円の1/4で、大剣の溜め強攻撃1発＋通常攻撃1回、大斧の溜め強攻撃なら1発で起こせます。片手剣や短剣は数回かかります。弓は遠くからでも矢で起こせて、起こす力は片手剣と同じです（斬撃波などの飛ぶ攻撃でも減ります）。
- 最近倒れた回数ほど起こしにくくなります（円の1/4 → 1/2 → 3/4 → 1周、最大4倍）。5分間倒れずにいると1段階戻ります。
- **同じエリアの全員が倒れると**（ひとりで戦っているときを含む）、這いずっている人は全員力尽きて戦闘不能になります。

### ヘイトとパーティの役割
- 敵は**ヘイト（敵対心）**が一番高いプレイヤーを狙います。ヘイトは与えたダメージで溜まり、時間とともに少しずつ減ります。
- **盾槍**はヘイトが溜まりやすい盾役です。ガードで攻撃を受けたり、シールドバッシュや挑発を使ったりすると、さらにヘイトを稼げます。
- ボスが誰を狙っているかは、ボスのHPバーの下に表示されます。自分を狙っている雑魚は、名前が赤く表示されます。

### 装備重量
- 装備には重さがあり、合計で「軽量 / 普通 / 重い / 過重」が決まります。重いほど回避のクールタイムが長くなり、過重だと転がる距離も短くなります。
- 防具には**軽装 / 中装 / 重装**があります。重装は重い代わりに、HPと被ダメ軽減が高くなります。
- 防具の種類は18種類あり、それぞれに**特性**が1つ付きます（例：忍び装束＝移動速度、魔導ローブ＝スキル短縮、大鎧＝攻撃力、城塞の重甲冑＝被ダメ軽減）。アイテムレベルが上がるほど、良い種類が出るようになります。

### 武器と武器パッシブ
装備しているだけで効くパッシブがあります。弓以外の近接武器には、全部に**生存本能**が付きます。常に被ダメージが8%減ります（被ダメ軽減のステータスに含まれます）。
HPの自然回復はありません。回復はポーション・吸収・スキルなどで行います（町・野営地の転移門の近くでは、HPとポーションが戻ります）。

| 武器 | 重さ | パッシブ |
|---|---|---|
| 片手剣 | 4 | 回避の無敵時間+0.1秒 / 当てるたびにスキルのクールタイムが0.15秒縮む |
| 大剣 | 9 | 強攻撃ダメージ+20% / 溜め中はひるまない |
| 大斧 | 11 | 強攻撃ダメージ+25% / 与ダメージの3%を回復（ハード版では55%効率） |
| 盾槍 | 8 | 被ダメージ-10% / 強攻撃の溜め中はガード。攻撃を受けてから離すとガードカウンター（回転なぎ払い） |
| 短剣 | 2 | 回避のクールタイム-25% / 当てるたびに攻撃速度+4%（最大+40%・3秒） |
| 弓 | 3 | 回避中も撃てる / **適性エリア**の敵にだけ本来のダメージ |

#### 弓の適性エリア
- 足元に2つの円が出ます。外の円は適性距離（10m）です。
- 2つの円の間にいる敵にだけ本来のダメージが出ます。外れると35%に下がります。
- 通常攻撃では円の間は2mしかありません。強攻撃で引き絞るほど、内側の円が内へ広がり、最大8mになります。
- スキル「集中」を使うと引き絞る速さが2倍になります。弓ツリーの「鷹の目」で最大幅が広がります。

- 1回で最大HPの10%以上のダメージを受けると、少しの間**ひるみ**ます（大剣の溜め中を除く）。

### ボス戦の駆け引き
- **正面が危険**：敵の正面で攻撃を受けるとダメージ1.3倍、背後なら0.7倍です。
- **ヘイトのリセット**：ボスのヘイトは12秒（雑魚は15秒）ごとにリセットされます。狙われている人がそのボスの攻撃を受けたりガードしたりすると、リセットまでの時間が少し延びます。盾役が「維持する」か、他の人が「取り直す」かが腕の見せどころです。
- **狙いの変更**：ボスはときどき、離れた位置にいる人へ遠距離弾や突進を撃ちます。弾は盾槍のガードで消せ、突進は正面でガードしている盾槍に当たると止まります。
- **スタンゲージ**：攻撃するとボスのスタンゲージが溜まります。満タンになると2.5秒間動けなくなり、被ダメージが1.3倍になり、出している最中の攻撃もすべて取り消されます。
  - 強攻撃で大きく溜まり、通常攻撃ではあまり溜まりません。
  - 武器ごとの溜まりやすさは、大斧 > 大剣 > 盾槍 > 片手剣 > 短剣 > 弓 の順です。
  - ステータスツリーの「崩しの心得」、ウォーストンプやシールドバッシュでも大きく溜まります。
  - スタンするたびに、次に必要な量が増えます。

### ゴールド
- 敵を倒すと、硬貨がチャリチャリと飛び散ります。近づくと吸い寄せられて拾えます。雑魚はたまに何も落としません。
- 拾った額は「+○○ G」とまとめて表示され、右上の所持金が弾みます。
- 精鋭はゴールドを多めに落とします。ネームド・ボス・ダンジョン最奥の宝箱は、光る**金貨袋**を落とします。袋は少し離れた所に跳ねるので、取りに行きます。
- 屋外の小さな宝箱からも少し出ます。
- 装備を**分解**するとゴールドになります（額はレアリティとアイテムレベルで決まり、ツールチップに表示されます）。分解したゴールドは足元から噴き出して、すぐ吸い込まれます。
- エリアを移動したとき拾い残しがあっても、自動で所持金に入ります。
- 今のところ使い道はまだありません（ショップや強化などで使う予定の通貨です）。

### 装備掘り
- レアリティは コモン → アンコモン → レア → エピック → **伝説** → **神器** の6段階です。
- 伝説と神器は名前付きの固有装備で、特殊効果が付きます（天叢雲剣、グングニル、エクスカリバー、デュランダル、村正 など）。
- ドロップは**プレイヤーごと**に抽選されるので、友達と取り合いになりません。伝説以上が出ると全員に告知されます。
- レア以上のドロップには、レアリティの色の光の柱が立ちます。

### 特性（ランダムで付く効果）
- 装備にはレアリティに応じて0〜4個の**特性**が付きます（攻撃力%・会心率・スキル短縮 など9種）。
- 特性には**ティア**（T1〜T5）があり、アイテムレベルが高いほど上のティアが出やすくなります。
- 後半（アイテムレベル25〜）では、その上の**超越 I・超越 II**（T6・T7）が付くことがあります。超越はドロップでしか手に入りません。
- 防具の種類ごとの固定の効果（忍び装束＝移動速度 など）は、特性とは別の**基本効果**です。
- **スキル変化**（武器のみ・1つまで）は、武器スキルの性質を大きく変える特別な特性です。
  - 二連：もう一度発動する
  - 巨大化：範囲・射程が広がる
  - 迅速：クールタイムが大きく縮む
  - 爆炎：炎属性になり、燃やし、爆発する
  - 雷鳴：雷が近くの敵に連鎖する
  - 吸命：与ダメージを回復する
  - 瞬身：発動前に瞬間移動する
  - 崩撃：スタン値が数倍になり、衝撃波が出る
  - 氷結：当たった敵が凍り、1秒後に砕けて周りの敵にも当たる
  - 旋風：狙った場所に竜巻が数秒残り、範囲に何度も当たる
  - 剛撃：必ず会心になり威力が大きく上がるが、クールタイムが大きく伸びる
  - 聖光：少し遅れて狙った場所に光の柱が落ち、自分のHPも回復する
  - 全部で12種類です。属性系（爆炎・雷鳴・氷結・旋風・聖光など）は色やエフェクトも変わります。

### エリアの傾向（踏破）
- エリアごとに**出やすい武器種**と**付きやすい特性**があります（どちらもゆるめの偏りです）。
- エリアを**踏破**すると、エリアマップ（M）の下に傾向が表示されます。
  - 迷宮区：ボスを倒すと踏破
  - 秘境：ネームドを倒すと踏破
  - ほかのエリア：敵を15体倒すと踏破

### 称号（4つ目の装備枠）
- ステータスはなく、短くて強い効果が1つ付きます。装備欄の「称号」に付けます。
- 入手方法：
  - 階層ボスの初討伐
  - ネームドの討伐
  - クエストの報酬
  - 鍛冶屋の**伝承化**（伝説・神器の固有効果がそのまま称号になります）
- 武器の動きに頼る効果には「近接武器のみ」「弓のみ」などの条件があります。条件に合わない武器では効きません。
- 同じ固有効果は、武器と称号で重ねても1つ分しか効きません。
- 主な称号：
  - コボルド王を討つ者：ボスへのダメージ +15%
  - 霧を越えし者：毒沼・流砂の影響を受けない
  - 湖のヌシ殺し：ゴールド +30%・吸い寄せ範囲2倍
  - 血の渇き：近接のみ。倒すとHP回復
  - 鷹の眼：弓のみ。適性エリアで会心率 +30%
  - 不落の盾：盾槍のみ。ガードカウンターで被ダメ軽減
  - 不死鳥：一度だけその場で復活
- 全部で26種類（クエスト報酬15・ボス／ネームド討伐5・ドロップ限定6）。クエストの報酬に称号があるときは、NPCとの会話に効果まで表示されます。
  - クエスト報酬の例：井戸の探索者（屋内で移動速度+15%）、地図職人（自動マッピングの範囲2倍・宝箱が先に映る）、旅人（移動・ワープ後10秒 移動速度+30%）、宝探し（宝箱でゴールド追加とHP回復）、崩しの達人（スタン値+30%）、古代の守護（被ダメ-8%・ひるみにくい）、夜目、薬師、呪い返し、甲殻の守り
  - 新しいクエスト（新しい敵が相手）：洞窟の羽音（ケイブバット）、毒キノコ採り（ドクキノコ）、まじない師の影（ゴブリンシャーマン）、大蠍の尾（ジャイアントスコーピオン）
- **ドロップ限定の称号**は、敵を倒したときにまれに落ちます（持っていないものだけ）。
  - 幸運の星（どの敵からも・ごくまれ）：会心率+8%・ゴールド+15%
  - 死神の影（精鋭）：HP30%以下の敵へのダメージ+25%
  - 狂戦士（ネームド・近接のみ）：与ダメ+20%・被ダメ+15%
  - 流星（階層ボス・神器級）：武器スキルのクールタイム-20%、当たると流れ星が降る
  - 嵐を歩む者（雨・霧・砂嵐のエリア）：天候の中で移動速度+15%・攻撃速度+10%
  - 百獣の狩人（狩場）：雑魚へのダメージ+15%

### 鍛冶屋（町・野営地）
- **強化**：基礎値（攻撃力・HP・被ダメ軽減）が1段階ごとに+8%されます。最大+10です。
  - +5までは必ず成功します。+6からは確率になりますが、失敗しても強化値は下がりません。
  - ゴールドと**強化の欠片**（分解で手に入ります）を使います。
- **特性変更**：特性の枠を1つ選び、別の特性に付け替えます。
  - 付けられるのは**特性リスト**で解放した特性だけです。その特性の宝石（分解で手に入ります）を使います。
  - ティアはランダムで、解放済みの上限（最高T5）までが出ます。
- **スキル変更**：武器スキルを、その武器種の4つのスキルから選び直します。
- **伝承化**：伝説・神器の装備を、その固有効果を持つ称号に変えます。元の装備はなくなります。
- **特性リスト**：装備を分解すると、付いていた特性とそのティアがリストに追加されます。
  - 超越を分解した場合はT5扱いです。
  - まだ一度も分解していない特性は「？？？」のままで、付けられません。

### 戦闘
- 敵の攻撃の前には、地面に赤い**予兆**が出ます。ゲージが満ちたタイミングで中にいると被弾します。
- 回避の無敵時間で攻撃を抜けると「**JUST回避**」になります（八咫鏡などを付けていると反撃が出ます）。
- **被弾リアクション**：受けたダメージの大きさで反応が変わります（ほかのプレイヤーにも同じに見えます）。
  - 小さいダメージ：のけぞるだけで、動きは止まりません。
  - 最大HPの10%以上：少し押し戻されて、短くひるみます。
  - 最大HPの25%以上、またはボスの大技（突進・広範囲の爆発・メテオ・聖域など）：吹き飛んで**ダウン**します（約1秒）。
    - 倒れた直後に回避を押すと**受け身**を取り、すぐ転がって起き上がります（無敵付き）。
    - 起き上がりには短い無敵があり、起き上がってすぐはもう一度ダウンしません（ひるみで済みます）。
  - 防具が重いほど飛ばされる距離が短くなります（軽装は遠くへ飛ぶ）。大剣の溜め中はひるみもダウンもしません。
- ボスには3つのフェーズがあります。HP65%で**激昂**、HP35%で**最終形態**になり、そのたびに大技で割り込んできます。フェーズが進むほど攻撃の間隔が短くなり、連続攻撃が増えます。
- ボスの攻撃パターン：追いかけ連続叩きつけ、回転薙ぎ払い、広がる衝撃波、連続突進、安全地帯が狭い爆発、範囲の雨、十字、螺旋、召喚など。最終形態になると技の種類が増えます。
- 第1〜3層のボスには、次の新しい技が2つずつあります（どれも予兆が出ます）。
  - **地割れ**（第1層・第3層）：狙った方向へ3本の亀裂が根元から先へ順に走る
  - **全方位弾幕**（第1層）：足元が光ったあと、全方向へ弾を2回撃つ。盾槍のガードで消せる
  - **市松**（第2層・第3層）：格子の半分 → 残りの半分が交互に爆発する
  - **聖域**（第2層）：アリーナ全体が爆発する大技。光る小さな安全地帯にだけ逃げ込める

### 敵
- 階層ごとに4種類の敵がいて、エリアによって出てくる組み合わせが違います。
  - 第1層：グリーンスライム、フレンジーボア、**ケイブバット**（コウモリ・素早い）、**ドクキノコ**（周りに胞子をまく）
  - 第2層：フォレストウィスプ、ミストウルフ、**ミストマタンゴ**（キノコ）、**ゴブリンシャーマン**（魔術師・離れた所から魔法陣）
  - 第3層：デザートスコーピオン、サンドゴーレム、**ジャイアントスコーピオン**（サソリ・尾の突き刺し）、**砂漠の呪術師**（魔術師）

### 見た目
- **武器の形**：6武器種それぞれに形の違う3種類（例：片手剣＝刀・木の葉剣・水晶剣）と、伝説・神器専用の形が1種類ずつ、全部で24種類あります。どの形かは装備で決まり、他のプレイヤーにも同じ形で見えます。
- **防具の見た目**：軽装（フード / 忍びの襟巻き）、中装（革の肩当てとマント / 鎖頭巾）、重装（騎士の兜と大肩当て / 角兜と重マント）の6種類。装備している防具で変わり、他のプレイヤーにも同じ見た目で見えます。

### 天候
- 屋外エリアの一部には天候があります。粒子・霧の濃さと色・日差し・環境音が変わります。
  - **雨**：第1層 イノシシの丘・静かな湖畔（雨筋と暗い空、雨音と時々の遠雷）
  - **霧**：第2層 霧の森・キノコの群生地（すぐ先が見えない濃い霧、低いうなり）
  - **砂嵐**：第3層 蠍の巣・流砂の谷（横殴りの砂、黄土色の視界、突風の音）

### スキル
- 武器には**武器スキル**が1つ付いています。武器種ごとに4種類あり、ドロップした武器ごとに違います（鍛冶屋で変更できます）。
- レベルが1上がるごとにスキルポイントが1もらえます。**スキルツリー（K）**は3種類あります。
  - **武器種ツリー**（6武器種）：その武器を装備しているときだけ有効です。最上段にその武器の**武器パッシブ**が表示されます。使うスキル2つと、強化系のスキルがあります。
  - **ステータスツリー**：筋力・体力・技量・敏捷・精神など、基本能力を上げます。
  - **プレイスタイルツリー**：回避型・守護型・攻撃型の3系統です。それぞれに使うスキルがあります。
- 段階が進むほど、そのツリーにポイントを多く振っておく必要があります。振り直しは無料です。
- 使うスキル（◆）は、Q / E のスロットにセットして使います。

### レベリング
- 敵を倒した経験値は、近くにいる全員がそれぞれ満額もらえます（分割されません）。
- 自分よりレベルの高い敵からは経験値が多めに入り、低すぎる敵からは減ります。上限は Lv50 です。

### 画面の配置（原神ふう）
- **左上**：ミニマップ。その下に現在地とクエストが出ます。
- **上中央**：ボスの名前とHP、スタンゲージ。
- **右上**：メニュー（装備・スキル・マップ・設定）。
- **右**：仲間のHP（2人以上のときだけ）。
- **下中央**：Lv・HP・経験値・バフ。
- **右下**：スキル（丸いアイコン）。クールタイムは時計回りに減ります。
- **自キャラの横**：回避の回復を示す黄色い輪（原神のスタミナのように、減ったときだけ出ます）と、溜めゲージ。
- **調べる**：表示は画面の右寄り中央に出ます。

### UI の構成
- 画面のコンポーネントは、すべて Root を頂点とする階層に置いています。
  - Root の下：ゲーム画面 / ログイン / HUD / 各パネル / 浮かぶ文字 / ツールチップ
  - HUD の下：ホットバーのスロット、チャットなど
- 各コンポーネントは **Passive View** です。描画に関わるパラメータ（文字・表示・クラス・スタイル）を `set()` で受け取るだけです。値の計算は Presenter が行います。
- クリックやキー入力は **UIイベント**として親へバブリングします（Chain of Responsibility）。途中のコンポーネントが文脈を足していきます（例：「インベントリのセル」「箱の中のセル」）。
- Root に届いたイベントは、ステートマシンの **Mediator** が裁定します。
  - 状態：`login / play / inv / tree / settings / map / dialog / gate / box / chat`
  - 例：同じアイテムのセルのクリックでも、インベントリでは「装備」、共有ボックスでは「箱に入れる」になります。

### 見やすさ
- カメラと自キャラの間にある敵・木・岩・壁は、ディザで透かして自キャラが見えるようにしています。設定でオフにできます。
- カメラのすぐ近くにあるものも透かします。
- 屋外の端ではカメラが崖に埋まらないよう、真上寄りから見下ろします。

プレイヤーのデータ（レベルと装備）は各自のブラウザの localStorage に保存されます。友達同士で遊ぶ前提なので、チート対策はしていません。


### モーションの管理

- `public/js/models.js`: モデルの生成。既存の `animatePlayer` 呼び出しはそのまま使える。
- `public/js/player-motion.js`: 歩行・回避・被弾と、モーションを適用する順序。
- `public/js/weapon-motion.js` / `weapon-pose.js`: 攻撃姿勢・武器姿勢の振り分け。
- `public/js/motions/`: 弓・槍・近接武器の腕と武器の動き。同じ曲線を使う片手剣・短剣、大剣・大斧は近接処理を共有する。
- `public/js/pose-rig.js`: 手の到達位置、肘の曲げ方、武器の向きを求める共通計算。
- `public/shared/skill-timings.js`: 槍の命中時刻・連撃間隔・回転・回復時間。スキル処理、モーション、通信が同じ定義を参照する。

`test/motion-parity.test.js` は、分離前に取得した全6武器・4形状・117状態の姿勢と、槍のスキルイベント列との一致を検証する。見た目やタイミングを意図的に変える場合は、差分を確認してから基準データを更新する。

### 追加の武器ツリースキル（29技）

右クリックの装備スキルは従来のまま。以下は武器ツリーの段階2〜4で各1ptで取得し、Q/Eの2枠へ選んで装備する。武器を持ち替えると、その武器のツリーの技だけが使用可能。振り直しは従来どおり無料。

| 武器 | 新しい技 |
| --- | --- |
| 片手剣（4） | 受け流し・空裂斬・霞返し・連撃の構え |
| 大剣（5） | 断頭落とし・払い上げ・横一文字・退き兜割り・破城の構え |
| 盾槍（5） | 扇突き・足払い・盾押し・杭打ち・迎撃の構え |
| 短剣（5） | 抜け駆け・急所穿ち・裂傷連舞・影縫い・疾走刃 |
| 大斧（5） | 引き裂き・処刑斬・返り刃・血払い・猛進断 |
| 弓（5） | 二段射ち・足留め矢・跳弦射撃・置き矢・弦鳴り |

役割はツリーの技名の上に表示する。足止め・押し戻し・引き寄せはサーバーで適用し、ボスには適用しない（スタン値の加算は別）。同じ足止めは加算されない。各技には専用の姿勢トラックがあり、発動時間と命中時刻は `public/shared/techniques.js` が管理する。効果は `advanced-skills.js`、姿勢は `technique-motion.js`、通信に使う一覧は `shared/motion-catalog.js`。既存モーションの比較テストはそのまま維持する。

攻撃速度の重なりで通常攻撃時間が負になることを防ぐため、通常攻撃時間の短縮は75%を上限とする。新技の威力・CTは初期の調整値で、実プレイのバランス調整は今後行える。
