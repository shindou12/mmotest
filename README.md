# 浮遊城エテルナ（プロトタイプ）

友達5人くらいで遊ぶ、10階層を登るブラウザMMOの試作です。
three.js で描画し、BGM・環境音・効果音はすべて WebAudio でその場で合成しています（音声ファイルは使っていません）。

## 起動

```bash
npm install
npm start
# → http://localhost:8080
```

- 同じLANの友達は `http://<ホストPCのIP>:8080` を開けば同じワールドに入れます。
- 外のネットの友達とは、ポート開放するか、`ngrok http 8080` のようなトンネルを使って URL を共有してください。
- サーバーにつながらないときは、自動でブラウザ内のソロモードになります（`?solo` を付けると強制的にソロ）。
- PCが重いときは `?low` を付けるとブルームと影を切った軽量モードになります。

## ゲームの流れ

- 今は品質を固めるため、**第3層まで**で遊べるようにしています（第4層以降のデータは残してあります）。
- 各階層の南に**転移門**、北に**ボス部屋**（魔法陣）があります。魔法陣に入るとボス戦が始まります。
- ボスを倒すと、サーバー全体で次の階層が解放されます。解放状況は `world-save.json` に保存されます。
- ボスは倒してから40秒後に再挑戦できるので、装備掘りの周回にも使えます。
- 死んでも5秒後に転移門で復活します。デスペナルティはありません。

### 装備掘り
- レアリティは コモン → アンコモン → レア → エピック → **伝説** → **神器** の6段階です。
- 伝説と神器は名前付きの固有装備で、特殊効果が付きます（天叢雲剣、グングニル、エクスカリバー、デュランダル、村正 など）。
- ドロップは**プレイヤーごと**に抽選されるので、友達と取り合いになりません。伝説以上が出ると全員に告知されます。
- レア以上のドロップには、レアリティの色の光の柱が立ちます。

### 戦闘
- 敵の攻撃の前には、地面に赤い**予兆**が出ます。ゲージが満ちたタイミングで中にいると被弾します。
- 回避の無敵時間で攻撃を抜けると「**JUST回避**」になります（八咫鏡などを付けていると反撃が出ます）。
- ボスには3つのフェーズがあります。HP50%で**激昂**、HP25%で**最終形態**になり、そのたびに大技で割り込んできます。フェーズが進むほど攻撃の間隔が短くなり、連続攻撃が増えます。
- ボスの攻撃パターン：追いかけ連続叩きつけ、回転薙ぎ払い、広がる衝撃波、連続突進、安全地帯が狭い爆発、範囲の雨、十字、螺旋、召喚など。最終形態になると技の種類が増えます。

### スキル
- 武器には**武器スキル**が1つ付いています。同じ武器種でも、ドロップした武器ごとにスキルが違います。
- レベルが1上がるごとにスキルポイントが1もらえます。**スキルツリー（K）**は3種類あります。
  - **武器種ツリー**（片手剣・大剣・槍・短剣）：その武器を装備しているときだけ有効です。使うスキル2つと、強化系のスキルがあります。
  - **ステータスツリー**：筋力・体力・技量・敏捷・精神など、基本能力を上げます。
  - **プレイスタイルツリー**：回避型・守護型・攻撃型の3系統です。それぞれに使うスキルがあります。
- 段階が進むほど、そのツリーにポイントを多く振っておく必要があります。振り直しは無料です。
- 使うスキル（◆）は、1 / 2 のスロットにセットして使います。

### レベリング
- 敵を倒した経験値は、近くにいる全員がそれぞれ満額もらえます（分割されません）。
- 自分よりレベルの高い敵からは経験値が多めに入り、低すぎる敵からは減ります。上限は Lv50 です。

## 構成

```
server.js              HTTP + WebSocket サーバー（20Hz でワールドを更新）
public/shared/data.js  階層・敵・装備・成長曲線などのデータ（サーバーとクライアントで共通）
public/shared/sim.js   ワールドのシミュレーション（敵AI、ボスの行動パターン、ドロップ）。ソロモードではブラウザで動く
public/js/main.js      クライアント本体（入力、戦闘、UI）
public/js/audio.js     BGM、環境音、効果音の合成
public/js/fx.js        パーティクル、斬撃、光の柱、雷、予兆
public/js/env.js       階層ごとの地形、プロップ、空
public/js/models.js    プレイヤー、武器、モンスターのモデル（プリミティブの組み合わせ）
public/js/toon.js      トゥーン調のマテリアル、輪郭線、メッシュの結合
public/js/skills.js    強攻撃、武器スキル、ツリーのスキル、スキルツリーの定義
```

プレイヤーのデータ（レベルと装備）は各自のブラウザの localStorage に保存されます。友達同士で遊ぶ前提なので、チート対策はしていません。
