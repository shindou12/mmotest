# 森の輪郭比較

既存の `forest_path_g3` 地図と元のアセット・光・仕上げを使用。現在と試作を縦に配置し、外形・奥行きと面・外側の殻を試す。`world.js` は元の `public/worldart/world.js` のコピーに、この実験フォルダだけのフックを追加したもの。モデルや本番の描画コードは変更しない。対象は樹木・岩・木箱・切り株で、茂み・地面の草はそれぞれ選択できる。地形は対象外。殻は透明な板の葉・茂み・草を除外する。視点ドラッグとスライダーは両画面に反映する。静止比較のため、操作時だけ再描画する。

既存の材質の葉の切り抜きを外形と深度・法線の描画にも使い、選択外の地形や植物を奥行きに含めて隠れた線が出にくいようにしている。細部ではアルファや影、近接した複数の物の境界にまだ未検証のケースがある。特に外形は葉と背景の隙間に太い縁が出ることがある。

`node codex/outline-forest/check.mjs`: 画面2つ、対象メッシュ13個、殻7個、3方式を撮影、エラーなし。`node codex/outline-forest/verify-params.mjs`: 強さ0と6を撮影した差は外形71641、深度法線104330、殻2420画素（RGBの差が2を超える画素）。スクリーンショットは `shots/`。単体の研究と出典は `../asset-outline-study/README.md`。

茂み・草の切り替え追加後、`node codex/outline-forest/verify-plants.mjs` で双方の切り替えを確認。外形方式では茂み追加で39982画素、続く草追加で240487画素、深度法線方式では各34136・218261画素の差。草を強く縁取ると地面がまだらに見えるため、まず弱めの線でも比べる。
