# ヤシの表示修正とROを意識した材質

目的: 葉が消えるシェーダーの誤りを修正し、ROの見本の大きな色面・淡い葉先・少ない細部を目安に材質を比べる。

- [x] 添付画面を開く。実際の材質フックを通したソースで、風の属性参照が宣言より前にあることを確認。
- [x] 描画・影の宣言順を修正。古いモジュールを読み続けないよう版を付ける。
- [x] 組み込みimagegenで葉と樹皮を生成。最初の写実寄りの案から、ROを意識した塗りへ生成し直す。見本画像は外部へ送らない。
- [x] 同じ木・同じ光で材質だけを替える比較を作る。後続のユーザー指示で、風のページは無風側を前案、揺れる側を新案にする。
- [x] 実物の植物資料を調べ、全体案2種を生成。ユーザーが評価した添付見本由来の案から葉・樹皮を作る。
- [x] Blenderで貼った状態を撮って開く。透過・UV・色空間・宣言順・構文・参照先を確認し、未確認を残す。

すべてcodex内。元のGLB・本番の材質は編集しない。自動ブラウザの既存セキュリティ拒否は回避しない。
