# 画像素材のファンタジー街路

- 変更はcodex/fantasy-world/内。校舎は既存のまま残す。
- 光る窓の木組みの家、草花、灯り、城門と遠景の城。青い夕暮れと暖かい灯りをつなぐ。
- 素材は組み込みimagegenで制作。固定画像面を前後・左右に分け、床と影を共有する。GLBやBoxGeometryは使わない。
- three.js r160の既存のControls、Postprocessingと床反射を再利用する。新しい依存のインストールなし。
- 見本（構成の参考）｜現在（最初の実画面）｜試作（改善後）を並べる。歩行・横移動・首振りの実画面を開いて判断する。
- 前のHD-2D調査の、光と影の統一、前景・中景・遠景の分離を参考にする。画像部品の回転対称でない物はカメラへ向け直さない。
