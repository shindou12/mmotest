# 灯りの街路

2Dの画像素材から組んだ、歩ける夕暮れのファンタジー街路。変更はこのフォルダだけ。

## 開く

- [街路](http://127.0.0.1:8172/codex/fantasy-world/?preview=1)
- [見本｜現在｜試作](http://127.0.0.1:8172/codex/fantasy-world/compare.html)
- WASD移動、ドラッグまたはマウスで見回し、Fで手元の灯り、Esc解除。
- 作業ツリーのルートで `python -m http.server 8172 --bind 127.0.0.1`。既存のthree.js r160を使う。追加インストールなし。

## 素材と構成

組み込みimagegenで4点を新規生成し、assets/に元画像をコピー。APIキー・従量課金は使用していない。プロンプト全文は [PROMPTS.md](./PROMPTS.md)。architecture.png / props.pngは透過画像。元の画素を加工せず、実行時のUVで部品を切り出した。

- architecture.png: 家の正面・側面・宿屋・庇。
- props.png: 城門・草花・ランタン・樽と籠。
- cobblestone.png: 石畳の繰り返し画像。
- distance.png: 城・山・森・夕空。

建物は正面・背面・側壁・傾斜した屋根など、固定した画像面で構成。箱や円柱、GLBは使用していない。草花も角度の異なる固定面。家や城門全体をカメラへ向ける処理はない。

住宅の一部の窓は壁に開口を作り、ガラスの画像を奥へ置いた。見込みと下枠も画像面。既定は6cm。宿屋の窓やドアなど、元画像の同じ面に残っている部分もある。

## 実画面を見て直したこと

1. 最初の画面は空の上端に切れ目が出た。背景面を広げ、端をなじませた。
2. 窓の光が壁を白くしていた。発光を弱め、窓からの光は道へ向けるSpotLightにした。
3. 横から見ると、側面画像の煙突が別の板として見えた。側壁と屋根の画像領域を分け、屋根の傾斜面、裏側の面、軒の面を追加。
4. 石畳の粒が大きく見えたため、人の目の高さから読める大きさへ変更。
5. 草花が横から薄く見えたため、角度の異なる固定した画像層を追加。極端な接近では交差面が残る。
6. 窓を同じ面 / 6cm / 18cmで比べた。深い版は斜めからガラスが隠れすぎるため、浅い見込みを既定にした。見込みの暖色は室内からの回り込みの簡略表現で、間接光を解いていない。
7. 振り返った方向の背景と地面の境を確認し、地面を広げ、街路の反対側の家と手前の森の層を追加した。

初回はshots/first.jpg、調整後はshots/entrance.jpg。比較ページの「現在」は初回の保存画像を指す。比較用の旧版を実行できる状態として保存したものではない。

## 確認と制約

構文確認、ブラウザーの警告・エラー取得、実際の歩行・横移動・首振り・Fを実施。入口、家、窓、街路、城門、振り返りの画像を実際に開いて見た。画像・ログはshots/。撮影のためにビューポートを変更していない。

診断用: `shot=entrance|house|window|street|gate|reverse`、`still=1`で灯りの揺れ停止、`recess=0|deep`で窓の見込み切替、`reflection=0`で床反射なし、`layers=0`で草花・城門の追加層なし。比較の画素数は描画へ値が届く補助確認で、品質の点数ではない。

建物の室内と城への移動は未実装。城と森は固定した遠景画像。城門の厚み、屋根の細部、草花の近接、平面に残る小物には限界がある。AAA品質に到達したとは判断していない。
