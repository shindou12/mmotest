# ヤシの葉軸を保つ追従

目的: 「草の生え方がそろっていない」という評価を受け、葉の付き方と放射方向が明確なヤシで比較する。

- [x] 既存の木・B03・ヤシ画像を開く。dreiの軸制限とSpeedTreeの葉カードを再確認する。
- [x] 既存のヤシを現在版として保存し、頂点から放射状に伸びる専用ヤシをBlenderで作る。
- [x] 葉房全体の自由回転をやめ、葉の芯を固定して葉面をひねる。曲面の各断面を共有し、裂け目を防ぐ。
- [x] 見本｜現在｜試作を同じカメラ操作で比較する。以前の比較ページは維持する。
- [x] Blenderで固定・中間・上限、複数方位を撮影して実際に開く。属性・芯の位置・画素応答を確認する。
- [x] 記録・出典・未確認をREADMEへ残す。変更先はcodex内。追加依存・課金なし。

既存Three.js r160とBlender 4.2.23を使用。dreiはMITで更新継続中だがReact/R3Fを要する。軸制限の考え方を参考にし、今回の葉ごとの曲線軸にはそのまま導入しない。SpeedTreeは商用製品のため説明を参考にするだけで導入しない。コードの転載なし。
