# W1 ヤシのゆっくりした風 Implementation Plan

目的: 同じ専用ヤシで、無風・弱い風・中程度の風を比較する。

構成: 既存のヤシと画像を再利用する。葉の芯の8区間を小さく回転させ、区間の長さと付け根を保つ。既存の2波を重ねる風処理とGPU Gemsの枝階層方式を参考にする。風の定数はconfig.jsonを正本とし、Three.jsとBlenderで共有する。

変更先: codex/palm-windの試作・UI・撮影・記録、codex/palm-billboard/scene.jsの任意の風フックと案内リンク、codex/art-tech-audit/EXPERIMENTS.mdの進捗。

- [x] 既存の風、既知の植生アニメーションとOSSを確認する。依存は増やさない。
- [x] 根元固定・区間長保持のW1を描画と影へ適用する。既存ページでは指定時のみ有効にする。
- [x] 大きな縦並びで見本／同じ木の無風／風を表示。弱・中、再生／停止、同じ時刻の比較を用意する。
