# 輪郭の手法ラボ

既存のヤシ・広葉樹・もみ・岩・木箱を比較。左は元、右は選んだ手法。強さ・幅を全手法で、境界の感度を奥行きと面の境界で変更できる。

- 外形: Three.js の OutlinePass の選択物マスク。葉はテクスチャの透明度で切る。
- 奥行き・面: 対象物の深度・法線を別の画像に描き、その差で外形と内部の変化を検出。透明な葉は同じアルファ閾値で深度・法線を描く。
- 外側の殻: 裏面を法線方向に膨らませる。板ポリの葉はこの試作では除外。頂点法線や個別のメッシュの切れ目によって輪郭に隙間ができる場合がある。

技法の参考資料は [前の調査](../asset-outline-study/README.md)。これは単体の比較ページで、既存ワールドへの導入や多数配置時の性能確認はしていない。

`node codex/outline-lab/check.mjs`: 3手法・10画面・スライダーの反映・エラーなしを確認。`node codex/outline-lab/verify-params.mjs`: それぞれの設定を変えた画像を保存。比較した画素の差は、外形の強さ17063・幅24839、深度法線の強さ13421・幅20774・感度29341、殻の強さ1651・幅3517。画像は `shots/`。
