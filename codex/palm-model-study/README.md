# ヤシの中心位置の比較

2026-10-26。ユーザーの「曲がった先から少し前に出る程度。上から見て不自然になるほどずらさない」という指摘を受けた試作。

- 見本: `../palm-study/reference/favorite-palm.png`。
- 現在: `palm2_a_liked_frond_v3.glb`。
- 試作: `palm2_a_liked_frond_v4.glb`。同じ葉・幹のテクスチャで形状だけを比べる。
- Blender本体をPythonから動かしてメッシュを編集する。v3の編集元は `assets/palm-compact-crown-v3.blend`、v4は `assets/palm-soft-top-v4.blend`。

## v4: 頂部の3枚を緩く開く

ユーザーの「一番上の3枚の角度が急すぎる」という指摘を受けた。頂部の3枚だけを、それぞれの付け根を軸に22・27・24度外側へ倒した。幹と残りの葉の形はv3と同じ。中央脈の曲線は保ち、追従用の位置・向きと照明法線も同じ回転へ合わせた。

`shots/soft-top-v4-*.png` の斜め4方向・真上・横の6枚を実際に開いて確認。横から見た突き出しが弱まり、冠の上面がなだらかにつながった。真上でも付け根は同じ位置を保っている。`capture_orbits.mjs` は `PAGE_ERRORS=[]`、実頂点と追従用中心の最大誤差は0.00000027。記録は `build-soft-top-v4.log` と `capture-soft-top-v4.log`。

葉の密度と、低い角度から見た裏面の暗さは残る。

## v3: 中心位置

調べた結果、元の葉の付け根は幹の先端から半径0.04程度に集まっていた。大きく離れた別の点から生えていたわけではない。一方、幹の曲がりが強く、葉の付け根にも高さの段差があるため、冠全体が根元から片側へ離れて見えた。

v3では幹の横への曲がりを0.78から0.46へ弱めた。幹の太さを保ち、各断面の向きも新しい曲線へ合わせる。葉の形は保ち、付け根の半径を0.018、高さの段差を元の35%へ寄せた。完全な左右対称や直立にはしていない。追従用の断面データも同じだけ動かす。

確認:

```powershell
blender -b --python codex/palm-model-study/make_liked_frond_candidate.py
node codex/palm-model-study/capture_orbits.mjs
```

- GLB書き出しと `.blend` 保存は成功。葉の頂点と追従用中心の最大誤差は0.00000048。
- canvasを実際にドラッグし、斜めの4方向と、UIの「真上」「横」ボタンで撮影した。`PAGE_ERRORS=[]`。
- `shots/compact-crown-v3-*.png` の6枚を実際に開いて確認した。上面での冠の横ずれは抑えられた。
- 葉の密度と立ち上がりの強さ、裏側の暗い筋は残る。この試作で改善済みとは扱わない。
- 書き出し時の既存のsampler警告は `build-compact-v3.log` に残る。葉と樹皮の両方は実画面で確認できた。
- アプリ内ブラウザーの自動接続はURL判定で拒否された。ローカルサーバーはHTTP 200、手元のChromiumで描画・回転を確認した。
