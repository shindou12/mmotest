# v5: 枝のまとまりを作る

ユーザーの承認: 前回の問題点（羽根状の反復、薄さ、細かい明暗、頂部と裾）を直す。

1. 前回v4を比較の「現在」に残す。最初は同じ枝画像を使い、組み方の違いを見る。
2. 幹→大枝→小枝→葉房の親子関係をBlenderで作る。幹から長い葉カードを並べる配置をやめ、大枝に沿って枝先の房を束ねる。
3. 枝の上面を覆う房と垂れる房を同じ大枝の中で重ね、枝の単位で厚みと陰を作る。上側は短い若枝にして蓋の形を避ける。
4. 正面・左右・背面・低い横・真上で撮影して開く。足りない点を記録して修正する。砂浜は指摘された1本だけで比較し、ヤシ3本と配置を保持する。
5. 最終の画像・台帳・比較ページを更新し、既存のSitesへ配置する。変更はcodex内。

## 既知の方法と選択

- [EZ-Tree](https://github.com/dgreenheck/ez-tree)（MIT）の現行ソースとREADMEを確認。親枝に沿って子枝を生やし、枝の骨格と描画用メッシュを分ける構成を参考にする。2026-10-26時点でREADMEにLOD、骨格共有、階層ごとの枝パラメータが記載されている。Three.js向けなので、Blenderの既存Builderへそのまま組み込まず、コードはコピーしない。新しい依存も入れない。
- [Saplingの公式説明](https://docs.blender.org/manual/en/3.0/addons/add_curve/sapling.html)も枝の階層・分岐位置・角度・曲がりを分けている。[現行拡張](https://extensions.blender.org/add-ons/sapling-tree-gen/versions/)は版により対応Blenderが異なる。今回は追加インストールをせず、既存のtubeと曲面カードで同じ基本構造を表現する。
- GPU Gems 3の葉房カードの方法は継続。一般的な樹木生成の構造を使い、見た目の設計に作業を集中する。
